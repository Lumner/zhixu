## 打开网站

在线阅读：[知序 · 计算机教程知识库](https://lumner.github.io/zhixu/)。源代码与自动部署位于 [Lumner/zhixu](https://github.com/Lumner/zhixu)，发布说明见 [部署到GitHub.md](部署到GitHub.md)。

**最简单：双击根目录的 index.html。** 网站正文、搜索、图表与高亮已经预生成，不需要联网或安装依赖即可阅读。所有运行资源位于dist内，不依赖外部字体或CDN。

也可以双击“启动网站.cmd”，或在此目录运行：

```powershell
npm start
```

需要本机Node.js20及以上。终端会显示实际本地URL，默认http://127.0.0.1:4173，端口占用会顺延。Ctrl+C停止预览。该服务器只绑定本机。

详细看 [添加教程.md](添加教程.md)。内容目录与界面分开：

```text
tutorial/

  reports/                   本地验证与预览截图
```

新增或改动内容后，在网站根目录：

```powershell
npm ci --ignore-scripts --no-audit --no-fund
npm run build
npm test
```

第一次修改需安装构建依赖；日常阅读不需要。实际锁文件已提供。build先在项目缓存生成新站点，成功后才替换dist，**不要直接编辑dist**，请修改web或content。构建时不要让其他聊天同时修改已接入课程。

## 构建与数据约定

页面使用原生HTML/CSS/JavaScript。固定Marked15.0.12与highlight.js11.11.1只在构建时工作；网页不动态解析Markdown。正文按节加载，搜索索引单独延迟加载，浏览器只缓存少量正文。

本地Markdown链接会转换为网页路由，未作为网页的教材文件保留下载；原始HTML被转义，危险链接协议不会生成可点击链接。教材流程/顺序图由本地SVG渲染器支持其当前语法，其他图表语法会保留源码。SystemVerilog围栏映射至Verilog语法高亮。

网站通过 GitHub Actions 构建并将 dist 发布到 GitHub Pages，也可将 dist 目录交给其他静态服务器；哈希路由不要求额外后端路由。

课程自身的真实微信、云、数据治理与发布验收状态仍以原文为准，网站转换不会改变它们。

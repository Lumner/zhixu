## 1. 导入与默认配置

导入16-studyhub-operations外层，主工程WebView，16主包+11分包共27页；独立renderer-probe另行导入。AppID、ENV_ID及runtime预期默认空白，启动目标检查会阻止云初始化。

在自己的隔离教学环境配置真实AppID、cloud.ENV_ID、runtime.STAGE/EXPECTED_APP_ID/EXPECTED_ENV_ID/RELEASE_VERSION，部署固定SDK 4.0.2云函数、九集合、存储规则和索引，并双账号验证。客户端核对不代替云端权限。真实诊断与性能采样默认关闭。

在教程根目录按顺序运行，非预期失败就停止后续汇总：

```powershell

node 验证/verify-compatibility.cjs 16-studyhub-operations
node 验证/verify-testing.cjs 16-studyhub-operations
node 验证/verify-release.cjs 16-studyhub-operations
node 验证/verify-operations.cjs
```

累计52→108→179→239→298→355→400→450→500→550→600。场景存在重叠。平台脚本运行临时127.0.0.1固定HTTP文件实验，受限环境需允许本机监听，不联网或发微信消息；其他微信/云使用桩或串行内存模型。

3类预期负向与3个固定内存变体另列。可选DOM、微信自动化、CI没有运行。标准50项局部覆盖率不代表本章新增50或全项目。

项目目录命令：

```powershell
node tests/run.cjs --coverage
node tools/build-manifest.cjs
node tools/release-audit.cjs
node tools/recovery-check.cjs
```

源码清单正常退出0，compiled/deployed均false；默认发布与回退检查退出2是预期受阻。不要用连续命令忽略中间非预期错误。发布默认28项待办，回退保持blocked/canExecute=false。

## 36.4 TypeScript最基本的类型标注

```ts
const title: string = '阅读一章';
const plannedMinutes: number = 25;
const done: boolean = false;
const tags: string[] = ['英语', '复习'];
```

冒号后是类型，不是赋值。string表示文字，number表示数值，boolean表示真假，string[]表示文字数组。

TypeScript在开发/编译时检查这些约定，运行前通常转换为JavaScript。微信和Node最终是否能执行，仍取决于输出语法与目标运行时。

参考[官方基础类型手册](https://www.typescriptlang.org/docs/handbook/2/everyday-types.html)；以下业务类型是课程自己的设计。

## 36.5 类型推断与错误位置

```ts
let count = 0;       // 推断为number
count = count + 1;
// count = '很多';   // 取消注释后产生类型错误
```

不是每个变量都要写冒号。对容易变化的边界、函数参数和返回协议写清楚，对明显的局部变量可使用推断。

“编译错误”不是运行中弹出的Toast。先看文件和行号，确认传入值与约定为何不同，不要立即加any消除提示。

## 36.6 用interface描述对象，用联合限制取值

实验src/contracts.ts包含：

```ts
export type Priority = 'normal' | 'high';
export interface TaskFields {
  title: string;
  done: boolean;
  priority: Priority;
}
export interface TaskDTO extends TaskFields {
  id: string;
  version: number;
}
```

interface描述对象有哪些字段；extends表示TaskDTO同时具备TaskFields字段，并增加id/version。export让其他模块能导入这些声明。

'normal' | 'high'是两个字符串字面量的联合，不能随便写'urgent'。这里是独立实验的简化规则，与主工程的完整优先级/任务模型分别管理。

## 36.7 函数类型表达输入与输出

```ts
function displayTitle(task: TaskFields): string {
  return task.done ? '已完成：' + task.title : task.title;
}
```

参数task必须满足TaskFields，返回值约定为string。函数仍执行普通JavaScript逻辑，类型声明不替你实现业务。

如果需要异步，返回类型可写Promise<TaskDTO>，表示等待后得到TaskDTO；这不表示请求一定成功，也不取消网络错误。

## 36.8 泛型：同一种外壳装不同数据

```ts
export type Reply<T> =
  | { ok: true; data: T }
  | { ok: false; error: { code: Code; message: string } };
```

T是类型参数。Reply<TaskDTO>的成功data是一条任务；Reply<TaskPage>的成功data是一页任务。

泛型复用的是结构约定，不会自动在网络上生成JSON，也不会检查JSON内容。真正的HTTP响应仍先视为unknown。

## 36.9 可辨别联合与缩窄

```ts
function readTitle(reply: Reply<TaskDTO>): string {
  if (reply.ok) {
    return reply.data.title;
  }
  return reply.error.message;
}
```

ok为true时，编译器知道走成功分支；另一个分支才有error。这叫依据共同字段缩窄联合。成功分支访问reply.error会产生类型错误。

这里的前提是reply确实符合协议。外部数据没有经过校验就强制声明成该类型，仍可能运行失败。参见[官方缩窄手册](https://www.typescriptlang.org/docs/handbook/2/narrowing.html)。

## 36.10 unknown为什么适合外部数据

```ts
const external: unknown = JSON.parse(text);
// external.title不能直接读取
const fields = parseFields(external);
```

unknown表示目前不知道具体结构。你必须先判断是不是对象、字段类型与范围是否符合要求，然后才能当业务对象使用。

any会绕过大量检查。它适合少数经过解释的边界，不适合用来把所有红线清掉。本实验的解析函数接受unknown并在运行时验证。

## 36.11 as与类型擦除的误区

```ts
// 反例：断言不是校验
const task = JSON.parse('{"done":"不是布尔值"}') as TaskDTO;
```

as告诉编译器按某类型理解，不会补字段、改数据或阻止恶意输入。interface、type与大多数类型标注也不会作为运行时规则保留。

本实验在数组所有条目通过isTask后才使用受限断言表达已验证结果；这与在网络入口直接as不同。任何断言都要能指出前面的事实依据。

## 36.12 完整的运行时字段校验

核心规则排版如下，实际工程提供完整文件：

```ts
export function parseFields(value: unknown): TaskFields {
  const data = shape(value, ['title', 'done', 'priority']);
  if (
    typeof data.title !== 'string' ||
    !data.title.trim() ||
    data.title.trim().length > 40 ||
    typeof data.done !== 'boolean' ||
    (data.priority !== 'normal' && data.priority !== 'high')
  ) {
    throw new DomainError('INVALID_INPUT');
  }
  return {
    title: data.title.trim(),
    done: data.done,
    priority: data.priority
  };
}
```

shape先保证对象只含这三个字段；if验证类型、非空、长度和允许值；return从零构造规范结果。类型缩窄让最后的priority自然符合字面量联合。

40按JavaScript代码单元计算，不声称是40个用户感知字符。业务限值是课堂选择，不是微信上限。

## 36.13 为什么未知字段也要处理

客户端传owner:'B'不应该改变服务器记录归属。本实验直接拒绝多余字段；真实主工程也保持明确的字段允许列表。

DTO响应同样校验，额外owner、错误version、重复ID、乱序和不匹配游标都会被拒绝，避免“接口有返回”被当作“结果可用”。

运行时校验与服务端归属检查各自负责一层，不能互相替代。

## 36.14 tsconfig的几个关键选项

| 选项 | 本实验值 | 作用 |
| --- | --- | --- |
| strict | true | 启用一组严格类型检查 |
| noUncheckedIndexedAccess | true | 数组/索引读取可能不存在 |
| exactOptionalPropertyTypes | true | 更精确地区分可选属性与显式undefined |
| noEmitOnError | true | 类型错误时不生成本次输出 |
| target | ES2020 | 选择输出语法目标 |
| module | commonjs | 与本实验CJS模块配合 |
| types | [] | 不自动纳入不需要的环境类型 |
| outDir | dist | 输出到独立目录 |

这些设置适用于本实验，不是所有微信TS项目的唯一配置。target不负责为运行时补齐API；lib声明也不等于运行环境真的拥有相应能力。

noEmitOnError默认并非true，本实验显式启用。它也不自动删除旧dist，因此任何编译失败都要停止后续运行。[官方选项说明](https://www.typescriptlang.org/tsconfig/noEmitOnError.html)

## 36.17 类型错误也可以成为测试

type-tests/positive.ts包含四个注释，例如：

```ts
// @ts-expect-error done必须是布尔值
const wrong: TaskFields = { title: 'x', done: 'false', priority: 'normal' };
```

注释针对紧接的一行，错误位置也需要落在该行。若该行不再产生错误，编译器会报告注释未被使用。[官方说明](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-3-9.html)

## 36.20 锁文件记录什么

本次package-lock.json实际记录固定版本、公开registry来源、integrity和依赖结构。它帮助复现解析结果，不是软件没有漏洞的证明。

package.json表达意图，锁文件记录具体解析，node_modules是本机安装结果。交付包含前两者与课程源码，排除node_modules；接收者运行npm ci恢复。

修改依赖后应审查锁文件差异并重测。不要手工编造integrity或把别的工程锁文件复制来充数。

## 36.21 install、ci与安装脚本

npm install适合有意调整依赖并更新锁文件；npm ci要求锁文件与清单一致，并重建安装目录。实际行为以所用npm版本为准。[npm ci官方文档](https://docs.npmjs.com/cli/v11/commands/npm-ci/)

本实验用--ignore-scripts关闭安装生命周期脚本；--no-audit与--no-fund减少附加网络/提示，不代表做过安全审计。ignore-scripts也不能让任意包天然安全。

在课程配置下，显式npm run build/npm test仍用于执行你选择的课程脚本。先读scripts，确认自己正在什么目录运行。

## 36.22 为什么不让npx临时下载未知工具

工具入口使用本地安装的typescript/bin/tsc，并检查版本5.9.3。不支持时明确报错，要求先安装依赖，不自动下载另一个版本。

这让“运行了哪个编译器”可核对。npx本身不是错误工具，但自动获取行为、包名与版本都应当清楚，不能用它掩盖缺失依赖。

第一次遇到Cannot find module时，先查目录、安装是否成功、锁文件和版本，不在所有文件里改require路径。

## 36.23 为什么Node包未必能用于小程序

依赖可能使用fs、http服务、process、Buffer、DOM、动态加载或不被目标构建支持的语法。类型声明能找到，不等于这些能力在微信中存在。

## 36.29 先理解不同的界面表达

原生写法：

```js
Page({
  data: { count: 0 },
  onAdd() { this.setData({ count: this.data.count + 1 }); }
});
```

在其他框架中，你会遇到React的state更新函数、Vue的响应式变量和模板指令。它们都在表达“状态改变后更新界面”，但API、生命周期、构建与平台映射不同。

不要把某端的浏览器DOM写法直接粘贴到小程序，也不要把Vue模板语法直接写进WXML。本课程先打好的事件、组件、状态和异步基础仍然有用。

## 36.30 框架迁移先做一个纵向小功能

选“读取固定任务列表—显示空态—失败重试”作为试点。保持同一接口契约与测试数据，分别验证状态、分页、原编号、权限和界面。

再扩展一项写入，随后才接知识库或计时。样式正常不代表后台恢复、隐私和幂等已迁移。

避免同时换框架、后端、数据模型和同步协议。若结果变坏，你会很难知道是哪一层造成。

## 36.31 什么时候考虑独立后端

当你需要自有服务部署、复杂外部集成、统一多端身份或更明确的运维边界时，可以评估独立后端。

你同时要负责认证、会话、数据库、事务、文件、网络、安全、监测、备份和费用等工作。后端不是把云函数复制到Express文件后就自然完成。

本章使用Node标准库演示边界，不引入Web框架，便于看清HTTP层究竟做了什么。

## 36.32 真实微信身份应怎样衔接

真实路线应由客户端取得一次性登录凭证，交给自己的后端；后端按当前微信官方服务端接口核验，再建立自己的会话与授权规则。密钥只能在服务端管理，不能接收客户端自报的OPENID作为可信身份。

本次微信npm与code2Session开发者页面未取得正文，因此不拼装未经核对的登录服务。本实验使用X-Course-Actor=A/B，是公开可伪造的固定夹具，只用于本机测试。

任何人都能把A改B。该实验没有微信登录、真正认证、持久会话、令牌刷新或生产权限模型，不能作为上线后端。

## 36.33 实验HTTP协议

| 方法与路径 | 输入 | 成功 |
| --- | --- | --- |
| GET /healthz | 无 | 固定夹具状态，不代表业务健康 |
| GET /v1/tasks | limit、cursor | 200，items与nextCursor |
| POST /v1/tasks | opId、fields | 201，TaskDTO |
| PATCH /v1/tasks/t0001 | opId、version、fields | 200，TaskDTO |

未知路由404、不支持方法405、输入400、夹具身份401、版本409、请求体413、媒体类型415、内存容量429，内部异常500且只回固定公开文案。

状态码与JSON结构共同解释结果。HTTP200并不保证业务DTO正确，客户端仍要解析。

## 36.34 启动并手动请求本地服务

构建成功后在第17组运行：

```powershell
npm start
```

服务仅绑定127.0.0.1的临时空闲端口，并输出实际URL。复制输出，例如实际端口是51000时，在另一终端：

```powershell
$apiBase = 'http://127.0.0.1:51000'
$actorHeaders = @{ 'X-Course-Actor' = 'A' }
Invoke-RestMethod -Uri "$apiBase/healthz"
$body = @{
  opId = 'operation_manual001'
  fields = @{ title = '学习HTTP'; done = $false; priority = 'normal' }
} | ConvertTo-Json -Depth 4
Invoke-RestMethod -Method Post -Uri "$apiBase/v1/tasks" -Headers $actorHeaders -ContentType 'application/json; charset=utf-8' -Body ([System.Text.Encoding]::UTF8.GetBytes($body))
Invoke-RestMethod -Uri "$apiBase/v1/tasks" -Headers $actorHeaders
```

51000只是说明端口，必须改为本次输出。Ctrl+C关闭服务后内存清空；没有持久保存。手机里的127.0.0.1也不指向你的电脑，本实验并未连接真机。

## 36.35 请求体上限按字节计算

server/index.cjs中的readJson函数按收到的Buffer长度累计，超过4096字节即拒绝，之后不再累积正文。结束时以严格UTF-8解码，再JSON.parse。

中文通常占多个UTF-8字节，不能只看JavaScript字符串length。实验测试专门用“字符数不足4096、字节数超过4096”的正文验证413。

4096是课堂上限，不是微信或Node默认额度；真实服务还需网关、超时、速率、解析和资源限制。[Node HTTP资料](https://nodejs.org/download/release/v24.15.0/docs/api/http.html)

## 36.36 内存模型怎样隔离记录

服务器把固定actor作为内部owner，DTO只返回id、version、title、done、priority。列表过滤owner，更新时同时检查归属，不信任请求正文中的owner。

在课堂固定身份假设下，这验证了“作用域必须进入查询/写入条件”的规则；它不能证明真实身份认证安全，因为actor本来就可伪造。

记录与回执均为进程内Map。代码没有数据库锁、跨进程事务或持久备份。

## 36.37 原编号与版本继续保留

创建/更新先规范化输入，按actor+opId查回执。同编号同内容重放返回旧结果，同编号改内容拒绝。

更新还要求当前version一致，成功只加一次。这个进程内教学模型可以帮助理解协议，但不是分布式幂等证明。

回执是历史结果，不是当前记录的强一致快照。真实迁移仍应沿用第25、30章完整草稿/outbox与回执协议。

## 36.38 分页与容量不能悄悄破坏约定

列表按ID继续，返回nextCursor；客户端不能把第一页当全量。限值1—20为课堂查询约定。

内存记录/回执默认上限100，满后阻止新写入，已有回执仍可重放。不能为了腾空间直接删回执，让旧指令突然再次生效。

真实后端应设计持久容量、过期操作拒绝、归档与清理；本实验没有实现这些生产流程。

## 36.39 客户端适配层负责哪一段

client/tasks-client.cjs接收一个request依赖：

```js
const client = createTasksClient({
  request: async ({ method, url, data }) => {
    // 传输层返回 { statusCode, data }
  }
});
```

list/create/update决定路径、状态与解析；传输层决定地址、会话、网络与平台API。测试既可传固定响应，也可接真实Node回环请求。

迁入微信时可以另做wx.request传输，但还要保留取消、期限、原编号、错误类型与合法域名等完整约束。本章没有直接替换主工程仓储。

## 36.40 适配层不自动修复未知写入

适配层不额外重试、不生成新opId，不把网络异常改成成功。create/update参数由原业务提交流程提供。

响应错误码只映射固定公共文案，不原样显示任意服务器message。成功状态不匹配、DTO非法或游标不一致都属于协议错误。

真正后端接入后，要测试“已提交但响应丢失”与重放；仅能正常GET一条数据不算迁移完成。

## 36.41 从实验到生产还缺什么

| 领域 | 本实验 | 真实接入前 |
| --- | --- | --- |
| 身份 | 固定可伪造A/B | 可信登录、会话、授权 |
| 数据 | 进程Map | 持久数据库、事务与并发验证 |
| 传输 | 本机HTTP | 实际HTTPS、合法域名、网络与隐私核对 |
| 文件 | 无 | 私人存储、归属、引用与清理 |
| 恢复 | 无持久备份 | 备份、恢复演练与回退 |
| 运维 | 固定本地测试 | 日志、告警、资源、依赖与负责人 |
| 数据治理 | 不接真实用户 | 告知、期限与适用权利机制 |

框架和类型系统不会替你填上这些空格。第34—35章的正式交付阻塞项依然有效。

## 36.42 三类测试分别证明什么

类型测试证明编译器是否接受或拒绝某种用法；运行时测试证明未知值经过校验后的行为；真实回环HTTP测试证明本机请求、字节、状态与适配链路。

本章新增50项，实际运行TypeScript5.9.3并拒绝四个无抑制负例。主工程保留原600项场景且摘要匹配，跨两类工程共650项，不说成一个微信项目运行了650种互不重复功能。

没有运行WeUI构建、Taro/uni-app、微信编译、真实微信身份或生产后端。报告明确记录这些范围。

## 36.43 工具迁移的验收顺序

先固定原行为与数据，再选一个小模块；写正例、类型负例和运行时非法输入；检查生成代码、依赖与输出目录；最后在目标平台编译、真机与真实权限验证。

测试通过后再扩大范围。任何“删校验后编译就过了”“换新opId就不冲突了”都可能改变业务协议，而不是解决工具问题。

## 36.44 最终综合实践的业务目标

以第16组为候选，实现并理解：私人任务增删改查、知识库与标签/链接、图片引用、专注会话与恢复、七日统计、草稿与待处理、平台实验、质量与维护准备。

你应能从按钮追到页面、仓储、云函数、事务与记录，再解释返回和恢复。具体执行步骤见 [最终综合实践](最终综合实践-毕业设计与能力验收.md)。

课程已经提供相对复杂业务代码；能在你自己的环境运行，还需要实际账号、部署、权限和真机操作。

## 36.45 分清课程完成与正式服务完成

36章正文、代码、练习和本地验证已经组成完整学习主线；正式服务仍需你完成真实部署、系统权限、数据隔离、隐私材料、期限/权利机制、审核与维护演练。

已有单条删除和汇总报告不等于完整账户处理或全量个人数据导出。未实现的生产能力不能靠在材料里勾选完成。

最终验收把“能解释”“本地已验证”“真实环境已验证”“尚未实现”分别记录，不把它们混成一个绿勾。

## 36.46 选择一个独立扩展作业

可选择分类管理、任务日历、知识库过滤、专注计划模板或一个新的只读统计维度。先写输入、输出、权限、口径、失败恢复和验收，再设计界面。

不要第一次扩展就同时加入支付、公开内容、定位和复杂消息。这些能力有独立平台、业务与资质条件，应逐专题查当前官方资料。

扩展必须保持原归属、版本与原编号约束，并重新核对数据清单。

## 36.47 学完后怎样巩固

第一轮不看源码，从空目录写本地任务板；第二轮独立做多页面和组件；第三轮接网络并制造失败；第四轮在隔离云环境验证两账号与恢复。

遇到疑惑回到相应章节：语法02—03、页面/组件10—15、网络16—19、云与权限20—25、完整业务26—29、体验与交付30—35。

最后再决定TS、组件库、框架或后端路线。能够解释并验证当前工程，比记住更多工具名称更有价值。

## 36.48 全课程主线完成标准

你能独立拆需求、写基本语法、组织页面/组件、处理网络与云端身份、设计数据和并发协议、排查失败，并给出有证据的验收记录。

你也知道能力边界：本地模拟不是微信运行时，类型不是运行时校验，体验版不是测试云，回退代码不是还原数据，材料齐全不是自动获得发布资格。

保存前面各阶段版本作对照，按最终实践表完成自己的真实结果。后续学习可以围绕一个具体需求继续深入，而不需要一次掌握微信平台的全部API。

# 第十六阶段：20组练习与参考答案

配合 [第36章](36-TypeScript工具扩展与最终综合实践.md)、[独立实验](示例代码/17-studyhub-tooling/README.md) 与 [最终综合实践](最终综合实践-毕业设计与能力验收.md)。先独立作答，类型负例不要混入正常构建入口。

## 1. 代码运行环境

题目：wx.chooseMedia、node:http、document.querySelector分别属于哪种环境？

参考：微信客户端、Node服务、浏览器DOM。安装包或添加类型声明不会把三种运行时能力自动变成相同东西。

验收：说明为何第17组不是可导入微信的小程序。

## 2. 类型推断

题目：let count=0后再写count='1'为何报错？是否所有变量都要写冒号？

参考：count推断为number，字符串不符合约定；明显局部值可推断，公共参数与边界应清楚标注。

验收：改为count+=1，并说明编译错误与运行异常的区别。

## 3. interface与联合

题目：TaskDTO比TaskFields多什么？priority为何不能写urgent？

参考：多id、version；Priority是normal/high字面量联合。实验是简化契约，不等于主工程全部任务字段。

验收：手写这三种声明并解释extends。

## 4. 泛型返回

题目：Reply<TaskDTO>与Reply<number>的成功data分别是什么？

参考：一条任务与一个数值。泛型表达结构复用，不生成HTTP或验证JSON。

验收：给两者写合法值，再写会被编译器拒绝的值。

## 5. 可辨别联合

题目：为什么reply.ok为true时不能读reply.error？

参考：编译器已缩窄到成功分支，只有data；失败分支才有error。外部数据未经校验时这个前提不可靠。

验收：在negative-cases/wrong-branch.ts看到真实诊断。

## 6. unknown与as

题目：JSON.parse(text) as TaskDTO是否能阻止done='false'？

参考：不能。断言不会执行验证；unknown要求先检查结构。应调用接受unknown的解析函数。

验收：用非法JSON对象调用parseFields，观察INVALID_INPUT。

## 7. 静态与运行时两道检查

题目：done字符串在TS文件里能被拒绝，为何服务器还要检查typeof？

参考：网络请求不受你的编译器约束，也可能来自JS、其他程序或错误版本。静态检查与运行时校验分别保护不同边界。

验收：不改TS源，直接HTTP发非法输入，仍应400。

## 8. 允许字段

题目：POST正文多owner:'B'为什么被拒绝？

参考：身份与归属不从正文接受；shape要求精确字段。内部owner来自课堂固定actor，真实后端必须来自可信会话。

验收：分别验证正文顶层与fields里的多余字段。

## 9. 标题与代码单元

题目：为什么“40代码单元”不能直接说成40个字？

参考：JavaScript字符串长度按UTF-16代码单元，一些字符占两个或多个。规范化trim也不会改变所有字符语义。

验收：比较'中'.length与一个补充平面字符的length，不把课堂限值说成微信上限。

## 10. tsconfig

题目：noEmitOnError能否自动删掉上次生成的dist？

参考：不能，它阻止本次错误输出，不清理旧结果。因此编译失败后必须停止后续运行，不能继续拿旧JS做验证。

验收：解释noUncheckedIndexedAccess为何要求考虑数组元素不存在。

## 11. 预期错误测试

题目：@ts-expect-error和“忽略所有错误”有何不同？

参考：紧接的行若没有错误，预期错误注释会被报告为无用。仍需检查注释覆盖的是预期位置，不能将其当正常代码修复方法。

验收：移除一处错误而保留注释，真实类型检查应失败；练习后恢复再全量检查。

## 12. 锁文件与ci

题目：package.json、package-lock.json、node_modules分别负责什么？

参考：依赖意图、具体解析/完整性、实际安装。npm ci核对并重建安装结果，不证明没有漏洞。

验收：指出本次锁定TypeScript5.9.3的实际字段，不手改integrity。

## 13. 开发依赖

题目：运行已构建HTTP服务是否需要TypeScript编译器？重新检查和构建呢？

参考：已生成服务只用Node标准库和dist，不需编译器；重建/测试需要固定开发依赖。主工程云SDK是另外的依赖边界。

验收：说明为何不能用第17组package覆盖云函数package。

## 14. 请求体字节数

题目：1500个中文字符加JSON为何可能触发4096字节上限？

参考：UTF-8中文占多个字节，字符length不等于传输字节。实验按Buffer长度累计并严格解码。

验收：对应真实HTTP测试返回413，非法UTF-8返回400。

## 15. 原编号与内存容量

题目：容量满时为什么不删最旧回执腾空间？

参考：旧指令再来可能重复生效。本实验停止新写，但允许已有回执重放；真实后端需设计过期拒绝与持久清理协议。

验收：容量1创建一次，再新写失败，同编号同内容仍返回原结果。

## 16. 接口适配

题目：客户端request返回statusCode=500但正文像合法列表，能否显示成功？

参考：不能；状态与正文共同校验。协议错误、业务失败和网络未知应区分。适配层不自动换opId或重试写入。

验收：用固定响应测试PROTOCOL，传输异常保持原对象。

## 17. 固定身份不是登录

题目：A看不到B的列表，是否证明此服务有生产认证？

参考：没有。任何人都能改X-Course-Actor；只证明在固定actor假设下的数据过滤规则。真实微信核验和会话未实现。

验收：解释哪些部分必须移到可信服务端，密钥为何不能在客户端。

## 18. WeUI与框架

参考：不会。组件负责界面，框架改变表达与构建，业务协议、数据与平台差异仍需自己验证。

验收：写一个只读小试点的验收范围，明确微信编译、包体和真机是待执行项。

## 19. 主工程与扩展实验

题目：为什么不说“第17组完整小程序650项全过”？

参考：第16组是完整JS业务，已有600本地场景且摘要匹配；第17组是独立TS/HTTP实验，新跑50。范围跨两个工程，未执行微信、框架或真实身份。

const { parsePageReply, parseTaskReply, DomainError } = require('../dist/contracts.js');
function createTasksClient({ request }) {
  async function call(method,url,data,parse,status) {
    // 不自动重试写入，不重新生成opId；身份与传输由调用方显式提供。
    const response = await request({ method,url,data });
    if (!response || typeof response.statusCode !== 'number') throw new DomainError('PROTOCOL');
    if (response.statusCode !== status) {
      if (response.data && response.data.ok === false) parse(response.data);
      throw new DomainError('PROTOCOL');
    }
    return parse(response.data);
  }
  return {
    list(cursor = null) { const query = cursor === null ? '' : '&cursor=' + encodeURIComponent(cursor); return call('GET','/v1/tasks?limit=5'+query,undefined,parsePageReply,200); },
    create(opId,fields) { return call('POST','/v1/tasks',{opId,fields},parseTaskReply,201); },
    update(id,opId,version,fields) { return call('PATCH','/v1/tasks/'+encodeURIComponent(id),{opId,version,fields},parseTaskReply,200); }
  };
}
module.exports = { createTasksClient };

    if (!isRecord(value) || Object.keys(value).length !== keys.length || !keys.every(key => Object.prototype.hasOwnProperty.call(value, key)))
        throw new DomainError('INVALID_INPUT');
    return value;
}
function parseFields(value) {
    const data = shape(value, ['title', 'done', 'priority']);
    if (typeof data.title !== 'string' || !data.title.trim() || data.title.trim().length > 40
        || typeof data.done !== 'boolean' || (data.priority !== 'normal' && data.priority !== 'high'))
        throw new DomainError('INVALID_INPUT');
    return { title: data.title.trim(), done: data.done, priority: data.priority };
}
function parseOp(value) {
    if (typeof value !== 'string' || !/^operation_[A-Za-z0-9_-]{8,64}$/.test(value))
        throw new DomainError('INVALID_INPUT');
    return value;
}
function parseCreate(value) {
    const data = shape(value, ['opId', 'fields']);
    return { opId: parseOp(data.opId), fields: parseFields(data.fields) };
}
function parseUpdate(value) {
    const data = shape(value, ['opId', 'version', 'fields']);
    if (!Number.isSafeInteger(data.version) || typeof data.version !== 'number' || data.version < 1)
        throw new DomainError('INVALID_INPUT');
    return { opId: parseOp(data.opId), version: data.version, fields: parseFields(data.fields) };
}
function validId(value) { return typeof value === 'string' && /^t\d{4}$/.test(value); }
function parseList(value) {
    if (!isRecord(value) || Object.keys(value).some(key => !['limit', 'cursor'].includes(key)))
        throw new DomainError('INVALID_INPUT');
    const limitText = value.limit === undefined ? '5' : value.limit;
    if (typeof limitText !== 'string' || !/^[1-9]\d?$/.test(limitText) || Number(limitText) > 20)
        throw new DomainError('INVALID_INPUT');
    const cursor = value.cursor === undefined ? null : value.cursor;
    if (cursor !== null && !validId(cursor))
        throw new DomainError('INVALID_INPUT');
    return { limit: Number(limitText), cursor };
}
function isTask(value) {
    try {
        const data = shape(value, ['id', 'version', 'title', 'done', 'priority']);
        const normalized = parseFields({ title: data.title, done: data.done, priority: data.priority });
        if (normalized.title !== data.title)
            return false;
        return validId(data.id) && typeof data.version === 'number' && Number.isSafeInteger(data.version) && data.version > 0;
    }
    catch (_) {
        return false;
    }
}
function unwrap(value) {
    if (!isRecord(value) || typeof value.ok !== 'boolean')
        throw new DomainError('PROTOCOL');
    if (!value.ok) {
        const code = isRecord(value.error) ? value.error.code : null;
        if (typeof code !== 'string' || !Object.prototype.hasOwnProperty.call(messages, code))
            throw new DomainError('PROTOCOL');
        // 不信任服务端任意message，只使用已知错误码的固定公开文案。
        throw new DomainError(code);
    }
    if (Object.keys(value).length !== 2 || !Object.prototype.hasOwnProperty.call(value, 'data'))
        throw new DomainError('PROTOCOL');
    return value.data;
}
function parseTaskReply(value) {
    const data = unwrap(value);
    if (!isTask(data))
        throw new DomainError('PROTOCOL');
    return { id: data.id, version: data.version, title: data.title, done: data.done, priority: data.priority };
}
function parsePageReply(value) {
    const data = unwrap(value);
    if (!isRecord(data) || Object.keys(data).length !== 2 || !Array.isArray(data.items) || data.items.length > 20
        || !data.items.every(isTask) || !(data.nextCursor === null || validId(data.nextCursor))
        || new Set(data.items.map(item => item.id)).size !== data.items.length)
        throw new DomainError('PROTOCOL');
    const rows = data.items;
    if (rows.some((item, index) => index > 0 && item.id <= rows[index - 1].id)
        || (data.nextCursor !== null && (!rows.length || rows[rows.length - 1].id !== data.nextCursor)))
        throw new DomainError('PROTOCOL');
    return { items: rows.map(item => ({ ...item })), nextCursor: data.nextCursor };
}

const http = require('node:http');
const { DomainError, failure } = require('../dist/contracts.js');
const { createStore } = require('./store.cjs');
const STATUS = { INVALID_INPUT:400,UNAUTHORIZED:401,NOT_FOUND:404,CONFLICT:409,OP_REUSED:409,CAPACITY:429,TOO_LARGE:413,MEDIA_TYPE:415,METHOD:405,PROTOCOL:502,INTERNAL:500 };
function readJson(request) {
  if (!/^application\/json(?:\s*;\s*charset=utf-8)?$/i.test(request.headers['content-type'] || '')) return Promise.reject(new DomainError('MEDIA_TYPE'));
  return new Promise((resolve,reject) => {
    let bytes = 0, ended = false; const chunks = [];
    const stop = error => { if (!ended) { ended = true; chunks.length = 0; reject(error); } };
    request.on('data',chunk => {
      if (ended) return;
      bytes += chunk.length;
      if (bytes > 4096) stop(new DomainError('TOO_LARGE')); else chunks.push(chunk);
    });
    request.on('aborted',() => stop(new DomainError('INVALID_INPUT')));
    request.on('error',() => stop(new DomainError('INVALID_INPUT')));
    request.on('end',() => {
      if (ended) return; ended = true;
      try { resolve(JSON.parse(new TextDecoder('utf-8',{fatal:true}).decode(Buffer.concat(chunks)))); } catch (_) { reject(new DomainError('INVALID_INPUT')); }
    });
  });
}
function createServer({ store = createStore() } = {}) {
  const server = http.createServer(async (request,response) => {
    function send(status,body) {
      if (response.destroyed || response.headersSent) return;
      response.writeHead(status,{ 'Content-Type':'application/json; charset=utf-8','Cache-Control':'no-store','X-Course-Mode':'fixture-only' });
      response.end(JSON.stringify(body));
    }
    try {
      const url = new URL(request.url,'http://127.0.0.1');
      if (url.pathname === '/healthz' && request.method === 'GET') {
        send(200,{ ok:true,data:{ mode:'fixture-only',persistent:false,wechatIdentity:false } }); return;
      }
      // 公开可伪造的课堂夹具，绝不是微信登录或可信身份认证。
      const actor = request.headers['x-course-actor'];
      if (!['A','B'].includes(actor)) throw new DomainError('UNAUTHORIZED');
      const item = /^\/v1\/tasks\/(t\d{4})$/.exec(url.pathname);
      if (url.pathname === '/v1/tasks') {
        if (request.method === 'GET') {
          const pairs = [...url.searchParams.entries()];
          if (new Set(pairs.map(([key]) => key)).size !== pairs.length) throw new DomainError('INVALID_INPUT');
          send(200,{ ok:true,data:store.list(actor,Object.fromEntries(pairs)) }); return;
        }
        if (request.method === 'POST') {
          if (url.search) throw new DomainError('INVALID_INPUT');
          send(201,{ ok:true,data:store.create(actor,await readJson(request)) }); return;
        }
        throw new DomainError('METHOD');
      }
      if (item) {
        if (request.method !== 'PATCH') throw new DomainError('METHOD');
        if (url.search) throw new DomainError('INVALID_INPUT');
        send(200,{ ok:true,data:store.update(actor,item[1],await readJson(request)) }); return;
      }
      throw new DomainError('NOT_FOUND');
    } catch (error) {
      request.resume(); const code = error instanceof DomainError ? error.code : 'INTERNAL';
      send(STATUS[code],failure(code));
    }
  });
  server.requestTimeout = 5000; server.headersTimeout = 5000; server.keepAliveTimeout = 1000;
  return server;
}

const { parseCreate, parseUpdate, parseList, DomainError, validId } = require('../dist/contracts.js');
function createStore({ capacity = 100 } = {}) {
  if (!Number.isInteger(capacity) || capacity < 1 || capacity > 100) throw new Error('INVALID_CAPACITY');
  const records = new Map(), receipts = new Map(); let sequence = 0;
  const clone = value => structuredClone(value);
  const actorCheck = actor => { if (!['A', 'B'].includes(actor)) throw new DomainError('UNAUTHORIZED'); };
  const dto = row => ({ id: row.id, version: row.version, title: row.title, done: row.done, priority: row.priority });
  function replay(actor, opId, content) {
    const row = receipts.get(actor + ':' + opId);
    if (!row) return null;
    if (row.content !== content) throw new DomainError('OP_REUSED');
    return clone(row.result);
  }
  function reserve() { if (receipts.size >= capacity) throw new DomainError('CAPACITY'); }
  return {
    list(actor, query = {}) {
      actorCheck(actor); const { limit, cursor } = parseList(query);
      const rows = [...records.values()].filter(row => row.owner === actor && (!cursor || row.id > cursor)).sort((a,b) => a.id < b.id ? -1 : a.id > b.id ? 1 : 0);
      const page = rows.slice(0,limit);
      return { items: page.map(dto), nextCursor: rows.length > limit ? page[page.length - 1].id : null };
    },
    create(actor, body) {
      actorCheck(actor); const { opId, fields } = parseCreate(body), content = JSON.stringify({ kind: 'create', fields });
      const old = replay(actor,opId,content); if (old) return old;
      reserve(); if (records.size >= capacity) throw new DomainError('CAPACITY');
      const id = 't' + String(++sequence).padStart(4,'0'), row = { id, owner: actor, version: 1, ...fields };
      records.set(id,row); const result = dto(row); receipts.set(actor + ':' + opId,{ content, result: clone(result) }); return result;
    },
    update(actor,id,body) {
      actorCheck(actor); if (!validId(id)) throw new DomainError('INVALID_INPUT');
      const { opId,version,fields } = parseUpdate(body), content = JSON.stringify({ kind: 'update', id, version, fields });
      const old = replay(actor,opId,content); if (old) return old;
      const row = records.get(id); if (!row || row.owner !== actor) throw new DomainError('NOT_FOUND');
      if (row.version !== version) throw new DomainError('CONFLICT');
      reserve(); const next = { ...row, ...fields, version: version + 1 }; records.set(id,next);
      const result = dto(next); receipts.set(actor + ':' + opId,{ content, result: clone(result) }); return result;
    },
    counts: () => ({ records: records.size, receipts: receipts.size })
  };
}

export type Priority = 'normal' | 'high';
export interface TaskFields { title: string; done: boolean; priority: Priority; }
export interface TaskDTO extends TaskFields { id: string; version: number; }
export interface TaskPage { items: TaskDTO[]; nextCursor: string | null; }
export type Code = 'INVALID_INPUT' | 'UNAUTHORIZED' | 'NOT_FOUND' | 'CONFLICT' | 'OP_REUSED' | 'CAPACITY' | 'TOO_LARGE' | 'MEDIA_TYPE' | 'METHOD' | 'PROTOCOL' | 'INTERNAL';
export type Reply<T> = { ok: true; data: T } | { ok: false; error: { code: Code; message: string } };
const messages: Record<Code, string> = {
  INVALID_INPUT: '输入不合法', UNAUTHORIZED: '本地固定身份无效', NOT_FOUND: '记录或路由不存在',
  CONFLICT: '版本冲突，请重新读取', OP_REUSED: '原编号内容不一致', CAPACITY: '课堂内存容量已满',
  TOO_LARGE: '请求体超过课堂上限', MEDIA_TYPE: '需要JSON请求', METHOD: '方法不支持',
  PROTOCOL: '响应格式不符合课堂协议', INTERNAL: '本地实验处理失败'
};
export class DomainError extends Error {
  constructor(public readonly code: Code) { super(messages[code]); this.name = 'DomainError'; }
}
export function failure(code: Code): Reply<never> { return { ok: false, error: { code, message: messages[code] } }; }
export function isRecord(value: unknown): value is Record<string, unknown> {
  return typeof value === 'object' && value !== null && !Array.isArray(value);
}
function shape(value: unknown, keys: string[]): Record<string, unknown> {
  if (!isRecord(value) || Object.keys(value).length !== keys.length || !keys.every(key => Object.prototype.hasOwnProperty.call(value, key))) throw new DomainError('INVALID_INPUT');
  return value;
}
export function parseFields(value: unknown): TaskFields {
  const data = shape(value, ['title', 'done', 'priority']);
  if (typeof data.title !== 'string' || !data.title.trim() || data.title.trim().length > 40
    || typeof data.done !== 'boolean' || (data.priority !== 'normal' && data.priority !== 'high')) throw new DomainError('INVALID_INPUT');
  return { title: data.title.trim(), done: data.done, priority: data.priority };
}
function parseOp(value: unknown): string {
  if (typeof value !== 'string' || !/^operation_[A-Za-z0-9_-]{8,64}$/.test(value)) throw new DomainError('INVALID_INPUT');
  return value;
}
export function parseCreate(value: unknown): { opId: string; fields: TaskFields } {
  const data = shape(value, ['opId', 'fields']);
  return { opId: parseOp(data.opId), fields: parseFields(data.fields) };
}
export function parseUpdate(value: unknown): { opId: string; version: number; fields: TaskFields } {
  const data = shape(value, ['opId', 'version', 'fields']);
  if (!Number.isSafeInteger(data.version) || typeof data.version !== 'number' || data.version < 1) throw new DomainError('INVALID_INPUT');
  return { opId: parseOp(data.opId), version: data.version, fields: parseFields(data.fields) };
}
export function validId(value: unknown): value is string { return typeof value === 'string' && /^t\d{4}$/.test(value); }
export function parseList(value: unknown): { limit: number; cursor: string | null } {
  if (!isRecord(value) || Object.keys(value).some(key => !['limit', 'cursor'].includes(key))) throw new DomainError('INVALID_INPUT');
  const limitText = value.limit === undefined ? '5' : value.limit;
  if (typeof limitText !== 'string' || !/^[1-9]\d?$/.test(limitText) || Number(limitText) > 20) throw new DomainError('INVALID_INPUT');
  const cursor = value.cursor === undefined ? null : value.cursor;
  if (cursor !== null && !validId(cursor)) throw new DomainError('INVALID_INPUT');
  return { limit: Number(limitText), cursor };
}
export function isTask(value: unknown): value is TaskDTO {
  try {
    const data = shape(value, ['id', 'version', 'title', 'done', 'priority']);
    const normalized = parseFields({ title: data.title, done: data.done, priority: data.priority });
    if (normalized.title !== data.title) return false;
    return validId(data.id) && typeof data.version === 'number' && Number.isSafeInteger(data.version) && data.version > 0;
  } catch (_) { return false; }
}
function unwrap(value: unknown): unknown {
  if (!isRecord(value) || typeof value.ok !== 'boolean') throw new DomainError('PROTOCOL');
  if (!value.ok) {
    const code = isRecord(value.error) ? value.error.code : null;
    if (typeof code !== 'string' || !Object.prototype.hasOwnProperty.call(messages, code)) throw new DomainError('PROTOCOL');
    // 不信任服务端任意message，只使用已知错误码的固定公开文案。
    throw new DomainError(code as Code);
  }
  if (Object.keys(value).length !== 2 || !Object.prototype.hasOwnProperty.call(value, 'data')) throw new DomainError('PROTOCOL');
  return value.data;
}
export function parseTaskReply(value: unknown): TaskDTO {
  const data = unwrap(value);
  if (!isTask(data)) throw new DomainError('PROTOCOL');
  return { id: data.id, version: data.version, title: data.title, done: data.done, priority: data.priority };
}
export function parsePageReply(value: unknown): TaskPage {
  const data = unwrap(value);
  if (!isRecord(data) || Object.keys(data).length !== 2 || !Array.isArray(data.items) || data.items.length > 20
    || !data.items.every(isTask) || !(data.nextCursor === null || validId(data.nextCursor))
    || new Set(data.items.map(item => item.id)).size !== data.items.length) throw new DomainError('PROTOCOL');
  const rows = data.items as TaskDTO[];
  if (rows.some((item,index) => index > 0 && item.id <= rows[index - 1]!.id)
    || (data.nextCursor !== null && (!rows.length || rows[rows.length - 1]!.id !== data.nextCursor))) throw new DomainError('PROTOCOL');
  return { items: rows.map(item => ({ ...item })), nextCursor: data.nextCursor };
}

function digest() {
  const files = [];
  function walk(dir) {
    for (const item of fs.readdirSync(dir,{withFileTypes:true})) {
      if (['node_modules','reports','.git','__pycache__'].includes(item.name)) continue;
      const file = path.join(dir,item.name);
      if (item.isDirectory()) walk(file);
      else if (/\.(?:ts|js|cjs|json)$/.test(item.name)) files.push(file);
    }
  }
  walk(ROOT); const hash = crypto.createHash('sha256');
  for (const file of files.sort()) hash.update(path.relative(ROOT,file).split(path.sep).join('/')+'\0').update(fs.readFileSync(file));
  return hash.digest('hex');
}

## 4 怎样判断网上教程是否过时

1. 看日期，还要看它调用的 API 是否已废弃；日期新不等于内容新。
2. 看是否把浏览器 DOM、localStorage、网页 fetch 直接搬到原生小程序。
3. 看是否把用户名、昵称或用户传入的 ownerId 当作可信身份。

7. 看示例是否具备完整路径、配置与前提；“复制到项目即可”往往省略关键环境。

# 微信小程序从零开发教程

适合第一次接触编程的学习者。编写日期：2026 年 10 月 28 日。路线：原生微信小程序，JavaScript → WXML → WXSS → 页面与组件 → 网络与云开发 → 综合项目。

这是一套分批完成的课程。**总规划及第 01—36 章正文已全部完成，附十七组代码示例、分阶段练习答案与最终综合实践。真实微信/云/数据治理/审核发布仍按验收表完成，不把教材齐备当作已上线。** 第一批编写于 2026-10-28，第二、三批续写于 2026-10-31，第四批续写于 2026-11-01，第五至十二批完成于 2026-11-02，第十三至十六批完成于 2026-11-03。请按顺序学习，不需要提前安装一整套前端框架。

## 从哪里开始

1. 先读 [00 整体规划](00-整体规划与最终项目.md)，知道每阶段做什么、怎样验收。
2. 从 [01 环境与第一个小程序](01-环境准备与第一个小程序.md) 开始动手。
3. 每章按“读概念 → 手敲例子 → 运行核对 → 改需求 → 做练习”的顺序学习。
4. 第 08 章结束时，运行 `示例代码/02-study-board`，做出第一个可持久保存数据的作品。
5. 遇到问题先查第 09 章，再把报错原文、文件名、操作步骤带回对话讨论。

## 你接下来可以怎么学

建议一开始每天花 60—90 分钟，学完一个小节就运行一次。不要以“看完多少页”判断进度；能从空文件写出例子、改变需求、解释结果，才算掌握。

36章主线已经齐备。建议按最终综合实践完成自己的作品，保留各阶段版本对照；后续围绕一个具体需求选TS、组件库、框架、独立后端或平台专题继续学习。

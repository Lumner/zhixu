`验证/verify-stats.cjs` 通过 60 个新增场景，另在 09 项目执行 verify-sync.cjs 的 52 个基础、verify-knowledge.cjs 的 56 个知识库与 verify-focus.cjs 的 71 个计时继承场景，合计 239 个。使用可控服务器/本地时钟、提交前/后故障的内存事务、文件存储桩与微信 API 桩，不访问云账号、不安装真实 SDK。事务模型采用串行隔离，不能替代真实数据库的并发、锁冲突与权限测试。

Canvas 测试核对几何坐标、调用顺序、节点查询、DPR、生命周期和回退，使用调用桩，未执行微信原生绘图。另通过实际 draw 函数导出指令，用带 Pillow 的 Python 重放为两个布局预览并目视核对有数据和零数据布局；预览明确标为非微信截图，不能证明真实字体、设备或基础库渲染已验收。主教程与业务测试不依赖 Pillow。

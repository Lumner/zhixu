# 19 计数器与时钟使能节拍

本章目标：设计模 N 计数器和单拍节拍，处理 N=1 与差一错误。预计 3 小时。

## 19.1 模 N 计数器

模 N 计数器顺序为 0、1、…、N−1、0。N=10 不是数到 10 再清零，否则周期会是 11 拍。位宽取能容纳 N−1 的最小值，N=1 时仍至少声明一位。

`08-tick` 的参数 DIV≥1，en=1 时计数，计到 DIV−1 就清零；en=0 时保持。tick 定义为“当前计数为 DIV−1 且 en=1 且不在复位”。它是供下一个上升沿使用的使能条件，不是新时钟。

## 19.2 组合终值使能

```systemverilog
// tick_gen模块内部片段
assign tick = en && !rst && (count == DIV-1);
always_ff @(posedge clk) begin
  if (rst) count <= '0;
  else if (en) begin
    if (tick) count <= '0;
    else count <= count + 1'b1;
  end
end
```

消费者仍在 `posedge clk` 中 `if(tick)` 更新。tick 在计数达到终值的周期为高，在下一上升沿消费，这使周期合同清楚。若改为寄存器输出 tick，消费者会读取旧 tick，需要重新计算流水延迟。

## 19.3 频率换算

假设时钟 50MHz，每秒 50000000 个上升沿；DIV=50000000 得一秒使能。需要 26 位计数器，因为 2^25 不够容纳 49999999。仿真用 DIV=4 或更小加速，但测试结构与真实参数保持一致。

DIV=1 时每个有效周期 tick 都为 1，这表示每拍都使能，不能要求高低交替。若需要一半占空比的方波，那是另一种输出合同。

## 19.4 暂停的含义

en=0 时保持计数，重新使能后从上次位置继续；若要每次启动都从完整间隔开始，应在启动时清零。两种方案都合理，需要规格明确。最终计时器采用暂停保留部分秒、清零才丢弃部分秒。

## 19.5 实验与答案

`08-tick` 检查 DIV=1 和 DIV=4。练习：DIV=4，从复位后的 count=0 开始，连续 en=1，第几次上升沿消费 tick？答案：第 4 次。验收：列出 0、1、2、3、0 的沿前沿后表，检查暂停不丢位置。

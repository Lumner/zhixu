# 同步消抖与单拍事件

对应示例 `14-button`。先阅读主线相关章节，再运行本目录。

## 电路和时间合同

async_in先两级同步，再连续STABLE_CYCLES次采样接受新电平；接受高电平时pressed只高一周期。rst假定已满足本地时钟域。

## 文件分工

[design.sv](design.sv) 是硬件描述，[tb.sv](tb.sv) 是测试平台。测试使用虚拟时间，设计通过寄存器和组合关系表达电路。每组独立编译，不把其他目录的tb加入。

## 自动检查怎样工作

短毛刺不能改变stable，有效长按只产生一次pressed，释放后再次按下再产生一次。仿真不模拟真实模拟亚稳过程。

## 运行与预期

在当前目录打开终端，第一条成功后再执行第二条。预期打印PASS；错误应以非零退出。

```powershell
iverilog -g2012 -s tb -o sim.vvp design.sv tb.sv
vvp sim.vvp
```

也可以回到上一级，用 `run.ps1 -Example 14-button` 运行。波形需要按第12章自行增加dump调用；测试通过与波形文件生成是两件事。

## 练习

测试STABLE_CYCLES=1边界；板上使用前按器件流程设置同步器属性并做CDC检查。

先预测，再修改，再运行；保留一次可解释的失败输入，并说明修复为什么成立。

# 八拍PWM

对应示例 `09-pwm`。先阅读主线相关章节，再运行本目录。

## 电路和时间合同

phase为3位每拍回绕，pwm由phase与4位duty比较。duty0全低，8及以上全高；周期中修改duty立即影响输出。

## 文件分工

[design.sv](design.sv) 是硬件描述，[tb.sv](tb.sv) 是测试平台。测试使用虚拟时间，设计通过寄存器和组合关系表达电路。每组独立编译，不把其他目录的tb加入。

## 自动检查怎样工作

duty0…8各观察完整8拍，统计高拍数。测试不依赖从哪一个相位开始，只要覆盖完整周期即可。

## 运行与预期

在当前目录打开终端，第一条成功后再执行第二条。预期打印PASS；错误应以非零退出。

```powershell
iverilog -g2012 -s tb -o sim.vvp design.sv tb.sv
vvp sim.vvp
```

也可以回到上一级，用 `run.ps1 -Example 09-pwm` 运行。波形需要按第12章自行增加dump调用；测试通过与波形文件生成是两件事。

## 练习

在周期边界锁存新的duty，比较立即更新与边界更新的波形差异。

先预测，再修改，再运行；保留一次可解释的失败输入，并说明修复为什么成立。

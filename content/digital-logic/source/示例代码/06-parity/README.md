# 参数化奇偶检测

对应示例 `06-parity`。先阅读主线相关章节，再运行本目录。

## 电路和时间合同

WIDTH在展开时固定，合法范围至少1。odd=1表示数据中有奇数个1。WIDTH改变的是硬件信号数量。

## 文件分工

[design.sv](design.sv) 是硬件描述，[tb.sv](tb.sv) 是测试平台。测试使用虚拟时间，设计通过寄存器和组合关系表达电路。每组独立编译，不把其他目录的tb加入。

## 自动检查怎样工作

同一测试放入WIDTH=1、8两个实例，对256个字节用整数计数模型比较。

## 运行与预期

在当前目录打开终端，第一条成功后再执行第二条。预期打印PASS；错误应以非零退出。

```powershell
iverilog -g2012 -s tb -o sim.vvp design.sv tb.sv
vvp sim.vvp
```

也可以回到上一级，用 `run.ps1 -Example 06-parity` 运行。波形需要按第12章自行增加dump调用；测试通过与波形文件生成是两件事。

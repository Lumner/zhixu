# 同步四项FIFO

对应示例 `12-fifo`。先阅读主线相关章节，再运行本目录。

## 电路和时间合同

宽8、深4，按沿前empty/full决定是否接受。空时同时读写只写，满时同时读写只读；成功读取后dout更新并保持。

## 文件分工

[design.sv](design.sv) 是硬件描述，[tb.sv](tb.sv) 是测试平台。测试使用虚拟时间，设计通过寄存器和组合关系表达电路。每组独立编译，不把其他目录的tb加入。

## 自动检查怎样工作

参考模型用移位数组保存逻辑队列，结构独立于环形指针。111拍覆盖空满拒绝、内部同时读写、回绕、复位和数据顺序。

## 运行与预期

在当前目录打开终端，第一条成功后再执行第二条。预期打印PASS；错误应以非零退出。

```powershell
iverilog -g2012 -s tb -o sim.vvp design.sv tb.sv
vvp sim.vvp
```

也可以回到上一级，用 `run.ps1 -Example 12-fifo` 运行。波形需要按第12章自行增加dump调用；测试通过与波形文件生成是两件事。

## 练习

增加accepted_write/accepted_read输出，让调用方明确知道请求是否成功；不要暗改成FWFT。

先预测，再修改，再运行；保留一次可解释的失败输入，并说明修复为什么成立。

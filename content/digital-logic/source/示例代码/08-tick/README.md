# 节拍使能发生器

对应示例 `08-tick`。先阅读主线相关章节，再运行本目录。

## 电路和时间合同

DIV≥1，en有效时计数；count为DIV−1时tick高，消费者在接下来的共同上升沿使用它。en=0保存部分周期。

## 文件分工

[design.sv](design.sv) 是硬件描述，[tb.sv](tb.sv) 是测试平台。测试使用虚拟时间，设计通过寄存器和组合关系表达电路。每组独立编译，不把其他目录的tb加入。

## 自动检查怎样工作

DIV=1/4两个实例连续40拍检查，包括暂停和中途复位；在沿前检查tick，避免误读更新后的下一周期。

## 运行与预期

在当前目录打开终端，第一条成功后再执行第二条。预期打印PASS；错误应以非零退出。

```powershell
iverilog -g2012 -s tb -o sim.vvp design.sv tb.sv
vvp sim.vvp
```

也可以回到上一级，用 `run.ps1 -Example 08-tick` 运行。波形需要按第12章自行增加dump调用；测试通过与波形文件生成是两件事。

## 练习

加入restart输入，定义它与rst/en冲突的优先级，再测试中途重启。

先预测，再修改，再运行；保留一次可解释的失败输入，并说明修复为什么成立。

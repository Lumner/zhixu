# 第一个逻辑门实验

对应示例 `01-gates`。先阅读主线相关章节，再运行本目录。

## 电路和时间合同

输入a、b均为一位，输出y_and与y_xor分别表示与、异或。两个assign持续存在，输入变化时组合结果重新计算，不使用时钟。

## 文件分工

[design.sv](design.sv) 是硬件描述，[tb.sv](tb.sv) 是测试平台。测试使用虚拟时间，设计通过寄存器和组合关系表达电路。每组独立编译，不把其他目录的tb加入。

## 自动检查怎样工作

测试依次输入00、01、10、11，每次等待1ns再比较。把与门故意改为或门，01就会失败。

## 运行与预期

在当前目录打开终端，第一条成功后再执行第二条。预期打印PASS；错误应以非零退出。

```powershell
iverilog -g2012 -s tb -o sim.vvp design.sv tb.sv
vvp sim.vvp
```

也可以回到上一级，用 `run.ps1 -Example 01-gates` 运行。波形需要按第12章自行增加dump调用；测试通过与波形文件生成是两件事。

## 练习

增加或门输出，并在每个输入组合检查它。

先预测，再修改，再运行；保留一次可解释的失败输入，并说明修复为什么成立。

# 可启动暂停清零计时器

对应示例 `15-timer`。先阅读主线相关章节，再运行本目录。

## 电路和时间合同

控制为同步高有效单拍。clear/rst最高，toggle次之且该沿不推进时间；暂停保留部分秒，seconds从0到59循环。

## 文件分工

[design.sv](design.sv) 是硬件描述，[tb.sv](tb.sv) 是测试平台。测试使用虚拟时间，设计通过寄存器和组合关系表达电路。每组独立编译，不把其他目录的tb加入。

## 自动检查怎样工作

参数1和3使用累计有效拍数参考模型，226拍覆盖暂停恢复、优先级、复位和两种参数59→0。

## 运行与预期

在当前目录打开终端，第一条成功后再执行第二条。预期打印PASS；错误应以非零退出。

```powershell
iverilog -g2012 -s tb -o sim.vvp design.sv tb.sv
vvp sim.vvp
```

也可以回到上一级，用 `run.ps1 -Example 15-timer` 运行。波形需要按第12章自行增加dump调用；测试通过与波形文件生成是两件事。

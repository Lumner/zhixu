# 二选一组合电路

对应示例 `03-mux`。先阅读主线相关章节，再运行本目录。

## 电路和时间合同

a、b各4位，sel=0取a，sel=1取b。always_comb每条分支都给y赋值，因此不保存过去的值。

## 文件分工

[design.sv](design.sv) 是硬件描述，[tb.sv](tb.sv) 是测试平台。测试使用虚拟时间，设计通过寄存器和组合关系表达电路。每组独立编译，不把其他目录的tb加入。

## 自动检查怎样工作

16×16×2共512组输入，逐组检查。删除else后测试会在跨输入序列时发现保持旧值的问题。

## 运行与预期

在当前目录打开终端，第一条成功后再执行第二条。预期打印PASS；错误应以非零退出。

```powershell
iverilog -g2012 -s tb -o sim.vvp design.sv tb.sv
vvp sim.vvp
```

也可以回到上一级，用 `run.ps1 -Example 03-mux` 运行。波形需要按第12章自行增加dump调用；测试通过与波形文件生成是两件事。

## 练习

加入高有效clear，clear优先于选择，输出全零；同时增加clear=0/1的检查。

先预测，再修改，再运行；保留一次可解释的失败输入，并说明修复为什么成立。

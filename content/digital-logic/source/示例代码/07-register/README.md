# 同步寄存器

对应示例 `07-register`。先阅读主线相关章节，再运行本目录。

## 电路和时间合同

clk上升沿采样。rst高有效同步且优先，en=1加载d，否则q保持；数据8位。

## 文件分工

[design.sv](design.sv) 是硬件描述，[tb.sv](tb.sv) 是测试平台。测试使用虚拟时间，设计通过寄存器和组合关系表达电路。每组独立编译，不把其他目录的tb加入。

## 自动检查怎样工作

检查复位与使能同时为1、正常加载、禁止加载、仅在两沿之间出现的复位脉冲。

## 运行与预期

在当前目录打开终端，第一条成功后再执行第二条。预期打印PASS；错误应以非零退出。

```powershell
iverilog -g2012 -s tb -o sim.vvp design.sv tb.sv
vvp sim.vvp
```

也可以回到上一级，用 `run.ps1 -Example 07-register` 运行。波形需要按第12章自行增加dump调用；测试通过与波形文件生成是两件事。

## 练习

加两级流水，证明第二级使用前一拍第一级的值，画出沿前沿后表。

先预测，再修改，再运行；保留一次可解释的失败输入，并说明修复为什么成立。

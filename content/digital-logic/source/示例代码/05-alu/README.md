# 算术逻辑单元

对应示例 `05-alu`。先阅读主线相关章节，再运行本目录。

## 电路和时间合同

4位a/b，op00加、01减、10与、11异或。宽结果5位保存进位；减法carry为无借位；overflow表示补码结果超出范围。

## 文件分工

[design.sv](design.sv) 是硬件描述，[tb.sv](tb.sv) 是测试平台。测试使用虚拟时间，设计通过寄存器和组合关系表达电路。每组独立编译，不把其他目录的tb加入。

## 自动检查怎样工作

1024组输入检查y、carry、overflow、zero。测试把4位输入转成整数−8…7，再根据数学结果判断溢出。

## 运行与预期

在当前目录打开终端，第一条成功后再执行第二条。预期打印PASS；错误应以非零退出。

```powershell
iverilog -g2012 -s tb -o sim.vvp design.sv tb.sv
vvp sim.vvp
```

也可以回到上一级，用 `run.ps1 -Example 05-alu` 运行。波形需要按第12章自行增加dump调用；测试通过与波形文件生成是两件事。

## 练习

增加一种操作前先扩操作码、更新接口表和全部实例，不只在case中追加一行。

先预测，再修改，再运行；保留一次可解释的失败输入，并说明修复为什么成立。

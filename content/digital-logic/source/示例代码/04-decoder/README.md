# 译码与使能

对应示例 `04-decoder`。先阅读主线相关章节，再运行本目录。

## 电路和时间合同

en有效时，sel=0/1/2/3分别使y的第0/1/2/3位为1；en=0输出0000。默认赋值覆盖禁用情形。

## 文件分工

[design.sv](design.sv) 是硬件描述，[tb.sv](tb.sv) 是测试平台。测试使用虚拟时间，设计通过寄存器和组合关系表达电路。每组独立编译，不把其他目录的tb加入。

## 自动检查怎样工作

测试覆盖8种输入，整数1左移sel得到独立预期。注意输出位编号从最低位0开始。

## 运行与预期

在当前目录打开终端，第一条成功后再执行第二条。预期打印PASS；错误应以非零退出。

```powershell
iverilog -g2012 -s tb -o sim.vvp design.sv tb.sv
vvp sim.vvp
```

也可以回到上一级，用 `run.ps1 -Example 04-decoder` 运行。波形需要按第12章自行增加dump调用；测试通过与波形文件生成是两件事。

## 练习

把输出改成低有效，再明确禁用时应全1，并同步修改参考模型。

先预测，再修改，再运行；保留一次可解释的失败输入，并说明修复为什么成立。

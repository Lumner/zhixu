# 两状态控制器

对应示例 `11-fsm`。先阅读主线相关章节，再运行本目录。

## 电路和时间合同

复位RED，advance每次有效使RED/GREEN切换，输出只依赖当前状态，属于Moore型。state保存，next组合计算。

## 文件分工

[design.sv](design.sv) 是硬件描述，[tb.sv](tb.sv) 是测试平台。测试使用虚拟时间，设计通过寄存器和组合关系表达电路。每组独立编译，不把其他目录的tb加入。

## 自动检查怎样工作

24拍覆盖保持、转换和中途复位；每次还验证red/green相反，避免双亮。

## 运行与预期

在当前目录打开终端，第一条成功后再执行第二条。预期打印PASS；错误应以非零退出。

```powershell
iverilog -g2012 -s tb -o sim.vvp design.sv tb.sv
vvp sim.vvp
```

也可以回到上一级，用 `run.ps1 -Example 11-fsm` 运行。波形需要按第12章自行增加dump调用；测试通过与波形文件生成是两件事。

## 练习

加入YELLOW并画完整状态表，别忘了输出译码和新增状态覆盖。

先预测，再修改，再运行；保留一次可解释的失败输入，并说明修复为什么成立。

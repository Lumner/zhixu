# SystemVerilog 示例代码总览

详细版第07–12章新增了[六组语言入门实验](../语言实验/README.md)，第13–16章新增[四组组合实验](../组合实验/README.md)，建议零基础读者按正文学习。下面保留原有15组工程示例，三类共25组，运行目录、接口与测试分别独立。

每组是独立实验：`design.sv` 是设计，`tb.sv` 是自动检查。请先学第 07 章。所有时间延时均在测试平台中，设计使用常见可综合 RTL 子集。

## 运行一个实验

进入相应目录后运行；仅在第一条成功时运行第二条：

```powershell
iverilog -g2012 -s tb -o sim.vvp design.sv tb.sv
vvp sim.vvp
```

在本总览所在目录，也可运行：

```powershell
.\run.ps1 -Example 05-alu
.\run.ps1 -Example all
```

脚本需要终端能找到 iverilog/vvp，也可用 `-Iverilog` 和 `-Vvp` 指定各自可执行文件绝对路径。若系统执行策略阻止脚本，使用直接命令即可，不要求修改机器策略。

## 文件下载

完整课程 ZIP 内保留全部源码及测试。网页也可直接下载单文件，例如 [ALU 设计](05-alu/design.sv)、[ALU 测试](05-alu/tb.sv)、[计时器设计](15-timer/design.sv)、[计时器测试](15-timer/tb.sv)、[运行脚本](run.ps1)。

不要把不同实验的 tb 一起编译；每次只编译当前目录。仿真产物不作为教材源码，重新打包时排除 `.build` 与 `.vvp/.vcd` 文件。

## 验证范围

测试是教学用的确定性功能验证，不是商用 IP 认证。CDC 的真实亚稳态、具体 FPGA RAM 推断、布局布线时序和板级电气需要另行验证。实际执行情况见[验证记录](../验证/示例验证记录.md)。

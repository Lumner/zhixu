# 8N1串口发送

对应示例 `13-uart`。先阅读主线相关章节，再运行本目录。

## 电路和时间合同

start在空闲上升沿被接受并锁存data，忙时请求忽略。起始0、低位先发、停止1；每位持续CLKS_PER_BIT拍。

## 文件分工

[design.sv](design.sv) 是硬件描述，[tb.sv](tb.sv) 是测试平台。测试使用虚拟时间，设计通过寄存器和组合关系表达电路。每组独立编译，不把其他目录的tb加入。

## 自动检查怎样工作

对00/FF/A5逐位中心采样，同时改变外部data、在忙中注入start、在发送中复位，确认合同。

## 运行与预期

在当前目录打开终端，第一条成功后再执行第二条。预期打印PASS；错误应以非零退出。

```powershell
iverilog -g2012 -s tb -o sim.vvp design.sv tb.sv
vvp sim.vvp
```

也可以回到上一级，用 `run.ps1 -Example 13-uart` 运行。波形需要按第12章自行增加dump调用；测试通过与波形文件生成是两件事。

## 练习

增加发送完成单拍done，明确它在停止位结束的哪一沿输出，并增加相应检查。

先预测，再修改，再运行；保留一次可解释的失败输入，并说明修复为什么成立。

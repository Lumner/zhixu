# 位向量与奇偶实验

对应示例 `02-bits`。先阅读主线相关章节，再运行本目录。

## 电路和时间合同

data是8位无符号向量，swapped将低四位放在高端、高四位放在低端；odd归约异或统计1的个数奇偶。

## 文件分工

[design.sv](design.sv) 是硬件描述，[tb.sv](tb.sv) 是测试平台。测试使用虚拟时间，设计通过寄存器和组合关系表达电路。每组独立编译，不把其他目录的tb加入。

## 自动检查怎样工作

测试枚举256个值，使用整数除法和余数算交换结果，用循环计数1而不是照抄归约表达式。

## 运行与预期

在当前目录打开终端，第一条成功后再执行第二条。预期打印PASS；错误应以非零退出。

```powershell
iverilog -g2012 -s tb -o sim.vvp design.sv tb.sv
vvp sim.vvp
```

也可以回到上一级，用 `run.ps1 -Example 02-bits` 运行。波形需要按第12章自行增加dump调用；测试通过与波形文件生成是两件事。

## 练习

输入3C时先预测C3；再改成逐位反转，不能把它与半字节交换混淆。

先预测，再修改，再运行；保留一次可解释的失败输入，并说明修复为什么成立。

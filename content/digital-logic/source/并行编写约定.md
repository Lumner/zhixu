# 数字逻辑课程并行编写约定

课程 ID 固定为 digital-logic，所属领域 systems；主线 01–32，阶段范围由 course.json 维护。主线顺序是先概念、再语言、再组合与时序、再控制与工程，不要求零基础读者预先会其他编程语言。

## 内容合同

### 详细版重写的当前合同

本课正按读者反馈逐阶段重写，已完成01–16章，其余17–32仍是原简版。最新范围以[重写进度](详细版重写进度.md)为准，不以文件存在或示例代码通过推断文字已经完成详细重写。

每个新术语先定义再使用；每个关键公式解释来源；典型例题写完整中间步骤并反向验算；习题答案给过程和常见错误原因。语言阶段必须从文件、编辑器、终端和符号开始，逐行解释完整代码，不能只链接源码代替讲解。生活类比写清适用范围，不把类比当作真实电气实现。

每批同时更新导览、正文、练习和进度，代码有变动再重新运行受影响的仿真。每位作者只接手分配的批次，不把待写章节批量标为完成。

每章先说明目标、先修和预计时间，再讲概念、推导和例子，最后练习、答案与验收。第一次出现英文缩写给中文解释。代码要明确“完整文件”或“模块内部片段”，引用的标识符必须能找到定义。示例不要只给代码而不解释位宽、极性、时钟与更新时刻。

术语采用“组合逻辑、时序逻辑、上升沿、阻塞/非阻塞、同步复位、使能、补码溢出”。SystemVerilog RTL 使用 logic、always_comb、always_ff、具名端口；组合用 =，时序用 <=；单信号单驱动。测试允许 initial、延时、打印和 finish，设计不依赖仿真时间等待。

## 示例接口合同

| 示例 | 固定语义 |
| --- | --- |
| ALU | 4位a/b，op00加、01减、10与、11异或；减法carry为无借位 |
| 组合实验16的扩展ALU | 新目录与新模块；3位op，000加、001减、010与、011异或、100或；101/110/111输出y/C/V=0、Z=1、valid=0；不改变旧ALU合同 |
| 寄存器 | rst高有效同步，rst优先于en |
| 节拍 | DIV≥1，tick为沿前终值使能；en=0保持计数 |
| PWM | 周期8拍，duty0…8，≥8全高 |
| RAM | 16×8，同步读取，同址读写返回旧值，未写内容不保证零 |
| FIFO | 深度4、宽8、单时钟、非FWFT；按沿前空满拒绝请求 |
| UART | 8N1、低位先发，忙时请求忽略，接受时锁存data |
| 按键 | 先两级同步后连续稳定计数，高有效，按下输出单拍 |
| 计时器 | 0…59循环；清零高于切换；切换沿不计时；暂停保留部分秒 |

## 扩写边界

增加新例子时使用新目录，不覆盖既有例子；跨章引用使用相对 Markdown 链接。添加章节须同步阶段、导览、真实数量和参考链接。不要复制编译输出到 source。source 之外的 drafts 是草稿区域，网站不会读取。

每位编写者写清自己实际运行的命令与结果，不能把其他人的“计划运行”当作通过。运行错误时优先保存失败输入、定位原因，修正后再更新验证记录。具体 FPGA 时钟、电压、引脚与时序只在有板卡依据和实际报告时声明完成。

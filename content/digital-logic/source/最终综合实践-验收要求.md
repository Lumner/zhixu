# 最终综合实践：验收要求

## 任务

独立完成第30章计时器规格，并选择一项扩展：倒计时、预置时间、串口输出或显示适配。基础核心必须先通过，再加入扩展。基础代码见[计时器设计](示例代码/15-timer/design.sv)与[测试](示例代码/15-timer/tb.sv)。

## 必交材料

| 材料 | 内容 |
| --- | --- |
| 一页规格 | 端口、位宽、极性、时钟域、优先级、暂停语义、范围与回绕 |
| RTL | 单一时钟、可解释状态、无多驱动、参数合法范围 |
| 测试 | 参考模型、自动失败、超时、关键边界和参数1 |
| 复现说明 | 工具版本、顶层、命令、文件顺序和实际结果 |
| 故障记录 | 一个真实或注入错误、失败输入、定位和修正证据 |
| 扩展说明 | 新需求、新边界、修改的接口和新增测试 |

## 基础通过标准

复位清零停止，启动/暂停切换正确，暂停保留部分秒，clear高于toggle，参数1与一般参数都正确，59→0正确。故意改终值或优先级时测试必须失败。没有板卡可以完成全部核心验收。

## 板级加分项

若使用开发板，再补真实板型、引脚/电压来源、时钟约束、综合资源、实现时序与板上演示记录。任何尚未执行项目明确写未验证，不用照片或“生成配置文件”代替时序证据。

## 自我评价

能运行原例是起点；能修改后验证是进步；能从需求写规格、设计与独立测试，并向别人解释每个时钟沿，才达到本课完整目标。

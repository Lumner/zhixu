# 99 术语与 SystemVerilog 语法速查

本页用于回查，按主线学习时不需要一次记完。

## 数字逻辑术语

| 名称 | 含义 | 回看章节 |
| --- | --- | --- |
| bit / byte | 比特/8位字节 | 01 |
| MSB / LSB | 最高/最低有效位 | 02 |
| 补码 | 有符号整数编码，最高位负权重 | 03 |
| carry / overflow | 无符号进位/补码溢出 | 03、14 |
| combinational | 输出只依赖当前输入的组合逻辑 | 04–06 |
| sequential | 带状态的时序逻辑 | 17 |
| MUX / decoder | 选择器/译码器 | 13 |
| RTL | 寄存器传输级描述 | 17、27 |
| FSM | 有限状态机 | 22 |
| latency / throughput | 延迟/吞吐量 | 23 |
| FIFO | 先进先出缓冲 | 24 |
| UART | 通用异步收发传输，本课实现发送端 | 25 |
| CDC | 跨时钟域处理 | 26 |
| setup / hold | 建立/保持时间要求 | 28 |
| DUT / testbench | 被测设计/测试平台 | 12 |

## 声明和赋值

```systemverilog
// 放在模块中的声明与组合片段
logic [7:0] data;
logic signed [7:0] temperature;
logic [7:0] mem[0:15];
logic odd;
assign odd = ^data;
```

logic不自动意味着寄存器。assign是持续关系，always_comb是组合过程，always_ff描述触发器更新。组合块每条路径赋值，时序块没赋值表示保持。

## 运算符

| 写法 | 作用 |
| --- | --- |
| a & b / a \| b / a ^ b | 逐位与/或/异或 |
| !a / a && b / a \|\| b | 逻辑非/与/或 |
| &a / \|a / ^a | 归约为一位 |
| == / != | 可能返回X的相等比较 |
| === / !== | 含X/Z的确定比较，常用于测试 |
| {a,b} / {4{a}} | 拼接/重复 |
| << / >> / >>> | 左移/逻辑右移/取决于signed的算术右移 |
| = / <= | 阻塞赋值/非阻塞赋值，注意上下文 |

## 常用实验命令

```powershell
iverilog -g2012 -s tb -o sim.vvp design.sv tb.sv
vvp sim.vvp
```

编译成功才运行。`-g2012`指定语言模式，`-s`指定顶层，`-o`指定产物。网页的npm build只生成教材页面，不替代HDL仿真。

## 五项排错顺序

先看第一条编译错误；再核对文件路径与模块名；再检查位宽和符号；再看复位、使能与采样沿；最后用最小失败序列定位。不要一次改多处直到“好像能跑”。

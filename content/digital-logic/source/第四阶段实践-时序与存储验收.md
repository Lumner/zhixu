# 第四阶段实践：时序与存储验收

本实践对应第17–21章，建议在五章实验后另用1–2小时整理证据。目标是让另一个人拿到文件与记录，就能知道状态在哪个沿变化、什么没有验证。完整文件入口见[时序实验总览](时序实验/README.md)。

## 1. 先在纸上预测

为两级流水列七行输入/rst/旧q1/旧q2/新q1/新q2；画15、25ns采样沿与17…19ns复位脉冲；为DIV=4写出暂停在2、3两处的计数表；画duty=3的八格PWM；为RAM的22→C3同址写入画两个有效沿。

预测先于运行，不要看到波形后才补出一份与它完全相同的“预期”。答错时保留第一处差异，解释是读错合同、漏沿、混淆旧值，还是代码错误。

## 2. 分目录运行五组程序

按第7章准备工具。分别进入17-pipeline、18-reset、19-tick、20-shift-pwm、21-memory目录的PowerShell，确认文件后逐条执行：

```powershell
iverilog -g2012 -s tb -o sim.vvp design.sv tb.sv
vvp sim.vvp
```

每次编译成功才运行，不把不同目录同名tb一起编译。21-memory必须带rom.hex，并从该目录运行vvp。保留实际版本、目录、两步退出码和PASS计数，而不是只抄教材预期。

## 3. 对照完整范围

| 实验 | 需要解释的证据 |
| --- | --- |
| 流水 | 七个脚本采样沿、一次沿间保持，pipeline.vcd来源 |
| 复位 | 17个脚本沿检查、短脉冲/释放/禁用保持三项 |
| 节拍 | DIV=1/4/5，各25周期；沿前tick与沿后消费者 |
| 移位/PWM | 五项移位、16帧、128相位、两次实时改duty |
| 存储 | 14次访问、ROM四行文件、未知内容、读旧值和沿间保持 |

## 4. 让错误版本确实失败

在另复制的实验目录中选一项：流水两句改阻塞；同步复位误改异步；暂停清零；PWM比较用<=；RAM误改write-first。一次只改一种，重新编译运行，保存首个失败输入或时刻，并写出实际/预期区别。

恢复正确版后重新编译通过。错误副本和记录另存，不覆盖教材源码。维护者完整九项故障结果见[第四阶段验证记录](验证/第四阶段详细重写验证记录.md)，不替代学习者自己的实际运行。

## 5. 写清限制

本阶段验证为理想RTL功能与有限输入序列，时钟和复位来自测试激励。记录是否实际打开GTKWave；生成VCD、解析VCD与操作GUI分别写。器件综合、静态时序、亚稳态/复位释放物理风险、真实PWM负载与上板都没有由这些PASS自动完成。

## 6. 独立改造的参考方向

可以把移位改成四位右移，或者给PWM增加边界装载duty。先写新位来源或更新时刻，再改预期与测试。配套发布的仍是原左移、实时PWM、read-first RAM；改造方案只是练习方向，尚未计入实测例程。

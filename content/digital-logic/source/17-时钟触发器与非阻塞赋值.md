# 17 时钟、触发器与非阻塞赋值

本章目标：建立“沿前计算、沿后更新”的状态模型，掌握 always_ff 与非阻塞赋值。预计 3–4 小时。

## 17.1 D 触发器

D 触发器在时钟有效边沿采样输入 d，更新输出 q，其余时间保持。`posedge clk` 是上升沿。理想模型先忽略实际建立、保持时间；第 28 章再讨论这些约束。

时钟不是普通“运行开关”，而是给许多寄存器共同提供采样时刻。数据需要在规定时间内稳定。电路在时钟沿之间仍进行组合计算。

## 17.2 带复位和使能的完整寄存器

```systemverilog
module data_reg(input logic clk, rst, en,
                input logic [7:0] d, output logic [7:0] q);
  always_ff @(posedge clk) begin
    if (rst) q <= 8'b0;
    else if (en) q <= d;
  end
endmodule
```

rst 高有效且同步，只有上升沿才清零；en=0 时保持 q。这里省略 else 是有意保存状态，符合触发器语义；组合块漏 else 则可能推断锁存器，场景不同。

## 17.3 为什么使用 <=

非阻塞赋值在当前沿先计算右值，稍后统一提交左值。假设 `q1<=d; q2<=q1;`，q2 得到沿前的 q1，形成两级流水。交换两行不改变这个结果。

若在时序过程中用阻塞赋值 `q1=d; q2=q1;`，第二句可能使用刚更新的 q1，仿真行为不再代表预期的两级采样。主线规则：组合计算用 `=`，寄存器更新用 `<=`。

| 沿 | 沿前 d | 沿前 q1 | 沿后 q1 | 沿后 q2 |
| --- | --- | --- | --- | --- |
| 第1沿 | A | 0 | A | 0 |
| 第2沿 | B | A | B | A |
| 第3沿 | C | B | C | B |

## 17.4 测试时钟

测试平台常写 `logic clk=0; always #5 clk=~clk;`，周期 10ns。此处 always 是仿真激励，不把它综合成板上时钟。驱动输入放在下降沿，采样放在下一上升沿后 `#1`。

## 17.5 实验与答案

`07-register` 检查复位、加载、禁止加载时保持，以及复位与使能同时有效时的优先级。练习：上例 en=0 且 d 不断变化，q 是否变化？答案：保持；若 rst=1，在下一上升沿清零。验收：画出三拍流水表，区分当前状态与下一状态。

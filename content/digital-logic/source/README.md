# 数字逻辑与 SystemVerilog 教程

课程正在逐阶段详细重写：**第01–25章详解与前五阶段过程习题已完成，题数分别为20、24、24、30、32；第26–32章目前仍为原简版，待重写。** 全课保留32章、7阶段、原15组工程、6组语言、4组组合、5组时序与4组控制通信实验，共34组。请先从[课程框架](00-课程框架与学习方法.md)和[重写进度](详细版重写进度.md)开始。

第一阶段从信号、位权与逻辑含义逐步讲起，只需纸笔。第二阶段从保存文件与打开终端开始，逐行解释代码，并学习独立参考模型和VCD；不要求购买开发板。新增语言实验见source/语言实验。

第三阶段从选择、译码和编码进入算术电路、参数化与独立验证，补充逐位进位表、标志推导、参数边界和故障日志。正文包含完整实测程序；[组合实验](组合实验/README.md)与[扩展ALU实践](第三阶段实践-扩展ALU验收.md)可独立运行。

第四阶段以旧值/新值逐沿表讲解流水、复位、计数、移位、PWM与同步RAM；补充ROM初始化附件、五组[时序实验](时序实验/README.md)、30题答案与[阶段实践](第四阶段实践-时序与存储验收.md)。有限序列已实际仿真，板级结果另按真实证据记录。

第五阶段从状态表进入握手和缓冲，再讲FIFO边界与UART位时间；提供四组[控制通信实验](控制通信实验/README.md)、32题过程答案与[验收实践](第五阶段实践-控制与通信验收.md)。分别记录成功、拒绝、丢弃、剩余和完整/中止帧，不以“提出过请求”代替“已经完成”。

解压后示例位于source/示例代码，运行方式见该目录README。网页阅读请打开知识库根目录index.html；本目录是教材源文件。

本课交付RTL功能教学；具体工具的实际执行情况见验证资料，具体开发板综合、时序、引脚与板上实验需另行完成。

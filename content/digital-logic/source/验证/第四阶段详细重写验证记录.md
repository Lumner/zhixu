## 九项故障注入

错误只写入缓存副本，正式源文件保持正确。九个副本均编译成功，在运行中触发FATAL并非零退出。

| 错误 | 首个失败的关键行为 |
| --- | --- |
| 流水else两句改阻塞 | 输入A后实际A/A，预期A/0 |
| 同步复位块误加rst事件 | 18ns同步输出错误清零，预期保留A |
| en优先于同步rst/clear | 控制011时实际5，预期0 |
| tick终值写成DIV | DIV=1第一个非复位周期缺少节拍 |
| 暂停把count清零 | i=3应保持2，实际0 |
| 移位方向反向 | 第一笔1后实际1000，预期0001 |
| PWM比较改<= | duty=0、phase=0错误为高 |
| RAM改write-first | 首次写20时实际20，预期旧X |
| RAM擅自初始全零 | 首次未写读实际00，预期模型X |

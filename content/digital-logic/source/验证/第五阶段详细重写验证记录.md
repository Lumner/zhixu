## 九项错误副本

以下均先编译成功，再在仿真中FATAL并非零退出。正确源码保留正确实现，错误只存在项目缓存。

| 修改 | 检出的不一致 |
| --- | --- |
| GREEN跳RED、漏YELLOW | 状态表要求的黄色未进入 |
| in_ready不允许满时同沿替换 | 下游接受旧项时，输入ready错误为0 |
| 更新不受in_ready控制 | 未接受B2覆盖旧A1 |
| FIFO满时允许替换 | 与沿前满拒绝写的合同不同 |
| FIFO空时允许旁路读 | 与空时拒绝读的合同不同 |
| level两条独立加减赋值 | 同进同出数量错误 |
| UART数据位反向 | 非对称字节中心位序不符 |
| UART读取外部data | 接受后的反码污染当前帧 |
| UART进入停止位即清busy | 停止中心本应忙却已空闲 |

## 真实UART波形独立解码

从正常运行产生的uart.vcd解析层次、时间单位与busy上升接受事件。每配置共识别257次接受：前256个内容依次0…255，最后一帧被复位中止。

分别取CPB1与4的00、53、A5、FF，共八帧80个中心，用起始0、数据最低位先发、停止1规则独立重建字节，均相同；各中心busy仍1。第25章图从CPB4的53帧实际符号生成，接受时刻35715ns，图横轴换成相对时间。

机器记录[第五阶段仿真结果.json](第五阶段仿真结果.json)保留编译消息、退出码、日志、真实帧符号与8份SV的SHA256。可重跑[维护脚本](verify-stage5.py)，用法见[实验总览](../控制通信实验/README.md)。测试队列先把队首转成八位，避免本批Icarus对连续队列切片的支持限制。

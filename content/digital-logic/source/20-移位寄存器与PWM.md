## 20.1 移位寄存器

模块内片段 `if(en) q <= {q[6:0],serial_in};` 将旧低七位向高位移动，新输入进入最低位。输入序列 1、0、1 在三拍后形成怎样的数据，取决于移位方向和发送位序，不能只说“按顺序进来”。

连续移出 q[0] 并右移可实现最低位先发；UART 采用数据位最低位先发，第 25 章会使用这个思想。移位寄存器也可用作固定拍数延迟线。

## 20.2 PWM 的定义

脉宽调制在固定周期内调整高电平占比。周期 8 拍，前 3 拍为高、后 5 拍为低，占空比 3/8。它不是改变每拍时钟频率，而是改变输出高电平持续多少拍。

`09-pwm` 使用 3 位相位计数器 phase=0…7，输入 duty 为 4 位，允许 0…8。组合输出 `pwm=!rst && ({1'b0,phase}<duty)`，每拍 phase 加一并自然回绕。

## 20.3 为什么 duty 多一位

3 位 duty 只能表示 0…7，无法表示完整 8/8 的 100% 占空比。4 位可表示 8；本例约定 duty≥8 时一直为高。0 对应全低，8 对应全高，中间值对应高电平拍数。

计数器值只在时钟沿改变，pwm 是其组合比较输出。若 duty 在周期中途改变，高电平长度会立即受影响。要求无中途变化时，应在 phase 回到 0 的边界把新 duty 装入活动寄存器。

## 20.4 不把仿真延时写成硬件时间

板上 PWM 使用时钟加计数器，不在设计里写 `#100 pwm=...`。频率约等于 f_clk/周期拍数。提高分辨率意味着更多相位，若时钟不变，PWM 频率会下降，这是常见权衡。

## 20.5 实验与答案

`09-pwm` 对 duty=0…8，各观察完整 8 拍并统计高拍数。练习：时钟 1MHz、周期 256 拍，PWM 频率是多少？答案：3906.25Hz。验收：实测 0%、中间值、100%，并解释更新 duty 的合同。

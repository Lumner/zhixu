## 二、读取器不是一个魔法模板

把一行看成逐个到来的字符。维护四个状态：`ch`为当前字符，`value`为已接受数字的值，`has_digit`记录有没有数字，`valid`记录这行到目前是否始终合法。

读到非数字，valid置0；读到数字，先算digit，再检查“下一步乘10加digit会不会超上界”；只有仍然合法才更新value。每轮最后再次getchar，这是循环推进的关键。遇到换行或EOF结束，非法或无数字则返回-1，否则返回value。

这里不累计“读了多少个字符”，只记录有没有数字。这样即使一行特别长，也不会为了统计字符数而让另一个int溢出。没有固定长度输入缓冲区，极长输入会花更多时间读取，但不会因写入小数组而溢出。

范围检查的原理：把limit写成 `10 * q + r`，其中`q=limit/10`、`r=limit%10`。新数字合法需要旧value小于q，或者等于q且digit不大于r。若旧value大于q，继续乘10必定超限。

| limit | 旧value | digit | 检查 | 结果 |
| --- | --- | --- | --- | --- |
| 7 | 0 | 7 | 0等于0，7不大于7 | 接受7 |
| 7 | 0 | 8 | 0等于0，8大于7 | 拒绝 |
| 1440 | 143 | 9 | 143小于144 | 接受1439 |
| 1440 | 144 | 0 | 相等且0不大于0 | 接受1440 |
| 1440 | 144 | 1 | 相等且1大于0 | 拒绝，先不做乘加 |
| 1440 | 1440 | 0 | 1440大于144 | 拒绝 |

一旦valid为0，后面的字符即使都是数字，也不会把它改回1。错误消息针对整行，不接受“前面有合法数字”就算成功的输入。前导0合法，空行则由has_digit拒绝。对于本项目的非负limit，value始终在0—limit内。

## 三、完整程序

**完整程序：stats.c。** 与可下载源码一致。声明和定义都在同一文件内，无需头文件拆分。

```c
#include <stdio.h>

#define CAPACITY 7
#define MAX_MINUTES 1440

int read_bounded(int limit);

int main(void)
{
    int minutes[CAPACITY] = {0};
    int count = read_bounded(CAPACITY);
    if (count < 0) {
        puts("invalid count");
        return 1;
    }
    if (count == 0) {
        puts("count=0\nempty");
        return 0;
    }

    for (int i = 0; i < count; i++) {
        int value = read_bounded(MAX_MINUTES);
        if (value < 0) {
            puts("invalid minutes");
            return 1;
        }
        minutes[i] = value;
    }
    int target = read_bounded(MAX_MINUTES);
    if (target < 0) {
        puts("invalid target");
        return 1;
    }

    int total = 0;
    int minimum = minutes[0];
    int maximum = minutes[0];
    int active = 0;
    int first = -1;
    for (int i = 0; i < count; i++) {
        int value = minutes[i];
        total += value;
        if (value < minimum) {
            minimum = value;
        }
        if (value > maximum) {
            maximum = value;
        }
        if (value > 0) {
            active++;
        }
        if (value == target && first == -1) {
            first = i;
        }
    }

    printf("count=%d\ntotal=%d\nmin=%d\nmax=%d\n", count, total, minimum, maximum);
    printf("average=%.2f\nactive=%d\n", (double)total / count, active);
    if (active == 0) {
        puts("active_average=NA");
    } else {
        printf("active_average=%.2f\n", (double)total / active);
    }
    printf("first=%d\n", first);
    return 0;
}

int read_bounded(int limit)
{
    int ch = getchar();
    int value = 0;
    int has_digit = 0;
    int valid = 1;

    while (ch != '\n' && ch != EOF) {
        if (ch < '0' || ch > '9') {
            valid = 0;
        } else {
            int digit = ch - '0';
            has_digit = 1;
            if (value > limit / 10 ||
                (value == limit / 10 && digit > limit % 10)) {
                valid = 0;
            }
            if (valid) {
                value = value * 10 + digit;
            }
        }
        ch = getchar();
    }
    if (!valid || !has_digit) {
        return -1;
    }
    return value;
}
```

## 四、程序的执行顺序和安全边界

main先读count，失败立即结束；count为0则直接输出空结果。正常情况下读count条分钟并保存，之后读取查询目标。只有全部输入合法，才开始打印统计报告，因此不会先显示一半正常结果再发现查询非法。

输入完成后，min与max才能安全取minutes[0]，因为空记录早已返回。循环边界为i<count，而count≤7。每个分钟值≤1440，所以total≤10080，处于标准C所保证的int最小正范围内；本项目无需凭本机int恰好32位才能成立。

全部平均除以count，count已大于0。有学习平均除以active，必须先检查active是否为0；NA表示该平均值没有适用数据，不把它伪装成0.00。first保留第一个位置，-1不会与合法0—6混淆。

这份程序只实现明确约定的文本协议。它没有重试菜单、文件保存和I/O故障诊断，也没有检查约定内容之后是否还有额外行。后续阶段扩展这些行为时，要同步扩展协议与测试。

## 五、怎样实际运行与对照

把程序保存到自己的 `~/dsa-labs/stage1/stats.c`。在 **UCRT64 Bash、该目录**执行：

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic stats.c -o stats.exe
printf '5\n30\n0\n45\n15\n60\n45\n' | ./stats.exe
```

输出应与练习页的8行完全相同。再运行：

```bash
printf '0\n' | ./stats.exe
printf '1\n0\n0\n' | ./stats.exe
printf '1\n1441\n0\n' | ./stats.exe
echo $?
```

第一条只输出count=0与empty；第二条total/min/max/average均为0、active=0、active_average=NA、first=0；第三条只输出invalid minutes，退出状态1。不要在第三条和echo之间插入其他命令。

核对时除结果外还应检查是否能结束、是否有额外行、错误时是否返回1。完整作者测试范围见 [验证记录](验证/课程验证记录.md)，你自己的运行仍需独立完成。

## 六、改造题答案方向

“至少60分钟天数”：在统计循环前设`int goal_days = 0;`，循环内当value>=60时递增，循环后输出。测试59、60、61应贡献0、1、1。这里是**上下文改造说明**，不是另一个已提供的完整程序。

“最后出现位置”：将first改名last，删除`&& first == -1`这一限制，每次目标相等就覆盖位置；输入45、15、45查询45应输出last=2。

如果觉得读取器难，先用纸逐字符跟踪“1441换行”，再独立实现固定数据的统计部分。无需跳过基础去学习链表，输入、循环和数组的边界意识会在后面反复使用。

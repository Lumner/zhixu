# 第九阶段下：最终项目独立验收

## 一、练习方式

本页属于第52章16—24小时总预算，不另重复计时。先完成 [正文](52-综合项目资料检索与路线规划.md)，在自己的解压副本中工作，不覆盖网站保留的样例。参考答案独立见 [答案](第九阶段下-参考答案.md)。

按“手算→改一处→重编译或重载→对照→解释”记录。改输入数据不必重编译，改C程序必须重新构建。保留终端名称、所在目录、完整命令、实际输出与失败原因；作者测试不代替自己的运行。

## 二、从干净目录构建

不依赖上一次生成的exe，在新解压副本的source/示例代码目录按 [命令](示例代码/stage9-planner/README.md) 编译。解释为什么不能链接前批main，以及两个catalog.c为何不冲突。

完成条件：check得到4/3/4/4；find 0正确；list与原主顺序的区别说明清楚。

## 三、映射与树

手画默认分类树，写出每个节点的ID、父ID、内部位置和展示深度。分别写出学习ID9999、地点ID9999的内部位置。

将类别声明中孩子与父项交换前后顺序，再加载；再制造一次缺失父项和一次分类环，预测状态。不要把类ID排序当树遍历。

完成条件：合法声明顺序可变，错误引用和环明确拒绝；没有资料的类别仍显示。

## 四、当前就绪与完整顺序

依次运行ready、ready 0、ready 0 17、ready 0 17 9、ready 9999。预测输出与状态，解释每条依赖的作用。

通过minutes命令把17改成10，输出到新目录文件，再用原关系侧文件重新运行ready 0。解释为何推荐顺序改变，却不必修改图或ID映射。

完成条件：区分完整拓扑、当前可开始集合、已完成闭包；不把推荐第一项自动算完成。

## 五、路线与错误

核对0→202、202→0、0→0、0→9999及0→44。分别说明零权边、无向对称、自身路径、不可达、未知ID。

在自己的关系副本添加反向重复R边，再把某条权重改成-1，观察拒绝状态。不要因为独立Bellman例程可处理负边，就让本工具静默接受负权。

完成条件：每份有限路径的端点、真实边、权重和正确；不可达不输出旧路径。

## 六、序列化与稳定视图

用minutes 0 20导出新文件，展示其协议头和记录顺序，再重载运行list与find。另运行export并重新check。说明为什么list输出不能直接当目录文件。

完成条件：原输入保持，新文件可重载，同分钟保持原序，关系归属仍正确。重定向目标必须是新路径。

## 七、错误与资源清单

至少实际尝试：空配置、重复资料ID、缺一条M、重复S、未知D端点、依赖环、空标签、超长标签、坏数字和不存在文件。逐项记录stdout、stderr、退出状态。

阅读 [验证记录](验证/第九阶段下验证记录.md)，用自己的话解释候选失败如何释放，借用流与自有流为何不同，为什么导出I/O失败不承诺文件回滚。不要通过故意坏指针或整数溢出来“测试极限”。

## 八、完成自己的选择报告

比较两个设计选择：索引与线性查找；稳定副本与原地重排；矩阵与邻接表；父关系表与链式一般树任选两对。明确输入规模、正确性前提、额外资源和失败代价。

如果引用SortStats，写清比较和SItem写入计数不含全部操作；不用一次毫秒数证明复杂度。最后列出自己的已运行项与未运行项，再按正文完成条件验收。

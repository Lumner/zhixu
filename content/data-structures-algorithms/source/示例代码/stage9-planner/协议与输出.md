# v1.0输入协议、状态与输出

## 一、资料文件保持兼容

[catalog.txt](catalog.txt)第一行DSA-CATALOG-1，随后每条三行：ID、分钟、标题。最多32条，ID0—9999唯一，分钟0—1440，标题1—63字节无ASCII控制字符；数字只能为ASCII十进制位，允许前导0，不接受负号、加号、空白或小数。标题可以有空格，旧格式不以竖线分字段。

接受LF/CRLF和无最后换行，拒绝BOM、空ID行、半条记录、过长标题和控制字节。UTF-8只作字节约定，不验证所有Unicode编码序列；长度不是汉字个数。资料顺序是主数据顺序，排序视图不会改变它。

## 二、关系文件语法

第一行必须是DSA-RELATIONS-1。记录区块顺序为C、M、S、D、P、R，可省略空区块，不能退回前一区块；不允许空行、注释、额外字段或未知类型。文件样本见 [relations.txt](relations.txt)。

| 记录 | 字段与数量（含类型） | 约定 |
| --- | --- | --- |
| C | C / 类别ID / 父ID / 标签，共4字段 | 父ID为-1或类别ID，类别最多8个，ID唯一 |
| M | M / 资料ID / 类别ID，共3字段 | 每条目录资料恰好出现一次 |
| S | S / 资料ID，共2字段 | 最多8个，声明学习网络及位置顺序，ID须存在且唯一 |
| D | D / 先修资料ID / 后继资料ID，共3字段 | 端点均已S声明，重复拒绝，整体须DAG |
| P | P / 地点ID / 标签，共3字段 | 最多8个，独立ID空间，声明顺序为图位置顺序 |
| R | R / 地点ID / 地点ID / 权重，共4字段 | 无向、0—1000，反向视同一条边，自环允许，重复拒绝 |

字段分隔符是`|`，不提供转义。标签1—31字节，允许普通空格和UTF-8字节，禁止ASCII控制和分隔符。关系数字范围同ID0—9999，只有C父字段精确文本-1可为负。道路权重须在0—1000内。

本版行缓冲有明确容量，超长行会读完该物理行后拒绝，不能让剩余部分冒充下一条记录。字段上限进一步限制合法记录大小，不用超长标签绕过单行预算。LF/CRLF和无最后换行均支持；裸CR、NUL、制表符、BOM拒绝。

## 三、引用与空配置

解析先收集有界候选，再核对引用，因此类别孩子可以在父项之前声明。类别非空时必须恰好一个根、所有父项存在、无自父和环；可以有不含资料的空类别。空目录允许空类别集合或一棵合法空分类树。

每条目录资料必须有一份M归属；未知资料/类别拒绝。S、D不能凭空创建资料。目录32条与学习图8点是不同预算，只有显式S节点参与学习计划。

依赖环在加载阶段就失败，调用者不会拿到半个可用配置；一个环即使与其他点不连通也要拒绝。地点图允许不连通与零权；未知端点是错误，不可达是成功计算的业务结果。

## 四、命令和状态

完整命令见 [运行说明](README.md)。固定格式：planner 目录路径 关系路径 命令 参数。argc数量错误/未知命令输出usage到stderr并退出1；有效命令先加载全套配置，再执行。因此即使只find资料，坏关系文件也会失败，这是“一个已验证应用快照”的契约。

| API状态 | 含义与典型场景 |
| --- | --- |
| P_OK | 完成，包括空匹配、无路线等有效结果 |
| P_INVALID | 参数无效、多个分类根、已完成集合不满足先修闭包 |
| P_FORMAT | 格式/字段/字符/数字语法错误；旧目录读取器也把部分越界输入归为格式错误 |
| P_DUPLICATE | 重复ID/归属/节点/边、重复完成项 |
| P_LIMIT | 新数字/字段/容量超范围 |
| P_MISSING | 资料、类别、网络端点或查询ID缺失 |
| P_CYCLE | 分类或依赖存在环 |
| P_MEMORY | 实际申请失败 |
| P_IO | 打开、读取、写入、刷新或所拥有输入流关闭失败 |

CLI错误为`planner: 状态文本`，例如planner: cycle，stdout为空；已经开始输出后发生I/O错误时可能有部分stdout。多个错误同时存在时按实际检查顺序返回第一个，不承诺忽略先前错误去报告所有问题。状态名与错误码一一映射见planner_status_name。

## 五、结果解释

list为稳定分钟视图；find为一条记录；title为区分大小写的字节子串，空模式匹配全部且保持主顺序。人读记录格式为id=… minutes=… title=…；空结果为no matches。

categories按根的前序展示，孩子按声明顺序，缩进表示深度；同一类别的资料按主顺序展示。不是按类别ID数值排序，也不把一般树说成BST。

order返回一个完整合法先后，不承诺业务ID字典序最小。ready输入的完成集合必须无重复、属于S网络，并对先修闭合：完成一个点，则它的每个直接先修也必须完成。输出当前未完成且全部直接先修完成的点，按分钟再ID排序；不模拟选中后立即完成，不计算预算最优。

route输出cost和业务地点ID路径。零权合法；相同起终点为单点、成本0；不可达输出unreachable，退出0。同样最短的路径可能有多份，只输出既定实现找到的一份，不承诺全局字典序最小。

minutes和export输出原资料协议，不能夹人读提示；minutes不直接覆写输入，ID与分类/依赖不变。导出不包含关系文件，保留原侧文件使用。成功的内存分钟修改与之后的文件写入是两个步骤，不将后者失败误称为已原子回滚。

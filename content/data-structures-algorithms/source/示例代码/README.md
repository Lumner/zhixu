# 完整示例与运行说明

当前累计63组完整程序/工程，按下文九阶段及最后工程分别统计；多文件、共享模块与验证辅助程序不重复当成新项目。

第一阶段有8个独立完整C程序：02—08章各1个，加阶段项目1个。第01章为手算，不冒充程序示例。所有程序只依赖标准C库，语法基线C17；源文件不需要复制其他课程的辅助头文件。

## 一、在哪里执行

Windows新手使用第02章准备的MSYS2 UCRT64 Bash；本批作者实际运行环境以 [验证记录](../验证/课程验证记录.md) 为准，没有把安装指引当成已重新安装。建议将源码复制到自己的练习目录，不在网站素材目录产生exe。

在**包含对应.c文件的目录**，命令模式是：

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic hello.c -o hello.exe
./hello.exe
```

把hello替换成实际文件名。Linux已有GCC时可生成不带.exe的文件并用`./文件名`运行；PowerShell启动当前目录程序用`.\文件名.exe`，管道输入与退出状态不要直接照搬Bash语法。

## 三、阶段项目复现

在**UCRT64 Bash、含stats.c的目录**：

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic stats.c -o stats.exe
printf '3\n45\n15\n45\n45\n' | ./stats.exe
```

预期：count=3、total=105、min=15、max=45、average=35.00、active=3、active_average=35.00、first=0，各占一行。空记录只要输入`0`一行，程序不再要求查询目标。

# 第四阶段模块与构建说明

本阶段新增8组完整程序/工程：顺序表、动态数组、单链表、循环双向链表、栈对照、括号检查、队列对照、后缀表达式。源码包含复用模块，多文件不重复算程序数。主线C17、Windows x64与MSYS2 UCRT64 Bash，无第三方库。

每章最简单的做法：将本章.h、实现.c、指定入口.c以及本目录ds_status.h复制到自己的练习目录，再按章中命令编译。表达式还要复制25-stack的stack.h/stack.c和26-queue的queue.h/queue.c。只有一份入口main参与每次链接。

| 程序 | 同一练习目录内参与构建的.c | 关键结果 |
| --- | --- | --- |
| 顺序表 | main.c sequence.c | removed=10，剩20、30 |
| 动态数组 | main.c vector.c | 17条，倍增32格/复制模型28，逐一17格/模型136 |
| 单链表 | main.c singly.c | 同一序列行为，节点最终释放 |
| 循环双向表 | main.c doubly.c | 正10/20/30，反30/20/10，删除20 |
| 栈 | main.c stack.c | 两种表示pop均为20 |
| 括号 | brackets_main.c brackets.c stack.c | ([])为ok，([)]为mismatch位置2 |
| 队列 | main.c queue.c | 10先出，绕回后20/30/40，两种表示一致 |
| 后缀表达式 | main.c expression.c stack.c queue.c | 2 3 + 4 *为20，错误有状态和token序号 |

所有命令前缀为`gcc -std=c17 -Wall -Wextra -Wpedantic`，输出名用`-o 名字.exe`，随后`./名字.exe`运行。旧MinGW对%zu的兼容选项见第09章；实际编译器与测试范围见 [第四阶段验证](../../验证/第四阶段验证记录.md)。

对象必须先成功初始化，始终保持表示不变量；输出参数指向独立可写int，不指向内部存储。动态拥有者不按值复制，循环双向表的root地址也必须稳定。init不代替清空已有分配，clear释放后可重复调用。

本课预算为：顺序表8格、动态数组/各链结构64项、顺序栈16格、循环队列运行容量1—16。预算与分配失败是不同错误。int元素允许0与负值，不用数据值当空标志。

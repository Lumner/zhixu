# 03 变量、类型与运算

## 3.1 目标与先修

先能独立编译第02章的程序。建议3—4小时。本章把“记录135分钟”变成程序中的值，并弄清赋值、整数除法、小数和显示格式。学完应能预测结果，再通过修改代码验证。

## 3.2 变量是有名字、类型和当前值的对象

**上下文片段：以下语句放在main的花括号内、return之前。** 练习片段时保留第02章的头文件和main，不要把每个片段都堆在同一文件中造成重复声明。

```c
int total_minutes = 135;
total_minutes = total_minutes + 15;
printf("%d\n", total_minutes);
```

第一行声明一个`int`类型的变量，并初始化为135。`int`用于表示一定范围内的整数，名字`total_minutes`说明用途。第二行先算右边135+15，再把150存回左边；`=`在这里是赋值，不是数学等式。第三行显示150。

初始化发生在创建时，后续赋值是修改已有对象。普通局部变量如果不初始化，不能假定值为0；先写 `int total = 0;`，不要先读一个没有确定值的局部变量。

名字可以用英文字母、数字、下划线，不能以数字开头，不能用`int`、`return`等关键字。`minutes`和`Minutes`是两个名字。建议用能解释含义的英文名，`total_minutes`比`x1`容易维护。

## 3.3 类型告诉编译器怎样解释和操作值

| 类型或写法 | 用来表示什么 | 本课例子与注意点 |
| --- | --- | --- |
| `int` | 范围有限的整数 | 天数、分钟、位置；不是任意大的数学整数 |
| `double` | 浮点数，可近似表示小数 | 平均分钟数；不能把所有十进制小数都精确保存 |
| `char` | 一个字节大小的字符/小整数类型 | `'m'`；单引号里的一个简单字符 |
| `const int` | 通过此名字不能修改的整数对象 | 每小时60分钟 |

C没有规定所有机器的`int`都必须是32位；本批数据刻意保持很小。超出有符号整数可表示范围的运算，不能当作可靠的“自动绕回”。想处理大数据时要先检查范围，第13章会继续讨论。

`'m'`与`"m"`也不同：前者是字符常量，后者是带结束标记的字符串。现在只用`%c`显示单个简单字符；第09章系统讲文字和字符串。一个中文字符在UTF-8中往往占多个字节，不能简单塞进一个`char`就当完整汉字。

`const int minutes_per_hour = 60;`能表达“不打算修改这个对象”。它不是万能的编译期常量替代品；固定数组容量在第08章使用单独说明的写法。

## 3.4 算术不是只看符号，还要看类型

`+ - * /`表示加、减、乘、除；乘号写`*`，不能写数学的`×`。`%`求整数余数。正整数135除以60，商2，余15，所以135分钟是2小时15分钟。

**上下文片段：放在main内。**

```c
printf("%d\n", 135 / 60);
printf("%d\n", 135 % 60);
printf("%d\n", 135 / 2);
printf("%.2f\n", 135.0 / 2);
```

依次输出2、15、67、67.50。两个整数做除法得到整数，去掉小数部分，向0截断；有浮点操作数时进行浮点除法。`%`的操作数应为整数，不能直接拿它对`double`求余。除数为0不能运行来猜结果。

如果先算 `135 / 2`，再把结果存到`double`，丢掉的小数不会回来。需要在除法发生前转换，例如 `(double)total_minutes / 2`。`(double)`叫显式类型转换，本例把整数值转为浮点值后再计算。

乘除余先于加减，括号可以明确分组：`(30 + 45) / 2.0`为37.5，`30 + 45 / 2.0`为52.5。对容易误读的表达式主动加括号，不靠读者背完整优先级表。

## 3.5 printf怎样知道显示什么

`printf`是格式化输出函数，格式文字中的占位符说明后面的参数如何显示：

| 格式 | 对应本章的参数 | 例子 |
| --- | --- | --- |
| `%d` | int | 135 |
| `%.2f` | double，显示小数点后两位 | 67.50 |
| `%c` | 本章使用的字符值 | m |
| `\n` | 格式字符串中的换行转义 | 开始下一行 |
| `%%` | 输出一个字面百分号，不取参数 | 50% |

`printf("hours=%d\n", hours);`中，前面是格式字符串，后面是要替换`%d`的值，逗号隔开。两个占位符就按从左到右提供两个匹配参数。格式与类型不匹配不是可靠的自动转换，编译器警告要认真处理。

`puts`自动加换行，`printf`不会无条件加换行，所以上面需要`\n`。`%.2f`只决定显示精度，不会把变量本身改成永远只有两位小数。也不要把一般浮点计算当成金额的精确表示，本课统计平均值只做展示。

## 3.6 完整实验：分钟换算

建立自己的 `~/dsa-labs/ch03`。**完整程序：values.c。** 对应 [可下载源码](示例代码/03-values/values.c)。

```c
#include <stdio.h>

int main(void)
{
    const int minutes_per_hour = 60;
    int total_minutes = 135;
    int hours = total_minutes / minutes_per_hour;
    int remaining = total_minutes % minutes_per_hour;
    double average = (double)total_minutes / 2;
    char unit = 'm';

    printf("hours=%d\nremaining=%d\n", hours, remaining);
    printf("integer_average=%d\n", total_minutes / 2);
    printf("average=%.2f\nunit=%c\n", average, unit);

    total_minutes = total_minutes + 15;
    printf("new_total=%d\n", total_minutes);
    return 0;
}
```

在 **UCRT64 Bash、`~/dsa-labs/ch03`目录**编译运行：

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic values.c -o values.exe
./values.exe
```

预期结果：

```text
hours=2
remaining=15
integer_average=67
average=67.50
unit=m
new_total=150
```

注意最后把`total_minutes`改为150，并不会自动让前面已经算好的`hours`或`average`重新计算。变量保存的是当时计算得到的值，不是电子表格中持续联动的公式。如果要重新换算，必须再执行相应赋值。

## 3.7 改造与排错

把初始135依次改为0、59、60、61，每次保存并重编译。你应分别得到小时和剩余分钟 `(0,0)`、`(0,59)`、`(1,0)`、`(1,1)`。60前后的三组专门检查换算边界。

把平均值计算改为 `double average = total_minutes / 2;`，135的平均值会显示67.00。程序语法没错，但转换太晚；这是逻辑错误。恢复显式转换再测。

在练习副本中尝试给`minutes_per_hour`重新赋值，编译器应拒绝。这个实验是检查只读约束，最后删除故意错误语句。不要通过关闭警告来“解决”类型问题。

## 3.8 常见错误

- 写成 `total_minutes == 150;`想修改值：`==`是比较，不是赋值，第05章展开。
- 把`/`写成`\`：C的除法使用正斜线。
- 在整数除法完成后才转换：小数已经丢失。
- 未初始化就累加：没有可靠起点。累加器先设0。
- 使用错误的格式符：看编译诊断，核对参数类型与数量。
- 以为变量保存公式：改变输入后没有重新计算，旧结果不会自己更新。

## 3.9 练习与参考答案

练习一：125分钟怎样分成小时和分钟？

答案：`125 / 60`为2，`125 % 60`为5。即2小时5分钟。

练习二：为什么 `double x = 5 / 2;`不是2.5？写两种修复方式。

答案：先进行整数除法得到2，再转成2.0。可改成`5.0 / 2`或`(double)5 / 2`。

练习三：初始`a=3`，执行`int b = a + 2;`后再执行`a = 10;`，b是多少？

答案：5。b保存声明时算出的值，不会追随a改变。

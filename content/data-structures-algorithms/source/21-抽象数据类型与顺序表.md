# 21 抽象数据类型与顺序表

## 21.1 目标与先修

先完成第20章，会结构体、数组、长度、输出参数和循环不变量。建议4—5小时。本章第一次把一组操作设计成可重复使用的数据结构接口，完成顺序表的读取、修改、插入与删除。

把待学任务按顺序排成一列，任务之间有先后，但不一定按编号大小排列。我们要在第p个位置插入或删除，而不是按数值大小排序。位置从0计数，第一个任务下标0。

## 21.2 ADT说行为，表示方法说怎样保存

**抽象数据类型**，简称ADT，是一组值及其操作约定。例如“有限的整数序列”提供按位置读写、插入、删除和查询数量。用户关心操作的结果，不应依赖数据恰好怎样摆放。

**顺序表**是把序列放在连续数组中的一种表示。下两章的链表会用节点与连接表示同样的逻辑序列。它们可以给调用者相似的行为，但定位、搬动、分配的成本不同。

ADT不是C的新语法，也不要求使用面向对象语言。这里用struct保存状态，用普通函数实现操作。为方便教学，头文件公开字段；调用者仍应通过约定接口修改，不能把count随便设大后要求函数恢复正确。

## 21.3 位置与插入边界不同

当前序列[10,30]，数量n=2：读、改、删只能操作位置0或1；插入有0、1、2三个边界。插入1得到[10,20,30]，插入2表示追加在末尾。

| 操作 | 合法位置 | 空表时 |
| --- | --- | --- |
| get/set/erase | 0≤p<n | 没有合法位置 |
| insert | 0≤p≤n，且有容量 | p=0可以插入 |

不要沿用一个`p >= count`检查所有操作，否则追加会被误拒绝。容量与数量也不同：本例固定8格，只处理前count格。

## 21.4 不变量、状态与输出参数

顺序表不变量是`0 <= count <= 8`，有效序列恰好为data[0]到data[count-1]，备用格子的内容没有业务意义。

本阶段共享 [ds_status.h](示例代码/stage4-common/ds_status.h)：

```c
#ifndef DSA_DS_STATUS_H
#define DSA_DS_STATUS_H

#include <stddef.h>

#define DS_MAX_ITEMS 64

typedef enum {
    DS_OK, DS_RANGE, DS_FULL, DS_EMPTY, DS_MEMORY, DS_INVALID
} DsStatus;

#endif
```

DS_OK成功；DS_RANGE位置不合法；DS_FULL达到容量预算；DS_EMPTY用于空栈/空队列；DS_MEMORY分配失败；DS_INVALID用于本例可检查的无效参数。0是合法元素，不能拿返回数值0同时表示读取失败。

这个枚举中的DS_OK数值是0，所以用`status == DS_OK`判断成功。前面有些函数用1表示布尔成功，那是另一种接口约定，不能把`if (!某个操作())`模板不加区分地套过来。函数返回状态，真正的数据通过输出参数交付。

所有对象参数必须非空、已初始化且满足不变量。输出参数要指向**调用者单独的可写int变量**，不指向容器内部元素或即将释放的节点；例如`int removed;`然后传`&removed`。函数只检查NULL，不检测任意坏地址或别名重叠。失败不改变有效序列和输出变量。

位置错误优先于插入时的满错误；读删的NULL输出优先于位置错误。这些小约定可以让测试结果明确，而不是依赖实现碰巧先执行哪条语句。

## 21.5 插入为什么从右往左搬

在[10,30]的位置1插入20：先把原位置1的30移到位置2，再写data[1]=20，最后count变3。

```text
原来： [10][30][备用]
腾位： [10][30][30]
写入： [10][20][30]   count=3
```

若从左往右搬，会覆盖后面尚未保存的旧值。循环开始时i=count，目标data[count]只有在count<capacity时才能写；每轮复制data[i-1]到data[i]，直到i==position停止。不使用无符号i>=0的倒序条件。

循环不变量可以写：原序列中下标i到count-1的元素，已各向右移动一格；更左的待处理元素还保留。插入位置越靠前，需要搬的越多，数量为n-p。

## 21.6 删除为什么向左搬

删除[10,20,30]的位置0，先保存10，再把20复制到0、30复制到1，最后count减1。剩余格子里的旧30无需抹成0，它已不属于有效序列。

若先count--再用错误的循环上限，可能漏掉原末尾。当前代码以旧count判断`i+1 < count`，完成所有搬动后再减数量。输出最后写入单独的removed变量。

查到某值并不等于知道它的稳定身份：插入删除会改变后面元素下标。上一阶段的二分前提也不会自动保持，因为这个序列没有排序约定。

## 21.7 完整接口与实现

把 [sequence.h](示例代码/21-sequence/sequence.h)、[sequence.c](示例代码/21-sequence/sequence.c)、[main.c](示例代码/21-sequence/main.c) 和共享ds_status.h复制到自己的`~/dsa-labs/ch21`。三份本章文件共同构成一个完整程序。

完整文件sequence.h：

```c
#ifndef DSA_SEQUENCE_H
#define DSA_SEQUENCE_H
#include "ds_status.h"

#define SEQ_CAPACITY 8
typedef struct { int data[SEQ_CAPACITY]; size_t count; } Sequence;

void seq_init(Sequence *list);
DsStatus seq_get(const Sequence *list, size_t position, int *out);
DsStatus seq_set(Sequence *list, size_t position, int value);
DsStatus seq_insert(Sequence *list, size_t position, int value);
DsStatus seq_erase(Sequence *list, size_t position, int *out);
#endif
```

完整文件sequence.c：

```c
#include "sequence.h"

void seq_init(Sequence *list) {
    list->count = 0;
}

DsStatus seq_get(const Sequence *list, size_t position, int *out)
{
    if (out == NULL) {
        return DS_INVALID;
    }
    if (position >= list->count) {
        return DS_RANGE;
    }
    *out = list->data[position];
    return DS_OK;
}

DsStatus seq_set(Sequence *list, size_t position, int value)
{
    if (position >= list->count) {
        return DS_RANGE;
    }
    list->data[position] = value;
    return DS_OK;
}

DsStatus seq_insert(Sequence *list, size_t position, int value)
{
    if (position > list->count) {
        return DS_RANGE;
    }
    if (list->count == SEQ_CAPACITY) {
        return DS_FULL;
    }
    for (size_t i = list->count; i > position; i--) {
        list->data[i] = list->data[i - 1];
    }
    list->data[position] = value;
    list->count++;
    return DS_OK;
}

DsStatus seq_erase(Sequence *list, size_t position, int *out)
{
    if (out == NULL) {
        return DS_INVALID;
    }
    if (position >= list->count) {
        return DS_RANGE;
    }
    int saved = list->data[position];
    for (size_t i = position; i + 1 < list->count; i++) {
        list->data[i] = list->data[i + 1];
    }
    list->count--;
    *out = saved;
    return DS_OK;
}
```

入口main先插入10、30，再在中间插20，删除位置0并读取剩余元素。入口完整代码在上述下载与 [第四阶段源码附录](示例代码/stage4-common/完整源码.md)，不是需要自行补全的片段。

在 **UCRT64 Bash、`~/dsa-labs/ch21`目录**：

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic main.c sequence.c -o sequence.exe
./sequence.exe
```

预期：

```text
removed=10 count=2
[0]=20
[1]=30
```

## 21.8 结果、复杂度与边界

get/set按下标直接访问，Θ(1)；位置p插入搬n-p个元素，删除搬n-p-1个，最坏Θ(n)，末尾操作可为Θ(1)。额外操作空间只有若干变量，Θ(1)；数组本身占容量对应的存储。

把8当固定常量时，这个演示当然有有限最大工作量；复杂度讨论的是同一种结构推广到可变容量的模型，不把“机器能存有限数据”误当所有算法永远无差别。

至少实际检查：空表删0应DS_RANGE；空表插0成功；插入count+1失败；装满8格后再插入失败；删除唯一元素后count=0；失败时removed原来的999不变。不要通过故意越界写data[8]来验证容量检查。

## 21.9 常见错误

- 混用元素下标与插入边界，拒绝合法追加。
- 右移按错误方向，覆盖还没搬的旧值。
- 满表仍写data[count]，写出数组之外。
- 删除后把备用值当仍存在，或平均值仍除容量。
- 输出地址指向容器内部，删除后又写坏有效元素；改用独立变量。
- 把下标当永久ID；后续结构变化会影响位置。

## 21.10 练习与参考答案

练习一：[5,7,9]在位置0插入3，要搬几个元素、顺序怎样？

答案：搬3个，先9到3，再7到2，再5到1，最后3写到0。

练习二：数量为3时，insert位置3与get位置3分别怎样？

答案：前者有容量时合法追加，后者越过最后元素，返回DS_RANGE。

练习三：删掉最后一个元素后，需要把旧格子写0才能表示空吗？

答案：不需要。count决定有效范围；清零可能是另一个业务需求，不属于本整数序列接口。

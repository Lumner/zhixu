# 第三阶段参考答案：规格、计数与查找

先完成 [第三阶段练习](第三阶段-练习.md)。完整参考程序见 [实验台运行说明](示例代码/stage3-search-lab/README.md)，代码见 [main.c](示例代码/stage3-search-lab/main.c) 与第20章的 [查询实现](示例代码/20-search/search.c)。它们组成一个工程，不新算成主线章节。

## 一、闭卷题答案

1. 非空有效int序列，值0—1440，总和应可由long表示，输出对象可写。成功返回总和、最大值与最早位置；非法或空时返回0并保持原输出字段。
2. 已处理前缀[0,i)；每轮加入i位置后i前进，未处理数量count-i下降到0。
3. 先后执行2n次，Θ(n)；完整嵌套n²次，Θ(n²)。先明确每次体内为常数工作。
4. 不能。三个符号是函数增长的上界、下界和紧界；最好、最坏、平均是选择分析哪一种工作量函数。
5. 必定成功、每个位置等概率且值互不相同。不能给任意业务请求直接套该平均。
6. 求和n+1次调用，最多n+1活跃层；汉诺塔总调用2^(n+1)-1，活跃层仍n+1，移动2^n-1。
7. 下界下标3，那里是9；没有5，所以精确查询返回count=4表示不存在。
8. 验证和读入本身线性；查询内核对数不等于完整程序对数。

## 二、四个数的下界表

每次初始lo=0、hi=4。下列“访问下标”按实际执行顺序列出，可反向核对你画的边界。

| 目标 | 访问下标 | 下界 | 下界比较次数 | 二分精确结果与比较次数 |
| --- | --- | --- | --- | --- |
| 0 | 2、1、0 | 0 | 3 | 未找到，4次 |
| 2 | 2、1、0 | 0 | 3 | 0，4次 |
| 4 | 2、1、0 | 1 | 3 | 1，4次 |
| 5 | 2、3 | 3 | 2 | 未找到，3次 |
| 9 | 2、3 | 3 | 2 | 3，3次 |
| 10 | 2、3 | 4 | 2 | 未找到，2次 |

末尾位置4不能读，因此最后一行没有额外等值比较。不同目标的精确次数可以不同，但最坏增长仍是对数。循环边界检查未包含在这张表的计数里。

## 三、实验台入口怎样组织

入口先校验目标参数，再读取count和values；随后做一次非递减验证；只有全部合法才调用查询并输出。数组容量128，count<=128，实际只读写前count个元素。数字仍先检查乘加上界，不依赖scanf的宽松前缀解析。

**完整工程中的入口文件main.c**如下；必须同时编译search.c，并准备search.h。

```c
#include "search.h"
#include <stdio.h>

#define CAPACITY 128

int parse_target(const char *text, int *out)
{
    int value = 0;
    if (text[0] == '\0') {
        return 0;
    }
    for (size_t i = 0; text[i] != '\0'; i++) {
        if (text[i] < '0' || text[i] > '9') {
            return 0;
        }
        int digit = text[i] - '0';
        if (value > 9999 / 10 || (value == 9999 / 10 && digit > 9999 % 10)) {
            return 0;
        }
        value = value * 10 + digit;
    }
    *out = value;
    return 1;
}

int read_number(int limit)
{
    int ch = getchar();
    int value = 0;
    int has_digit = 0;
    int valid = 1;
    while (ch != '\n' && ch != EOF) {
        if (ch < '0' || ch > '9') {
            valid = 0;
        } else {
            int digit = ch - '0';
            has_digit = 1;
            if (value > limit / 10 || (value == limit / 10 && digit > limit % 10)) {
                valid = 0;
            }
            if (valid) {
                value = value * 10 + digit;
            }
        }
        ch = getchar();
    }
    return valid && has_digit ? value : -1;
}

int main(int argc, char *argv[])
{
    int target = 0;
    if (argc != 2 || !parse_target(argv[1], &target)) {
        fputs("usage: search_lab target (0..9999)\n", stderr);
        return 1;
    }
    int entered_count = read_number(CAPACITY);
    if (entered_count < 0) {
        fputs("invalid count\n", stderr);
        return 1;
    }
    size_t count = (size_t)entered_count;
    int values[CAPACITY];
    for (size_t i = 0; i < count; i++) {
        int value = read_number(9999);
        if (value < 0) {
            fputs("invalid value\n", stderr);
            return 1;
        }
        values[i] = value;
    }
    if (!is_nondecreasing(values, count)) {
        fputs("array is not sorted\n", stderr);
        return 1;
    }
    SearchResult lower = lower_bound_int(values, count, target);
    SearchResult linear = linear_find(values, count, target);
    SearchResult binary = binary_find_first(values, count, target);
    printf("count=%zu target=%d\nlower=%zu\n", count, target, lower.index);
    printf("linear=%zu comparisons=%zu found=%d\n",
           linear.index, linear.comparisons, linear.index < count);
    printf("binary=%zu comparisons=%zu found=%d\n",
           binary.index, binary.comparisons, binary.index < count);
    return 0;
}
```

查询函数不拥有数组，不返回堆对象，也不修改数据，所以本阶段没有动态分配与释放；固定缓冲区仍有边界和生命周期约定。输入文件读取与前一阶段目录项目保持独立，不改写它的字段或接口。

## 四、更多结果与分析

对六数样例找4：lower=4，linear=6比较6次found=0，binary=6比较4次found=0。找12：lower=5，linear=5比较6次found=1，binary=5比较4次found=1。找13：lower=6，linear=6比较6次found=0，binary=6比较2次found=0。

在[0,1,...,127]找127，下界依次访问64、96、112、120、124、126、127，共7次<；再做1次==，二分精确8次。顺序128次。找0却会访问64、32、16、8、4、2、1、0，共8次下界比较，再1次==，顺序只1次。相同n的不同目标，哪种比较少也不同。

完整工具仍读入并验证全部n条，且为了展示分别执行多个查询函数，因此不能把整个工具叫“只做8次工作”。这是对照实验台，不是正式性能优化服务。

## 五、小练习答案

最大值反例：30、0、45、15、45，把>改>=会返回最后位置4，而规格要求2。恢复代码后核对结果，不只修输出文字。

整数减半：7→3→1为2次，8→4→2→1与9→4→2→1均3次。log2(7)向下取整2，log2(8)与log2(9)向下取整3。n=0不进入循环，不能对它套对数表达式。

汉诺塔3盘移动：1 A→C，2 A→B，1 C→B，3 A→C，1 B→A，2 B→C，1 A→C。逐条检查源顶部和目标盘大小；行数正确并不保证移动合法。

上界改造：要找第一个严格大于目标的位置，左侧应满足≤target，右侧>target。二分分支可以按`values[mid] <= target`时令lo=mid+1，否则hi=mid。对[3,3,3]找3，上界3而下界0。注意它只回答插入边界，不是原精确查找的可直接替代实现。

## 六、测试与证明怎样配合

作者检查既用独立的逐条扫描计算期望，也检查下界两侧性质、最早匹配、比较计数上界和空输入；汉诺塔检查每一步是否合法，不只比较总数。有限穷举仍不是对所有可能C运行环境的证明，第17章的不变量和第20章的边界推理仍然必要。

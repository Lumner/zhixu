# 48 并查集、Kruskal与Prim生成森林

## 48.1 目标与先修

先完成图、堆排序和权重，建议8—11小时。目标是区分最短路径与最小生成树，实现并查集，手推Kruskal/Prim，处理负权、自环、孤立点，并验证生成森林既连接正确又总成本最小。

修路网络可能要让所有地点互相连通，同时总修路成本最少；这与“从某一地到各地走最短路”不同。最短路径树并不一定让选中边总权最小。

## 48.2 树、森林与输出关系

对无向连通图，**生成树spanning tree**覆盖全部顶点且无环，有V-1边；总权最小者是MST。若图断开，根本不存在一棵覆盖全图的树，本接口为每个连通分量取MST，合成**最小生成森林**。

若有C个分量，选边数为V-C，孤立点也是一个分量。空图V=C=0、选0边、成本0。返回G_OK不表示一定连通，需要查看components；有向图返回G_INVALID，不用本算法求有向树形图。

负边与零边都允许，自环不可能出现在树里，直接忽略；无向边只收u<v一份。相同权重可能有多份合法最优森林，不强求两算法选完全相同的边。

## 48.3 并查集：只维护哪些点属于同组

**并查集disjoint set union，DSU**支持find查代表、union合并组，不保存原图路线。parent形成代表树，每个根parent[root]=root；size只在根上表示组大小，非根旧size不解释为当前组大小。

初始每点一组。union先找两根，相同则不合并；不同把小组接到大组，组件数减1。相同大小按根编号确定方向。find沿parent找根，再让路径各点直接指根，叫路径压缩；因此这个“查询”也会修改内部表示。

union成功总为G_OK，额外merged=0/1区分是否真合并；已经同组不是错误。非法编号/NULL输出在修改前拒绝，旧对象和输出保持；对象只含有界数组，可值复制。

## 48.4 完整并查集实现

接口 [dsu.h](示例代码/48-spanning/dsu.h)，完整文件dsu.c：

```c
#include "dsu.h"
GStatus dsu_init(DisjointSet *sets, size_t n)
{
    if (sets == NULL) { return G_INVALID; }
    if (n > GRAPH_MAX) { return G_RANGE; }
    DisjointSet next = {0}; next.n = next.components = n;
    for (size_t i = 0; i < n; i++) { next.parent[i] = i; next.size[i] = 1; }
    *sets = next; return G_OK;
}
GStatus dsu_find(DisjointSet *sets, size_t value, size_t *out)
{
    if (sets == NULL || out == NULL || value >= sets->n) { return G_INVALID; }
    size_t root = value;
    while (sets->parent[root] != root) { root = sets->parent[root]; }
    while (value != root) { size_t next = sets->parent[value]; sets->parent[value] = root; value = next; }
    *out = root; return G_OK;
}
GStatus dsu_union(DisjointSet *sets, size_t a, size_t b, int *merged)
{
    if (sets == NULL || merged == NULL || a >= sets->n || b >= sets->n) { return G_INVALID; }
    size_t ra, rb; (void)dsu_find(sets, a, &ra); (void)dsu_find(sets, b, &rb);
    *merged = 0;
    if (ra != rb) {
        if (sets->size[ra] < sets->size[rb] || (sets->size[ra] == sets->size[rb] && ra > rb)) { size_t saved = ra; ra = rb; rb = saved; }
        sets->parent[rb] = ra; sets->size[ra] += sets->size[rb]; sets->components--; *merged = 1;
    }
    return G_OK;
}
```

按大小合并时，一条路径每加一层，其所在组至少翻倍，因此未考虑压缩也有O(log V)高度；压缩只会进一步缩短。进阶资料会给更强的摊还界，本课用这个保守上界已足够分析，不要求先背特殊函数。

## 48.5 Kruskal：全局从便宜边开始

按权重升序处理边；两端不在同一组就加入森林并合并，同组则拒绝，以免形成环。这里同权按from/to确定顺序；边排序用大根堆思路，完整搬动Edge，不调用需要新讲函数指针的通用回调。

样本5点，4孤立，边1—2=-1、0—2=1、1—3=2、0—1=3、2—3=4，另0自环-100：

| 处理边 | 决定 | 总成本 |
| --- | --- | --- |
| 自环0—0 | 不参与候选 | 0 |
| 1—2，-1 | 两组，选 | -1 |
| 0—2，1 | 两组，选 | 0 |
| 1—3，2 | 两组，选 | 2 |
| 0—1，3 | 已同组，跳过 | 2 |
| 2—3，4 | 已同组，跳过 | 2 |

最终3边、2分量。不能把最小的自环也加进去；小权本身不能替代无环条件。

## 48.6 Prim：从当前树跨出最便宜一条

Prim对每个未覆盖分量另起一个根，维护best[v]为“从当前树接到v的最便宜边”，parent[v]记连接点。选best最小的未选顶点加入，再用它发出的边更新候选。

known标记有无候选，不能拿best初始0代表无连接，因为0和负权都合法。每个根的best=0仅为启动，不计为真实边。没有候选时当前分量结束，外层从下一未选顶点开始，孤立点也被统计。

Dijkstra更新的是distance[u]+weight[u][v]，Prim更新的是weight[u][v]。二者都“选小值”，但小值的含义不同，不能复制公式混用。

## 48.7 为什么便宜跨边安全

把已选的一组顶点与其余顶点分开，连接两侧的边叫跨越这个划分的边。最小跨边可以属于某份最优树：若最优树没选它，加入会形成环，环中有另一条跨边；用这条不更贵的边交换，不增加总成本。

Kruskal用当前组件作一侧，Prim用当前长出的树作一侧，各自维持“还能扩展成最优结果”。这是当前生成树问题的交换依据，不是所有图问题都可以贪心。

## 48.8 完整两种森林实现

接口 [spanning.h](示例代码/48-spanning/spanning.h)，完整文件spanning.c：

```c
#include "spanning.h"
#include "dsu.h"
#include "graph_internal.h"
static int compare(Edge a, Edge b)
{
    if (a.weight != b.weight) { return a.weight < b.weight ? -1 : 1; }
    if (a.from != b.from) { return a.from < b.from ? -1 : 1; }
    return a.to < b.to ? -1 : a.to > b.to ? 1 : 0;
}
static void swap(Edge *a, Edge *b) { Edge saved = *a; *a = *b; *b = saved; }
static void edge_down(Edge *edges, size_t root, size_t n)
{
    while (root < n / 2) {
        size_t child = root * 2 + 1;
        if (child + 1 < n && compare(edges[child + 1], edges[child]) > 0) { child++; }
        if (compare(edges[root], edges[child]) >= 0) { break; }
        swap(&edges[root], &edges[child]); root = child;
    }
}
static void edge_sort(Edge *edges, size_t n)
{
    for (size_t i = n / 2; i > 0; i--) { edge_down(edges, i - 1, n); }
    for (size_t end = n; end > 1; end--) { swap(&edges[0], &edges[end - 1]); edge_down(edges, 0, end - 1); }
}
GStatus graph_kruskal(const Graph *graph, Forest *out)
{
    if (graph == NULL || out == NULL || graph->directed) { return G_INVALID; }
    Edge edges[GRAPH_ARCS]; size_t n = 0;
    for (size_t u = 0; u < graph->n; u++) { for (size_t v = u + 1; v < graph->n; v++) { if (graph->has[u][v]) { edges[n++] = (Edge){u,v,graph->weight[u][v]}; } } }
    edge_sort(edges, n); DisjointSet sets; (void)dsu_init(&sets, graph->n);
    Forest next = {0}; next.vertices = graph->n;
    for (size_t i = 0; i < n; i++) {
        int merged; (void)dsu_union(&sets, edges[i].from, edges[i].to, &merged);
        if (merged) {
            GStatus status = graph_cost_sum(next.total, edges[i].weight, &next.total);
            if (status != G_OK) { return status; }
            next.edges[next.count++] = edges[i];
        }
    }
    next.components = sets.components; *out = next; return G_OK;
}
GStatus graph_prim(const Graph *graph, Forest *out)
{
    if (graph == NULL || out == NULL || graph->directed) { return G_INVALID; }
    Forest next = {0}; next.vertices = graph->n;
    int used[GRAPH_MAX] = {0}, known[GRAPH_MAX] = {0}, best[GRAPH_MAX] = {0}; size_t parent[GRAPH_MAX];
    for (size_t i = 0; i < GRAPH_MAX; i++) { parent[i] = GRAPH_MAX; }
    for (size_t root = 0; root < graph->n; root++) {
        if (used[root]) { continue; }
        next.components++; known[root] = 1; best[root] = 0;
        for (;;) {
            size_t u = GRAPH_MAX;
            for (size_t v = 0; v < graph->n; v++) { if (!used[v] && known[v] && (u == GRAPH_MAX || best[v] < best[u])) { u = v; } }
            if (u == GRAPH_MAX) { break; }
            used[u] = 1;
            if (parent[u] != GRAPH_MAX) {
                size_t a = parent[u] < u ? parent[u] : u, b = parent[u] < u ? u : parent[u];
                next.edges[next.count++] = (Edge){a,b,best[u]};
                GStatus status = graph_cost_sum(next.total, best[u], &next.total); if (status != G_OK) { return status; }
            }
            for (size_t v = 0; v < graph->n; v++) {
                if (!used[v] && graph->has[u][v] && (!known[v] || graph->weight[u][v] < best[v] || (graph->weight[u][v] == best[v] && u < parent[v]))) {
                    known[v] = 1; best[v] = graph->weight[u][v]; parent[v] = u;
                }
            }
        }
    }
    *out = next; return G_OK;
}
```

结果Forest含vertices、edges、count、components和total，选中端点规范为小编号在前。所有工作在局部对象，最后提交；有向/NULL等错误保留out。权和用检查long相加，最多7边、绝对总权<=7000。

矩阵收边本身O(V²)，Kruskal再用O(E log(E+1))排序与O(E log(V+1))保守并查界；不要漏前者。Prim为矩阵O(V²)，工作O(V)。所有数组有界，不使用malloc。

## 48.10 与最短路及项目的区别

三角形0—1=2、0—2=2、1—2=1，MST可选0—1与1—2总3，但树内0到2路为3，原图直达只需2。Dijkstra的两条直达边总4，却让源到每点最短。目标不同，答案不应互换。

[关系网络实验台](示例代码/stage8-graph-lab/README.md) 组合拓扑与路径查询，属于可运行的v0.8a基础实验；未给旧资料目录接分类树、图文件或最终菜单。完整v0.8/v1.0仍待第52章整合，不拿独立函数数量冒充成品。

## 48.11 常见错误

MST当最短路径；断开图仍硬取V-1边；只处理根0忘孤立点；选自环；无向两方向重复算权；DSU用原顶点parent不找根；压缩后继续读非根size；Prim把路径总距当best；负边一律拒绝；相同权重森林不同就判错。

## 48.12 练习与参考答案

练习一：8点3分量森林几边？答案：5；若有孤立点也已算进分量。

练习二：union已同组返回什么？答案：G_OK且merged=0，组件数不变，压缩可能改变内部父指针。

练习三：自环权-100能让MST更便宜吗？答案：不能，树不含自环；负的普通跨边则可选。

# 39 二叉搜索树与三种删除

## 39.1 目标与先修

先完成二叉树与中序遍历，建议6—8小时。目标是用整棵子树的取值范围解释BST，跟踪查找/插入，画出叶、单孩子、双孩子删除，并说明高度如何决定成本。

前面把资料放在数组和散列表中。若希望按键查询、也方便按键顺序遍历，可以让二叉树的形状帮助比较。代价是每次修改都必须维护顺序，不能任意挂接节点。

## 39.2 搜索性质约束的是全部后代

**二叉搜索树binary search tree，BST**在本课定义为：每个节点的左子树所有键都小于当前键，右子树所有键都大于当前键；每个子树也满足同样性质。

不是只检查两个直接孩子。例如10的左孩子5、5的右孩子12，局部5<12成立，但12仍在10左子树且12>10，所以整树无效。中序遍历合法唯一键BST会严格递增；普通二叉树没有这个保证。

本版只存int key，支持所有int值，最多63节点，重复键拒绝，不静默覆盖或累计次数。要做多重集合或保存资料记录，可以另定义计数/负载协议，不能把重复键随意塞某边后继续使用严格不等号证明。

## 39.3 查找与插入路径

从root比较：相等成功；目标小就走left，大就走right；走到NULL说明不存在。每次可以排除另一个子树，因为它所有键都在不可能包含目标的范围内。

插入沿同样路径找到空位置，记住父节点。先查重复，再检查63项预算，再malloc和初始化节点，最后接到父节点对应方向；空树则接root。分配失败时旧链接还没改，原树保持。

满树put已有键返回T_DUPLICATE，新键才T_FULL。init不申请，clear释放全部节点；拥有者不可复制后分别clear。公开contains返回布尔值，不把节点地址作为长期可用的查询结果。

## 39.4 删除叶与单孩子节点

找到目标后：若没有孩子，用NULL代替它；若只有一个孩子，让父节点直接接到该孩子。原节点释放一次，孩子和整棵子树仍保留。

```text
删除单孩子5：
    8                 8
   /                 /
  5        ->       3
 /
3
```

若目标本来是根，同样要更新tree.root，不能只改某个局部node变量。代码让删除辅助函数返回“这棵子树删除后的新根”，调用者把结果写回对应链接。

## 39.5 双孩子：用中序后继补位

有两个孩子时，不能直接接任意一边而丢掉另一边。选**中序后继successor**：右子树里最小的键，沿right后不断走left得到。它大于左子树及当前旧键，且不大于右子树其他键。

将后继键复制到当前节点，再从右子树删除原后继节点。后继不可能有左孩子，因此第二步最终落入叶或单右孩子的简单情况。公开erase只将count减一次，不因内部又调用删除就减两次。

```text
       4                    5
     /   \                /   \
    2     6     ->       2     6
   / \   / \           / \     \
  1   3 5   7         1   3     7
```

不能用右子树最大键代替后继：若补到根，右侧剩余的一些键可能更小，破坏全局范围。也可以对称使用左子树最大键（前驱），但须同时改为从左子树删除它，不能混搭。

## 39.6 节点地址与业务记录的区别

双孩子删除中，当前节点对象可能仍活着，却代表了后继键；真正free的是原后继对象。因而缓存一个BNode*并假定“这个地址永远是原ID”不可靠；成功修改后按键重新查询。

当前节点仅有key与链接。未来若附加标题等负载，补位应替换完整业务键值记录，不能只换key；同时也不能把后继整个节点结构体（含左右链接）直接覆盖当前节点。记录内容和结构链接承担不同职责。

## 39.7 完整C实现与失败协议

接口 [bst.h](示例代码/39-bst/bst.h)，完整文件bst.c：

```c
#include "bst.h"
#include <stdlib.h>
void bst_init(BST *tree) { tree->root = NULL; tree->count = 0; }
static void release(BNode *node)
{
    if (node != NULL) { release(node->left); release(node->right); free(node); }
}
void bst_clear(BST *tree) { release(tree->root); bst_init(tree); }
int bst_contains(const BST *tree, int key)
{
    const BNode *node = tree->root;
    while (node != NULL) {
        if (key == node->key) { return 1; }
        node = key < node->key ? node->left : node->right;
    }
    return 0;
}
TStatus bst_insert(BST *tree, int key)
{
    BNode *parent = NULL, *node = tree->root;
    while (node != NULL) {
        if (key == node->key) { return T_DUPLICATE; }
        parent = node; node = key < node->key ? node->left : node->right;
    }
    if (tree->count == TREE_LIMIT) { return T_FULL; }
    node = malloc(sizeof *node);
    if (node == NULL) { return T_MEMORY; }
    node->key = key; node->left = node->right = NULL;
    if (parent == NULL) { tree->root = node; }
    else if (key < parent->key) { parent->left = node; }
    else { parent->right = node; }
    tree->count++; return T_OK;
}
static BNode *erase_node(BNode *node, int key)
{
    if (key < node->key) { node->left = erase_node(node->left, key); }
    else if (key > node->key) { node->right = erase_node(node->right, key); }
    else if (node->left == NULL || node->right == NULL) {
        BNode *child = node->left != NULL ? node->left : node->right;
        free(node); return child;
    }
    else {
        BNode *successor = node->right;
        while (successor->left != NULL) { successor = successor->left; }
        node->key = successor->key;
        node->right = erase_node(node->right, successor->key);
    }
    return node;
}
TStatus bst_erase(BST *tree, int key)
{
    if (!bst_contains(tree, key)) { return T_MISSING; }
    tree->root = erase_node(tree->root, key); tree->count--; return T_OK;
}
TStatus bst_min(const BST *tree, int *out)
{
    if (out == NULL) { return T_INVALID; }
    const BNode *node = tree->root;
    if (node == NULL) { return T_EMPTY; }
    while (node->left != NULL) { node = node->left; }
    *out = node->key; return T_OK;
}
static void collect(const BNode *node, int *out, size_t *n)
{
    if (node != NULL) { collect(node->left, out, n); out[(*n)++] = node->key; collect(node->right, out, n); }
}
TStatus bst_inorder(const BST *tree, int *out, size_t capacity, size_t *out_count)
{
    if (out_count == NULL || (tree->count != 0 && out == NULL)) { return T_INVALID; }
    if (capacity < tree->count) { return T_SPACE; }
    size_t n = 0; collect(tree->root, out, &n); *out_count = n; return T_OK;
}
```

erase先contains，缺失T_MISSING且不改树；私有erase_node因此只沿确实存在的路径递归，没有“任意坏树也能处理”的承诺。删除不申请内存。contains与删除两遍路径仍为O(h)，这里用少量重复查找换取清楚的私有前提。

min需要独立int输出，空树T_EMPTY、NULL输出T_INVALID，失败不写。inorder先检查输出数量指针、数组和capacity，不足T_SPACE，不写数组或数量。所有对象为已初始化有效对象，输出与树存储分离，单线程使用，不自行改公开字段。

## 39.9 成本首先看高度h

查找、插入、删除都沿若干根到叶路径，时间O(h)；min也O(h)。中序和clear访问全部节点，Θ(n)，递归额外栈O(h)。对象保存count，所以直接读数量O(1)。

若树较均衡，h=O(log n)，查询较短；但普通BST不主动平衡。按0、1、2……62插入，会得到63层右链，查最大键需63次节点访问，最坏O(n)。没有指定随机输入模型，不能无条件宣传平均O(log n)。

节点总空间O(n)，递归删/释放的栈最坏O(n)；63项是本课预算，不是证明所有输入都平衡。下一章让修改主动约束高度。

## 39.10 常见错误

只查直接孩子不查全部子树；重复键随意放一侧；插入先接节点再判断malloc；删根忘更新root；单孩子删除把孩子也释放；双孩子只换key不删后继导致重复；count减两次；错误选择右最大；持有旧节点地址当永久身份；用key±1设置验证边界导致极端int溢出。

## 39.11 练习与参考答案

练习一：4的右子树根6且6有左5，后继是谁？答案：5，不是6。

练习二：只有一个节点，删除后root/count如何？答案：NULL/0；节点只释放一次，再删返回T_MISSING。

练习三：BST是否保证中序连续整数？答案：只保证严格递增，允许缺口；例如-8、2、100完全合法。

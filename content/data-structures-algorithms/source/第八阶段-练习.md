# 第八阶段练习：依赖、路线与连接成本

建议另留10—14小时。先预测和手算，再编译运行，最后看 [参考答案](第八阶段-参考答案.md)。记录终端、目录、命令、实际输出与原因；没有运行的故障/平台项目不写通过。

## 一、存储与遍历

画第43章矩阵和邻接行，数逻辑边、弧及自环的数学度数；把零权边改为不存在，解释has为何必须独立。测试反向重复、删除缺失、权重1001、顶点8，检查失败旧图保持。

手推0—1、0—3、1—2、2—3加孤立4的DFS/BFS，列parent、depth、队列及分量。给出DFS树深不最短的顶点；再解释有向分量接口为什么拒绝。

## 二、拓扑与环

为0/1先于2、2先于3列所有可能顺序；按Kahn每步记录入度。加3→1后，为什么旧count仍4却不能当新计划？举“环下游但不在环上”的顶点例子。

另用0→1、2独立，预测本FIFO顺序，解释它与字典序最小的区别。不要通过排序最终输出伪造合法拓扑。

## 三、最短路

对第46章5点样本逐轮列暂定距离/已确定集合，沿parent逆向再正向恢复0到3。比较边数最少与权和最小，给一条负边使Dijkstra证明失效的反例。

手算第47章有限负边分层表；再给0→1、1→2=-2、2→1=1、2→3=4、4孤立分别标三态。若把负环移到源不可达处，单源和全点对哪些结果变化？解读Floyd0到2受影响而0到0仍有限的情况。

## 四、并查集与森林

对0..4逐次union(1,2)、union(0,2)、union(1,3)、union(0,3)，记录merged、组件数、根size；做find后哪些字段可能改、哪些业务分组不变？

手推样本Kruskal/Prim，忽略负自环后选哪些边？验证V-C、总权与原分量。给出MST并不是源最短路树的三角形反例。空图/全部孤立/负权普通边应怎样返回？

## 五、组合实验与错误结果

按README编译关系实验台，运行study、study cycle、route 0 4、route 0 5、route 2 2及非法编号。区分计算成功但不可达、输入不合法、依赖有环，不把所有非数字输出都叫程序失败。

尝试在自己的练习副本中只做一项安全逻辑改动：忽略0权边、拓扑接受部分顺序、负环只传播一次或Prim只从0开始。观察哪个检查能发现；不要运行故意越界、溢出或无效指针实验，正式源码保持。

运行维护者验证器后，分别解释小图穷举、简单路径/环参考、全部边子集参考为何比“两个算法答案相同”更有力。说明有限穷举仍没覆盖什么，以及为何无动态申请的本批没有malloc失败实验。

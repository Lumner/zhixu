# 数据结构与算法：从零学习C语言

先读 [整体规划与学习路线](00-整体规划与学习路线.md)，再从 [第01章](01-从生活问题到算法.md) 顺序学习。

截至2026-11-12，已交付第01—52章详细正文、9阶段和最终v1.0工程，基础主线完整。

- 第一阶段01—08：C起步与数组，27—40小时，学习分钟统计器。
- 第二阶段09—16：字符串、指针、内存、程序组织与文件，39—56小时，资料目录v0.2。
- 第三阶段17—20：规格、不变量、复杂度、递归与查找，24—33小时，查找对照实验台。
- 第四阶段21—26：顺序表、扩容、单/双向循环链表、栈与队列，34—48小时，括号与后缀表达式实验。
- 第五阶段27—30：朴素匹配与KMP、拉链与开放寻址、索引一致性，30—42小时，内存索引目录v0.3a。
- 第六阶段31—36：九种排序、稳定性与操作计数、资料目录v0.3，42—60小时。
- 第七阶段37—42：树、遍历、BST、AVL插入、堆/堆排序、哈夫曼，46—65小时。
- 第八阶段43—48：图存储、遍历、拓扑、最短路径、并查集与最小生成森林，48—67小时。
- 第九阶段上49—51：贪心反例、回溯/剪枝、位掩码与4×4数独、记忆化/表格、零钱/背包恢复，33—47小时。
- 第九阶段下52：分类/业务ID/先修/就绪/路线/导出整合与故障验证，16—24小时，含练习。
- 累计63组完整程序/工程，全课339—482小时，含独立练习与排错。

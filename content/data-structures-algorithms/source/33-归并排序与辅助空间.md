# 33 归并排序与辅助空间

## 33.1 目标与先修

先完成递归、半开区间、稳定性和动态内存。建议5—7小时。目标是分清“递归排好两边”和“合并两边”这两个任务，跟踪三个下标，解释线性合并、相等取左与申请失败保留。

想象两叠资料分别按分钟排好。比较两叠最上面的一份，把较小者放到新叠末尾，再重复；一叠用尽后，另一叠按顺序全部接上。归并排序先把大问题拆小，再用这个合并动作逐层拼回。

## 33.2 分治：拆成同类的小问题

**分治divide and conquer**是把问题分成更小的同类问题，分别解决，再合成结果。这里对区间[lo,hi)计算mid=lo+(hi-lo)/2，递归排序[lo,mid)与[mid,hi)，最后合并。

hi不属于区间，长度为hi-lo；长度小于2直接返回，因为空或单项已经有序。n=5会分2项和3项，不要求长度是2的幂，也不需要补虚构记录。

```text
[0,5)
  [0,2) -> [0,1) 与 [1,2) -> 合并
  [2,5)
    [2,3)
    [3,5) -> [3,4) 与 [4,5) -> 合并
    合并 [2,3) 与 [3,5)
  最后合并 [0,2) 与 [2,5)
```

每层区间都更短，因此会终止；递归返回时，左右各自有序是接下来合并的前提，不是合并函数凭空假设的事实。

## 33.3 两个读取位置，一个写入位置

left从lo读左半，right从mid读右半，dest从lo写辅助数组work。当两边都没用尽，比较a[left].key与a[right].key，把较小记录写work[dest]，对应读下标和dest各前进一步。

循环不变量：work[lo,dest)已按顺序放好两边已消费记录；这些记录是原两半中目前最小的若干项；尚未消费的第一项分别由left/right指向。每次至少消费一项，因此合并会结束。

不在a中边读边覆盖，是因为尚未读取的记录可能被提前写入破坏。work让读取的两半在本次合并期间保持不动，最后统一复制回a[lo,hi)。

## 33.4 从有序小段合成大段

以`3:A,1:B,2:C,1:D,3:E`为例，左右递归返回后是`[1:B,3:A]`与`[1:D,2:C,3:E]`：

| 比较/动作 | 取出的记录 | work有效前缀 |
| --- | --- | --- |
| 1:B与1:D，相等取左 | 1:B | 1:B |
| 3:A与1:D | 1:D | 1:B,1:D |
| 3:A与2:C | 2:C | 1:B,1:D,2:C |
| 3:A与3:E，相等取左 | 3:A | 1:B,1:D,2:C,3:A |
| 左边用尽，接右边 | 3:E | 全部5项 |

只在两边都有项时比较。接剩余一边时不再读另一边的头，不拿无效下标参与“最后一次比较”。

## 33.5 为什么相等时取左很关键

左右子区间在原输入中也是左边在先。递归已经保持各自内部同键顺序；合并再让左侧相等项先出，就保持跨两半的原相对顺序。由小区间到整个数组归纳，本实现稳定。

若把<=改成<，相等时会走右边。例如左右各只有一条相同键记录，右侧就先出，立即构成不稳定反例。整体key序仍可能完全正确，所以只查有序抓不住这种错误。

## 33.6 辅助空间怎样申请与归还

公开merge_sort先验证n与输出，再一次申请n条SItem空间，所有递归共用同一个work。每次只使用自己区间对应的格，不需要每层再malloc整张数组。

n<=128限制了本课资源；Windows主线中两int的SItem足够小，乘法在预算内。推广到任意n时须在分配前核对n<=SIZE_MAX/sizeof *work，不能只检查malloc返回值来补救已经溢出的乘法。

若malloc失败，立即S_MEMORY，输入和*out都还没改。成功后递归部分不再申请，也没有业务失败分支；排序完成free(work)，最后写统计。n=0或1不申请，成功统计清零。调用者不需要也不能释放这个局部辅助数组。

## 33.7 完整C实现与表达式说明

完整文件merge.c：

```c
#include "sort_internal.h"
#include <stdlib.h>
static void merge_range(SItem *a, SItem *work, size_t lo, size_t hi, SortStats *stats)
{
    if (hi - lo < 2) { return; }
    size_t mid = lo + (hi - lo) / 2;
    merge_range(a, work, lo, mid, stats);
    merge_range(a, work, mid, hi, stats);
    size_t left = lo, right = mid, dest = lo;
    while (left < mid && right < hi) {
        if (sort_compare(a[left].key, a[right].key, stats) <= 0) {
            sort_write(work, dest++, a[left++], stats);
        }
        else { sort_write(work, dest++, a[right++], stats); }
    }
    while (left < mid) { sort_write(work, dest++, a[left++], stats); }
    while (right < hi) { sort_write(work, dest++, a[right++], stats); }
    for (size_t i = lo; i < hi; i++) { sort_write(a, i, work[i], stats); }
}
SortStatus merge_sort(SItem *a, size_t n, SortStats *out)
{
    SortStatus status = sort_validate(a, n, out);
    if (status != S_OK) { return status; }
    SortStats stats = {0, 0};
    if (n > 1) {
        SItem *work = malloc(n * sizeof *work);
        if (work == NULL) { return S_MEMORY; }
        merge_range(a, work, 0, n, &stats);
        free(work);
    }
    *out = stats;
    return S_OK;
}
```

`sort_write(work,dest++,a[left++],stats)`使用dest旧值作为写位置、left旧值作为读位置，各自随后增加；它们是不同变量。它不是让同一个变量在一条表达式里被多次无序修改。初学时可以等价地分成“写、dest加1、left加1”三行，结果相同。

mid的写法避免lo+hi先相加；左右长度之和恰好hi-lo。work写完本区间所有有效位置后才复制，未初始化的其他格从不读取。

## 33.8 时间与空间怎样推出来

合并k项最多做k-1次键比较，每项写到work一次、写回a一次，合并工作Θ(k)。同一层各区间互不重叠，总长度n，所以每层Θ(n)。区间不断折半，约log₂n层，整体Θ(n log n)，无论原来有序还是逆序；本版没有“已排好就跳过合并”的优化。

辅助记录数组Θ(n)，递归深度Θ(log n)，合计额外空间Θ(n)。这是当前数组归并实现的结论，不代表所有归并变体都必须这样分配。

例如32项已有序：每层记录写入2n，共5层，所以writes=320；各层比较总80。比较数字与记录写入不是同一回事，不能只看一个就估计真实耗时。

## 33.9 编译、运行与输出原因

把 [公共5文件](示例代码/stage6-common/README.md)、[merge.c](示例代码/33-merge/merge.c)、[main.c](示例代码/33-merge/main.c) 放自己的`~/dsa-labs/ch33`。在 **UCRT64 Bash、该目录**：

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic main.c merge.c sort_common.c demo.c -o merge.exe
./merge.exe
```

预期：

```text
merge comparisons=8 writes=24
1:1 1:3 2:2 3:0 3:4
```

键1的原标记1、3顺序保留，键3的0、4也保留。n=5各次合并长度为2、2、3、5，总写入2*(2+2+3+5)=24。不是把log₂5四舍五入后简单乘2n。

## 33.10 常见错误

把hi当最后有效下标；左右递归重叠或漏mid；长度1还继续分；直接覆盖a导致未读记录丢失；left/right用尽后仍读；相等取右而宣称稳定；每层重复申请整张n空间却不计；先修改输入再申请辅助数组；忘记free或在每次递归返回都释放同一work。

## 33.11 练习与参考答案

练习一：合并两段长度2和3，最多比较几次？答案：4；一边用尽后直接接另一边，不必再比较键。

练习二：8项时本版记录写入多少？答案：3层，每层2*8，共48，n为2的幂且无跳过优化。

练习三：申请失败时统计原值该变成0吗？答案：本接口失败保留*out，不能写0假装完成了一次零成本排序。成功的空排序才把统计写0。

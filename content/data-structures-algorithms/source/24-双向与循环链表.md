# 24 双向与循环链表

## 24.1 目标与先修

先完成单链表与所有权。建议4—6小时。本章给节点增加previous，理解双向关系，再用一个循环哨兵统一空、头、尾情况。重点是同时维护两个方向，不只让正向打印看起来正确。

在资料浏览中，既想“下一条”也想“上一条”。单链表只记后继，反向查找需要从头重新走；双向节点额外保存前驱，换取局部反向访问能力。

## 24.2 双向与循环是两个不同维度

双向描述每个节点有previous与next；循环描述末尾如何结束。双向链表可以用NULL结尾，也可以接回哨兵。单链表也可循环，不能把“双向”和“循环”当同一个词。

普通双向链的概念形式是：`NULL ← 10 ⇄ 20 ⇄ 30 → NULL`。本章完整实现选择循环哨兵root：

```text
root ⇄ 10 ⇄ 20 ⇄ 30 ⇄ root
空时：root.next与root.previous都指回root
```

root.value不存真实元素，count不包括root。遍历的结束条件是回到root，不是遇到NULL；若仍用while(node!=NULL)，合法循环表也可能永远跑下去。

## 24.3 表示不变量

- 从root.next正向经过count个真实节点，下一步回到root。
- 从root.previous反向经过相同数量节点，再回到root。
- 对每个连接，next的previous必须接回当前节点，previous的next也必须接回当前节点。
- 空表两个方向都指root，真实节点唯一归属此表。

只更新next忘记previous，可能正向遍历仍成功，却在反向或下一次删除时失败。验证必须检查两边，不以一张正向输出截图作全部证据。

## 24.4 root的位置必须稳定

root内嵌在DList中，其他节点和空表链接会保存`&list.root`。所以DList不能初始化后按值复制、memcpy或随意搬到另一地址；即使空表，复制后的指针仍可能指向原对象的root。

这比普通“指针浅拷贝会共享分配”还多一层自引用问题。使用时创建一个DList，init后保持其地址稳定，通过DList*传给函数，最后clear。不在函数中创建局部DList再按值返回一个已连好的表。

## 24.5 插在某节点之前的四条关系

找出要插入位置的后继next，前驱是next.previous。新节点先写好previous和next，然后：

```text
原前驱.next = 新节点
原后继.previous = 新节点
```

空表时原前驱与原后继都是root，这两句自然同时建立root.next和root.previous。末尾插入时next就是root，因此不调用不存在的第count个真实节点。

分配失败之前不修改任何连接。按位置定位仍有遍历，本实现从较近一端出发，访问位置p需O(min(p+1,n-p))步；已知相邻节点之后的接链才是Θ(1)。

## 24.6 删除的对称关系

对真实node，先保存值，再让node.previous.next=node.next，让node.next.previous=node.previous，然后free。最后数量减1，把值写给独立输出变量。

删除唯一节点时，前后都是root，两条赋值让root重新连回自己，不需要把root释放。位置检查保证不会把哨兵当真实元素删除。

clear正向保存next再释放，到root停止，最后重新建立空环。不能在free之后再读取node.previous或next，也不能把旧节点指针带到clear之后使用。

## 24.7 完整接口与实现

下载 [doubly.h](示例代码/24-doubly/doubly.h)、[doubly.c](示例代码/24-doubly/doubly.c)、[main.c](示例代码/24-doubly/main.c) 与 [共享头](示例代码/stage4-common/ds_status.h)，放到自己的`~/dsa-labs/ch24`。

完整文件doubly.h：

```c
#ifndef DSA_DOUBLY_H
#define DSA_DOUBLY_H
#include "ds_status.h"

typedef struct DNode { int value; struct DNode *previous; struct DNode *next; } DNode;
typedef struct { DNode root; size_t count; } DList;
void dlist_init(DList *list);
void dlist_clear(DList *list);
DsStatus dlist_get(const DList *list, size_t position, int *out);
DsStatus dlist_set(DList *list, size_t position, int value);
DsStatus dlist_insert(DList *list, size_t position, int value);
DsStatus dlist_erase(DList *list, size_t position, int *out);
#endif
```

完整文件doubly.c：

```c
#include "doubly.h"
#include <stdlib.h>

void dlist_init(DList *list)
{
    list->root.next = list->root.previous = &list->root;
    list->count = 0;
}

void dlist_clear(DList *list)
{
    DNode *node = list->root.next;
    while (node != &list->root) {
        DNode *next = node->next;
        free(node);
        node = next;
    }
    dlist_init(list);
}

static DNode *node_at(const DList *list, size_t position)
{
    DNode *node;
    if (position < list->count / 2) {
        node = list->root.next;
        for (size_t i = 0; i < position; i++) {
            node = node->next;
        }
    } else {
        node = list->root.previous;
        for (size_t i = list->count - 1; i > position; i--) {
            node = node->previous;
        }
    }
    return node;
}

DsStatus dlist_get(const DList *list, size_t position, int *out)
{
    if (out == NULL) {
        return DS_INVALID;
    }
    if (position >= list->count) {
        return DS_RANGE;
    }
    *out = node_at(list, position)->value;
    return DS_OK;
}

DsStatus dlist_set(DList *list, size_t position, int value)
{
    if (position >= list->count) {
        return DS_RANGE;
    }
    node_at(list, position)->value = value;
    return DS_OK;
}

DsStatus dlist_insert(DList *list, size_t position, int value)
{
    if (position > list->count) {
        return DS_RANGE;
    }
    if (list->count == DS_MAX_ITEMS) {
        return DS_FULL;
    }
    DNode *next = position == list->count ? &list->root : node_at(list, position);
    DNode *node = malloc(sizeof *node);
    if (node == NULL) {
        return DS_MEMORY;
    }
    node->value = value;
    node->previous = next->previous;
    node->next = next;
    next->previous->next = node;
    next->previous = node;
    list->count++;
    return DS_OK;
}

DsStatus dlist_erase(DList *list, size_t position, int *out)
{
    if (out == NULL) {
        return DS_INVALID;
    }
    if (position >= list->count) {
        return DS_RANGE;
    }
    DNode *node = node_at(list, position);
    int saved = node->value;
    node->previous->next = node->next;
    node->next->previous = node->previous;
    free(node);
    list->count--;
    *out = saved;
    return DS_OK;
}
```

node_at是内部辅助函数，只在位置已经确认有效时调用。它不会替所有外部任意位置自行补边界；公开get/set/erase先检查，insert的末尾分支直接选root，避免count=0时计算count-1。

## 24.8 什么时候选哪种表示

| 表示 | 直接按位置访问 | 已知合适位置后的修改 | 代价与限制 |
| --- | --- | --- | --- |
| 连续数组 | 常数 | 可能搬动后缀 | 连续存储、扩容可能使借用地址失效 |
| 单链表 | 通常需走链 | 已知前驱可常数接链 | 每节点一个next，反向困难 |
| 双向链表 | 通常需走链 | 已知节点可局部摘链 | 每节点两个链接，维护更复杂 |

链表不是每种任务都更快。CPU缓存、每节点分配、内存开销和定位方式都会影响实际选择；复杂度结论首先看完整操作，不只看改了几条箭头。

本版仍有64条实验预算，不提供任意节点地址作为公开删除接口；若以后增加这种接口，还要定义节点是否属于本表、删除后借用何时失效。

## 24.9 常见错误

- 混淆双向与循环，按NULL作为本实现的结束条件。
- 只改一个方向，反向关系与数量脱节。
- 把root当元素，读其无业务意义的value。
- 空表在node_at内部计算count-1，没有走公开位置检查。
- 初始化后复制或移动DList，留下指向旧root的自引用。
- 声称双向表按下标也是常数时间，忽略定位。

## 24.10 练习与参考答案

练习一：空表插入一条，再删除它，root的四个相关连接怎样变化？

答案：插入后root.next与root.previous都指新节点，新节点两侧指root；删除后root两个字段都回到root。

练习二：正向能打印10、20、30，能证明反向正确吗？

答案：不能。还要检查previous及相邻互反关系和反向数量。

练习三：为什么空DList也不能随便按值复制？

答案：空环指针存的是原root的地址，复制字段不自动把它们重定向到新root。

# 32 插入排序与希尔排序

## 32.1 目标与先修

先完成第31章的记录、稳定性和统计口径，建议5—7小时。目标是用“有序前缀”解释插入排序，手推保存与右移，比较顺序/逆序工作量，再说明希尔的分组有序与不稳定性。

拿扑克牌时，常先把手里的牌排好，再把新牌插到合适位置。程序用数组表达同一个动作：先保存新项，让更大的旧项右移，最后填回空出的位置。

## 32.2 插入前，哪一部分已经有序

进入第i趟时，[0,i)是已经有序的前缀，a[i]是待插入项；i从1开始，因为单个第0项天然有序。saved保存完整记录，j从i向左找位置。

当a[j-1].key>saved.key，把a[j-1]写到a[j]，j减1。循环结束有两种原因：j=0，已到最左；或左侧键<=saved.key，当前j就是可插入位置。最后把saved写入a[j]，有序前缀扩展为[0,i+1)。

## 32.3 一趟一趟演算，不只看最后结果

| 趟i | 待插入 | 右移项 | 本趟完成的数组 |
| --- | --- | --- | --- |
| 初始 | — | — | 4,1,3,2 |
| 1 | 1 | 4 | 1,4,3,2 |
| 2 | 3 | 4 | 1,3,4,2 |
| 3 | 2 | 4，再3 | 1,2,3,4 |

右移过程数组会暂时出现重复内容，真正的新记录保存在saved中；这不是丢记录，只要最后正确写回。不能在移位时又从已覆盖的a[i]读取“原待插入项”。

有序前缀里，右移的都是严格更大的项，移后顺序不变；左侧保留项都<=saved，右侧移动项都>saved。因此最后填入后仍有序，并保留所有记录。

## 32.4 相等时停下来，才能稳定

已有`2:A`，新项`2:B`的键相同，不右移A，B落在A之后。前缀逐渐扩展，所有相等键都按进入前缀的先后保留，故本实现稳定。若把>改成>=，B会越过A。

“找到插入位置”不等于必须调用第20章二分查找。即使用二分降低比较次数，数组中间仍要移动记录；那是二分插入排序变体，不能把其整个过程称为O(log n)。本章用向左扫描，便于看清每次移动。

## 32.5 已排序与逆序的差距

已有序时，每个新项只与前一项比较一次，无需右移；仍将saved写回一次，所以n>=1时comparisons=n-1、writes=n-1，最好Θ(n)。写回相同位置在本课口径里也计写入。

逆序且键不同，第i项要右移i条，总移位数1+2+…+(n-1)=n(n-1)/2；最后每趟再写saved，所以writes=n(n-1)/2+n-1，最坏Θ(n²)。

前面键大于后面键的一对位置叫**逆序对**。本版插入每右移一次恰好消除一对，移位总数等于原逆序对数；近乎有序数据逆序对少，因而常较省移动。不要把“只有一处看着不顺”直接当作严格的低成本证明，一项从末尾移到最前就要跨过很多项。

## 32.6 希尔排序：先允许跨格移动

**步长gap**是同组相邻位置相差的下标数。gap=4时，下标0、4、8是一组，1、5、9另一组；每组分别做插入排序，使整个数组达到gap有序。组在内存中交错，不是先切成四块连续数组。

希尔排序逐步减小gap。本版固定`n/2, n/4, …,1`的整数除法序列，比如n=8为4、2、1；最后gap=1时对全数组插入，保证全局有序。前面的较大步长帮助某些项较快跨过长距离，但并不保证每个输入都快。

```text
n=4，gap=2：组(0,2)与组(1,3)
初始        2:A 2:B 1:C 2:D
gap=2完成  1:C 2:B 2:A 2:D
gap=1完成  1:C 2:B 2:A 2:D
```

2:A与2:B已被跨组移动颠倒；最后稳定的gap=1插入不会修复原先顺序。因此组内只在>时右移，也不能使整个希尔稳定。

## 32.7 代码中的边界与完整实现

完整文件insertion_shell.c：

```c
#include "sort_internal.h"
SortStatus insertion_sort(SItem *a, size_t n, SortStats *out)
{
    SortStatus status = sort_validate(a, n, out);
    if (status != S_OK) { return status; }
    SortStats stats = {0, 0};
    for (size_t i = 1; i < n; i++) {
        SItem saved = a[i];
        size_t j = i;
        while (j > 0 && sort_compare(a[j - 1].key, saved.key, &stats) > 0) {
            sort_write(a, j, a[j - 1], &stats);
            j--;
        }
        sort_write(a, j, saved, &stats);
    }
    *out = stats;
    return S_OK;
}
SortStatus shell_sort(SItem *a, size_t n, SortStats *out)
{
    SortStatus status = sort_validate(a, n, out);
    if (status != S_OK) { return status; }
    SortStats stats = {0, 0};
    for (size_t gap = n / 2; gap > 0; gap /= 2) {
        for (size_t i = gap; i < n; i++) {
            SItem saved = a[i];
            size_t j = i;
            while (j >= gap && sort_compare(a[j - gap].key, saved.key, &stats) > 0) {
                sort_write(a, j, a[j - gap], &stats);
                j -= gap;
            }
            sort_write(a, j, saved, &stats);
        }
    }
    *out = stats;
    return S_OK;
}
```

`j>0 && ...`和`j>=gap && ...`利用C的短路求值：左侧为假时不计算右侧，避免先读j-1或j-gap越界。size_t不能靠j>=0控制递减，因为它始终非负。

希尔每个新组前缀也有同样插入不变量，只是位置相隔gap。n=0或1时gap=0，外循环不执行；不会拿gap=0作循环内步长。

## 32.8 时间与额外空间

插入最好Θ(n)、最坏Θ(n²)，本版额外空间Θ(1)。希尔的性能与步长序列有关；本版折半序列可给最坏O(n²)上界，不能无条件写成O(n log n)。每个gap内若都很有序，也仍需遍历各组并写回待插入项。

一种上界思路：gap为g时约g组、每组约n/g项，各组插入最坏总量约n²/g；对折半的g求和仍可由常数倍n²控制。这里只推当前序列的保守上界，不把它说成所有希尔序列的最佳结论。希尔只用局部saved与下标，额外空间Θ(1)，不稳定。

## 32.10 常见错误

未保存待插入项就覆盖它；右移方向写反；只搬键不搬tag；在j为0时先读a[j-1]；用j>=0控制size_t递减；希尔最后没有gap=1；把交错分组当连续分块；认为“组内稳定”就代表整个算法稳定；混用不同步长序列的复杂度结论。

## 32.11 练习与参考答案

练习一：5项逆序插入写入多少？答案：移位10次，填回4次，共14次；此口径不数saved赋值。

练习二：n=9的本版gap有哪些？答案：4、2、1，整数除法不会产生2.25。

练习三：把希尔反例的最后gap=1改成稳定归并，能还原A/B原顺序吗？答案：仅依据当前同键顺序不能；A/B此前已颠倒，稳定算法只会保持当前输入次序。

# 43 图的语义、矩阵与邻接表

## 43.1 目标与先修

先完成数组、结构体、树和所有权，建议5—7小时。目标是先说清关系含义，再画图和存储；分清顶点编号、方向、权重、自环、重边，正确表示零权边，并将矩阵转换成有界邻接表。

树里每个非根只有一个父节点。道路、课程先修和通信连接可能有多个入口、环或断开的部分，需要更一般的**图graph**。图不是指一张图片，而是一组对象及它们之间的关系。

## 43.2 顶点、边、方向与权重

**顶点vertex**是对象，**边edge**是关系。有向边u→v只表示u到v；无向边u—v可以两个方向使用。**权重weight**是边的数值含义，例如距离、时间或费用；先明确单位，不能把先修箭头直接当成路线距离。

路径是沿边到达的一串顶点，环会回到已出现位置。不同教材区分路径、简单路径、游走的用词可能不同：本课“简单路径”不重复顶点；讨论负环时允许反复走边，说明成本是否可无限降低。

图可以不连通，有孤立顶点；自己连自己是**自环**；相同端点关系保存多次是**重边**。有向入度/出度数进入/离开的边，无向自环在数学度数中算2，不能直接数矩阵一行。

## 43.3 统一协议与预算

最多8顶点，编号0到n-1是数组位置，不是资料目录0—9999业务ID；本批不增删顶点，graph_init可以重建整张图。n=0空图合法，directed只能0/1。

权重限-1000—1000。允许自环；拒绝重边，不静默改权；无向add(0,1)后add(1,0)也为G_DUPLICATE。删除不存在关系G_MISSING，非法顶点/参数G_INVALID，数量或权重越界G_RANGE，失败保留旧图。

对象只含数组和整数，可按值复制，不需要free。算法输入应由本API构造并保持不变量，输出为独立有效对象，不与输入重叠；字段用于观察，不自行改n、对称关系或状态。G_OK=0，应显式与枚举名比较。

## 43.4 为什么has与weight分开

**邻接矩阵**用行u列v代表u到v。has[u][v]回答有没有边，weight只在has真时有意义。权重0合法，不能同时用0代表无边。

样本无向4顶点：0—1权0，0—2权5，2自环权-1，3孤立：

| u\v | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| 0 | 无 | 0 | 5 | 无 |
| 1 | 0 | 无 | 无 | 无 |
| 2 | 5 | 无 | -1 | 无 |
| 3 | 无 | 无 | 无 | 无 |

无向矩阵对称，自环只在对角一格。逻辑edges=3，有边格共5，不能混算。

## 43.5 邻接表与弧的数量

**邻接表adjacency list**为每个顶点保存一串出邻居。这里Arc数组加next下标表示链，不用malloc；head指首弧，GRAPH_ARCS=64作结束标记，合法弧下标0—63。

无向普通边存两方向，自环本版只存一个弧；样本共5弧，数学度数仍须把自环算2。8顶点全有向含自环最多64弧；无向完全含自环逻辑36边、弧64。

v从大到小扫描并头插，最终邻居递增，方便复现实验。改变邻居顺序可能改变合法遍历次序。邻接表是转换时的副本，之后改矩阵需重新转换，不自动同步。

## 43.6 完整公共代码

完整文件graph.h：

```c
#ifndef DSA_GRAPH_H
#define DSA_GRAPH_H
#include <stddef.h>
#define GRAPH_MAX 8
#define GRAPH_ARCS (GRAPH_MAX * GRAPH_MAX)
#define GRAPH_WEIGHT_MAX 1000
typedef enum { G_OK, G_INVALID, G_RANGE, G_DUPLICATE, G_MISSING, G_SPACE, G_NEGATIVE, G_CYCLE } GStatus;
typedef struct { size_t from; size_t to; int weight; } Edge;
typedef struct { size_t n; int directed; size_t edges; unsigned char has[GRAPH_MAX][GRAPH_MAX]; int weight[GRAPH_MAX][GRAPH_MAX]; } Graph;
typedef struct { size_t to; int weight; size_t next; } Arc;
typedef struct { size_t n; size_t count; size_t head[GRAPH_MAX]; Arc arcs[GRAPH_ARCS]; } Adjacency;
GStatus graph_init(Graph *graph, size_t n, int directed);
GStatus graph_add(Graph *graph, size_t from, size_t to, int weight);
GStatus graph_remove(Graph *graph, size_t from, size_t to);
GStatus graph_adjacency(const Graph *graph, Adjacency *out);
#endif
```

完整文件graph.c：

```c
#include "graph_internal.h"
#include <limits.h>
GStatus graph_init(Graph *graph, size_t n, int directed)
{
    if (graph == NULL || (directed != 0 && directed != 1)) { return G_INVALID; }
    if (n > GRAPH_MAX) { return G_RANGE; }
    Graph next = {0}; next.n = n; next.directed = directed; *graph = next; return G_OK;
}
GStatus graph_add(Graph *graph, size_t from, size_t to, int weight)
{
    if (graph == NULL || from >= graph->n || to >= graph->n) { return G_INVALID; }
    if (weight < -GRAPH_WEIGHT_MAX || weight > GRAPH_WEIGHT_MAX) { return G_RANGE; }
    if (graph->has[from][to]) { return G_DUPLICATE; }
    graph->has[from][to] = 1; graph->weight[from][to] = weight;
    if (!graph->directed) { graph->has[to][from] = 1; graph->weight[to][from] = weight; }
    graph->edges++; return G_OK;
}
GStatus graph_remove(Graph *graph, size_t from, size_t to)
{
    if (graph == NULL || from >= graph->n || to >= graph->n) { return G_INVALID; }
    if (!graph->has[from][to]) { return G_MISSING; }
    graph->has[from][to] = 0; graph->weight[from][to] = 0;
    if (!graph->directed) { graph->has[to][from] = 0; graph->weight[to][from] = 0; }
    graph->edges--; return G_OK;
}
GStatus graph_adjacency(const Graph *graph, Adjacency *out)
{
    if (graph == NULL || out == NULL) { return G_INVALID; }
    Adjacency next = {0}; next.n = graph->n;
    for (size_t u = 0; u < GRAPH_MAX; u++) { next.head[u] = GRAPH_ARCS; }
    for (size_t u = 0; u < graph->n; u++) {
        for (size_t end = graph->n; end > 0; end--) {
            size_t v = end - 1;
            if (graph->has[u][v]) {
                size_t index = next.count++;
                next.arcs[index] = (Arc){v,graph->weight[u][v],next.head[u]}; next.head[u] = index;
            }
        }
    }
    *out = next; return G_OK;
}
GStatus graph_cost_sum(long left, long right, long *out)
{
    if (out == NULL) { return G_INVALID; }
    if ((right > 0 && left > LONG_MAX - right) || (right < 0 && left < LONG_MIN - right)) { return G_RANGE; }
    *out = left + right; return G_OK;
}
```

init验证后提交零初始化候选；add验证后才写格与计数，remove清无向两格，自环计数只减一次。转换先准备整个Adjacency，不交出半份结果。

graph_cost_sum声明在 [graph_internal.h](示例代码/stage8-common/graph_internal.h)，后续路径/森林复用。它在真正相加前检查LONG_MIN/MAX，风险返回G_RANGE且不改输出；不是先溢出再检查结果。

## 43.7 成本与表示选择

矩阵空间Θ(V²)，查边O(1)，枚举邻居需扫V格。传统邻接表空间Θ(V+E)，枚举实际邻居较省，查特定边通常需扫链。本版固定64格预算，实际对象大小固定，不假装按当前E动态申请。

转换扫描完整矩阵，Θ(V²)，不是O(E)。后续主要用矩阵，正文按真实循环报告成本，不把邻接表版常见的O(V+E)直接套上。

## 43.9 存储合法不等于算法适用

空图没有起点，遍历/单源路径会拒绝source=0；全点对、空有向拓扑或空森林可返回空结果。自环/负权在存储层合法，Dijkstra却要求非负，拓扑要求无环，MST只接无向。

将限制分到对应算法，才能用同一表示讨论不同问题。数组有界不等于能识别任意损坏对象或坏指针。

## 43.10 常见错误

用0当无边；有向边自动反向；逻辑边/弧混算；自环一律存两份；业务ID直接作下标；重复边覆盖；改矩阵后用旧邻接表；存储允许负权就认为所有算法都允许；忽略表示成本。

## 43.11 练习与参考答案

练习一：无向三角形无自环有几边/弧？答案：3/6；加一自环后4/7，数学度数另算。

练习二：has=0/weight=0与has=1/weight=0相同吗？答案：前者无边，后者零权边。

练习三：为何逆序扫描头插？答案：最终邻居升序，正向头插会反序。

## 复现方法

维护者在PowerShell、网站根目录执行：

```powershell
python content/data-structures-algorithms/source/验证/verify-stage2.py
```

需要Python3.10以上和已有GCC，脚本不安装软件；临时编译产物只在本次创建的系统临时目录生成并清理。学习者手动练习无需Python。程序测试、调试器、浏览器和工具安装分别记录。

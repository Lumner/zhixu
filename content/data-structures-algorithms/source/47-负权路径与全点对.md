# 47 Bellman-Ford、负环与Floyd全点对

## 47.1 目标与先修

先完成松弛、三态距离与路径恢复，建议8—11小时。目标是按轮次推导Bellman-Ford，区分负边与负环、源可达与目标受影响，用Floyd求全点对并解释为什么不能把负环影响一概扩大到整图。

负边不自动意味着无最短路：0→1=4、1→2=-2而没有回路，0到2仍有有限最短成本2。真正造成无下界的是可反复走的负总和环，并且它必须在相应查询能够经过的范围内。

## 47.2 至多k条边的分层思路

Bellman-Ford先令源0、其余未达。第k轮尝试把上一轮的已知路线再接一条边，并保留不接边的旧结果。于是第k轮结束得到“至多k条边”的最佳成本。

本实现每轮复制previous，候选只从previous读取，再写next，避免一轮中沿扫描顺序连续传播许多条边。其他常见原地版本同样可正确，但轮次中间状态不同，不能拿两份表逐格混比。

有限最短路线若无相关负环，可以去掉重复顶点间的非负环，选一条简单路径，最多V-1边，因此做V-1轮足够。若某轮无任何变化，之后也不会变化，可提早停止。

## 47.3 先手算一份无负环输入

概念演算用0→1=4、0→2=5、1→2=-2、2→3=3：

| 轮次 | d0 | d1 | d2 | d3 |
| --- | --- | --- | --- | --- |
| 0 | 0 | U | U | U |
| 1 | 0 | 4 | 5 | U |
| 2 | 0 | 4 | 2 | 8 |
| 3 | 0 | 4 | 2 | 5 |

第2轮的d3=8来自上一轮d2=5，不能同轮立刻用新d2=2得到5。最终路径0,1,2,3成本5。下面main改用负环样本，分别展示不同输出状态。

## 47.4 第V轮仍能改进意味着什么

V-1轮后，再查看能否从源可达顶点经一条边严格改进某v。若可以，说明可达范围内存在负环；否则有限简单路径界已足够，不会再出现更优结果。

先标这些可改进的v，再沿出边传播，所有它们能通往的目标都标PATH_NEGATIVE。只标环点不够，下游目标也能先绕环再走过去，成本无下界；未从源到达的负环则不影响这次单源结果。

例如0→1，1→2=-2，2→1=1，2→3=4，4孤立：0仍有限0；1、2、3受影响；4不可达。不能给1某个很小负数就当最终最短。

## 47.5 完整Bellman-Ford实现

完整文件bellman.c：

```c
#include "shortest_internal.h"
GStatus graph_bellman(const Graph *graph, size_t source, Shortest *out)
{
    if (graph == NULL || out == NULL || source >= graph->n) { return G_INVALID; }
    Shortest next; graph_paths_begin(&next, graph->n, source);
    for (size_t pass = 1; pass < graph->n; pass++) {
        Shortest previous = next; int changed = 0;
        for (size_t u = 0; u < graph->n; u++) {
            if (previous.state[u] != PATH_FINITE) { continue; }
            for (size_t v = 0; v < graph->n; v++) {
                if (!graph->has[u][v]) { continue; }
                long cost; GStatus status = graph_cost_sum(previous.distance[u], graph->weight[u][v], &cost);
                if (status != G_OK) { return status; }
                if (next.state[v] == PATH_UNREACHABLE || cost < next.distance[v]) {
                    next.state[v] = PATH_FINITE; next.distance[v] = cost; next.parent[v] = u; changed = 1;
                }
            }
        }
        if (!changed) { break; }
    }
    int affected[GRAPH_MAX] = {0};
    for (size_t u = 0; u < graph->n; u++) {
        if (next.state[u] != PATH_FINITE) { continue; }
        for (size_t v = 0; v < graph->n; v++) {
            if (!graph->has[u][v]) { continue; }
            long cost; GStatus status = graph_cost_sum(next.distance[u], graph->weight[u][v], &cost);
            if (status != G_OK) { return status; }
            if (next.state[v] == PATH_UNREACHABLE || cost < next.distance[v]) { affected[v] = 1; }
        }
    }
    for (size_t pass = 0; pass < graph->n; pass++) {
        for (size_t u = 0; u < graph->n; u++) { if (affected[u]) { for (size_t v = 0; v < graph->n; v++) { if (graph->has[u][v]) { affected[v] = 1; } } } }
    }
    for (size_t v = 0; v < graph->n; v++) { if (affected[v]) { next.state[v] = PATH_NEGATIVE; next.parent[v] = GRAPH_MAX; } }
    *out = next; return G_OK;
}
```

函数G_OK表示分析完成，即使部分state为NEGATIVE。它不因一个负环就拒绝全部结果；与Dijkstra的G_NEGATIVE输入拒绝、graph_path对受影响目标的G_NEGATIVE区分。

负环点/下游的parent清为8，不能恢复一条“无限短路径”。本版传播最多V遍以覆盖最坏编号逆序链；只传播一遍可能漏掉后来才标出的低编号顶点。

## 47.6 Floyd：逐个允许中间顶点

**全点对all pairs**同时求每个u到每个v，而不是只选一个源。Floyd令Dᵏ表示仅允许编号0到k-1作为中间顶点的成本；下一阶段比较旧D[u][v]与D[u][k]+D[k][v]。

初始对角0代表空路线，已有边用其权重；正自环不比空路线更优，负自环需保留以检测无下界。两段都可达才相加，不把未达占位0当实际距离。

本实现也用previous快照，让每个k只读上一阶段。例0→1=4、1→2=-2、0→2=5，在允许1时0到2由5改2。主算法结束，若某k对角距离<0，则所有能u→k且k→v的(u,v)标NEGATIVE；其余有限/未达各自保留。

## 47.7 完整Floyd与数值边界

完整文件floyd.c：

```c
#include "shortest_internal.h"
GStatus graph_floyd(const Graph *graph, AllPairs *out)
{
    if (graph == NULL || out == NULL) { return G_INVALID; }
    AllPairs next = {0}; next.n = graph->n;
    for (size_t u = 0; u < graph->n; u++) {
        next.state[u][u] = PATH_FINITE;
        for (size_t v = 0; v < graph->n; v++) {
            if (graph->has[u][v] && (u != v || graph->weight[u][v] < 0)) { next.state[u][v] = PATH_FINITE; next.distance[u][v] = graph->weight[u][v]; }
        }
    }
    for (size_t k = 0; k < graph->n; k++) {
        AllPairs previous = next;
        for (size_t u = 0; u < graph->n; u++) {
            for (size_t v = 0; v < graph->n; v++) {
                if (previous.state[u][k] != PATH_FINITE || previous.state[k][v] != PATH_FINITE) { continue; }
                long cost; GStatus status = graph_cost_sum(previous.distance[u][k], previous.distance[k][v], &cost);
                if (status != G_OK) { return status; }
                if (next.state[u][v] == PATH_UNREACHABLE || cost < next.distance[u][v]) { next.state[u][v] = PATH_FINITE; next.distance[u][v] = cost; }
            }
        }
    }
    AllPairs finite = next;
    for (size_t u = 0; u < graph->n; u++) {
        for (size_t v = 0; v < graph->n; v++) {
            for (size_t k = 0; k < graph->n; k++) {
                if (finite.state[u][k] == PATH_FINITE && finite.state[k][v] == PATH_FINITE && finite.distance[k][k] < 0) { next.state[u][v] = PATH_NEGATIVE; }
            }
        }
    }
    *out = next; return G_OK;
}
```

分类前复制finite，不能边把state改NEGATIVE边拿改后的FINITE判断可达，否则可能漏掉后续受影响对。这里不输出Floyd前驱矩阵，仅给状态和有限距离；路径恢复仍用单源结果。

快照版初始路线至多1边，每个阶段最多拼两条旧路线，8阶段最多256边、绝对成本<=256000，落在long范围；Bellman分层候选至多8边、<=8000。仍用检查相加，避免未来扩展直接引入未定义溢出。负环时中间数值只是检测工具，不作为最终有限答案。

## 47.8 负环按查询范围判断

Floyd样本加入2→1=1后，1↔2总权-1；0能到环且环能到2，所以0到2NEGATIVE。但环不能回0，0到0仍有限0；孤立3到自己也有限0。

无向负边u—v可来回走u→v→u，不断降低成本，因此在允许重复走边的最短路线模型中，该连通部分受影响；这与“无向简单环是否允许同边两次”的术语不同。第48章生成树只选无环的边集，负边在那里完全可用。

## 47.10 成本与常见错误

本Bellman每轮扫描矩阵V²，松弛与传播最坏均O(V³)，工作O(V)；边表版常见O(VE)，不能漏掉当前空格扫描。Floyd阶段快照与三重循环O(V³)，工作/结果O(V²)。所有参数错误保留out，空图Floyd成功为空，单源无法选起点。

常见错误：负边等于负环；任何负环都污染全图；只标环不标下游；未达也相加；把原地表与快照表逐轮混比；NEGATIVE仍打印distance占位；Floyd分类中覆盖可达状态后再读；负环对角小负数当最短；矩阵实现写成边表复杂度。

## 47.11 练习与参考答案

练习一：负环在源不可达部分，Bellman全部失败吗？答案：不会，保留该部分不可达，本次分析G_OK。

练习二：0能到负环但环不能回0，0到0是否无下界？答案：不一定，需环还能通往目标0才受影响。

练习三：为什么Floyd先留finite副本？答案：标记NEGATIVE只改变结论，不应抹掉用于判定其他对的可达证据。

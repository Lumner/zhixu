# 26 队列、绕回与排队

## 26.1 目标与先修

先完成栈、链表、数组与取余。建议5—7小时。本章实现循环数组队列和带尾指针的链队列，解释先进先出、空满与绕回，再把队列和栈组合到后缀表达式实验中。

排队取号先来的先办理。先入队10，再20，先出队的应是10。这叫**先进先出**，FIFO。队头负责取出，队尾负责加入；它与栈不是按名字不同，而是允许操作的端点和顺序不同。

## 26.2 为什么不每次把数组全部左移

如果出队后把所有剩余元素左移，结果可以正确，但每次Θ(n)。另一种表示只移动队头下标，让新元素复用前面腾出的格子。

循环队列用capacity、head、count：head指第一个有效元素，count是数量；第j个逻辑元素在`(head+j)%capacity`。物理下标绕回，逻辑顺序仍然是排队顺序，不是把数值排序。

本实现物理最多16格，运行时capacity允许1—16；成功init后capacity>0，所以取余不会除0。无效capacity返回DS_INVALID，不改旧状态；未成功初始化的对象不能继续push/pop。

## 26.3 用数量区分空和满

空为count=0，满为count=capacity，下一写入位置为`(head+count)%capacity`。满时这个位置也可能等于head，但必须先检查满，不能覆盖队头。

```text
capacity=3，入10、20：   [10][20][备用] head=0 count=2
出10，再入30：          [旧值][20][30] head=1 count=2
再入40，写位置0：       [40][20][30] head=1 count=3
逻辑顺序：20、30、40
```

有的实现只存head/tail并浪费一格来区分空满，那是另一套表示。这里存count，可以使用全部capacity格，capacity=1也能正常工作。不要把两套空满公式拼在一起。

当前预算保证head+count至多31，不会在取余前溢出。推广到可能接近size_t上限的容量时，还要检查求和或使用等价分支，不能把取余当成能修复已经发生的溢出。

## 26.4 循环数组的操作不变量

push先查满，再写新尾、增加count；旧的逻辑序列保持，新元素在最后。pop先查空，取data[head]，令head前进并绕回，再count减1；剩余顺序不变。

删到空时head可以不是0，只要仍在合法范围，count为0就表示没有元素。peek只观察队头，不改head与count。读出的值写到调用者独立变量，空或NULL输出时不改变量。

按当前表示，push/pop/peek的结构操作都是Θ(1)，不移动整个序列。

## 26.5 链队列为什么保存两个端点

链队列head指第一节点，tail指最后节点，tail.next=NULL。入队在尾接一个新节点，出队摘掉头节点，因此两种操作不必每次走完整条链。

空表不变量是head与tail都NULL、count=0。出队删掉最后一个节点后，必须同时把tail设NULL；只改head会留下指向已释放节点的尾地址，下一次入队可能访问失效对象。

先申请并初始化新节点，成功后再连接；失败不改旧队列。本版链队列也有64项预算。clear保存next再释放所有真实节点，最后两端归NULL。

## 26.6 完整接口与实现

下载 [queue.h](示例代码/26-queue/queue.h)、[queue.c](示例代码/26-queue/queue.c)、[main.c](示例代码/26-queue/main.c) 与 [共享头](示例代码/stage4-common/ds_status.h)，放到自己的`~/dsa-labs/ch26`。

完整文件queue.h：

```c
#ifndef DSA_QUEUE_H
#define DSA_QUEUE_H
#include "ds_status.h"

#define QUEUE_MAX_CAPACITY 16
typedef struct { int data[QUEUE_MAX_CAPACITY]; size_t capacity; size_t head; size_t count; } Queue;
typedef struct QNode { int value; struct QNode *next; } QNode;
typedef struct { QNode *head; QNode *tail; size_t count; } LinkedQueue;
DsStatus queue_init(Queue *queue, size_t capacity);
DsStatus queue_push(Queue *queue, int value);
DsStatus queue_pop(Queue *queue, int *out);
DsStatus queue_peek(const Queue *queue, int *out);
void lqueue_init(LinkedQueue *queue);
void lqueue_clear(LinkedQueue *queue);
DsStatus lqueue_push(LinkedQueue *queue, int value);
DsStatus lqueue_pop(LinkedQueue *queue, int *out);
DsStatus lqueue_peek(const LinkedQueue *queue, int *out);
#endif
```

完整文件queue.c：

```c
#include "queue.h"
#include <stdlib.h>

DsStatus queue_init(Queue *queue, size_t capacity)
{
    if (capacity == 0 || capacity > QUEUE_MAX_CAPACITY) {
        return DS_INVALID;
    }
    queue->capacity = capacity;
    queue->head = queue->count = 0;
    return DS_OK;
}
DsStatus queue_push(Queue *queue, int value)
{
    if (queue->count == queue->capacity) {
        return DS_FULL;
    }
    size_t tail = (queue->head + queue->count) % queue->capacity;
    queue->data[tail] = value;
    queue->count++;
    return DS_OK;
}
DsStatus queue_pop(Queue *queue, int *out)
{
    if (out == NULL) {
        return DS_INVALID;
    }
    if (queue->count == 0) {
        return DS_EMPTY;
    }
    *out = queue->data[queue->head];
    queue->head = (queue->head + 1) % queue->capacity;
    queue->count--;
    return DS_OK;
}
DsStatus queue_peek(const Queue *queue, int *out)
{
    if (out == NULL) {
        return DS_INVALID;
    }
    if (queue->count == 0) {
        return DS_EMPTY;
    }
    *out = queue->data[queue->head];
    return DS_OK;
}
void lqueue_init(LinkedQueue *queue) {
    queue->head = queue->tail = NULL;
    queue->count = 0;
}
void lqueue_clear(LinkedQueue *queue)
{
    QNode *node = queue->head;
    while (node != NULL) {
        QNode *next = node->next;
        free(node);
        node = next;
    }
    lqueue_init(queue);
}
DsStatus lqueue_push(LinkedQueue *queue, int value)
{
    if (queue->count == DS_MAX_ITEMS) {
        return DS_FULL;
    }
    QNode *node = malloc(sizeof *node);
    if (node == NULL) {
        return DS_MEMORY;
    }
    node->value = value;
    node->next = NULL;
    if (queue->tail == NULL) {
        queue->head = node;
    }
    else {
        queue->tail->next = node;
    }
    queue->tail = node;
    queue->count++;
    return DS_OK;
}
DsStatus lqueue_pop(LinkedQueue *queue, int *out)
{
    if (out == NULL) {
        return DS_INVALID;
    }
    if (queue->count == 0) {
        return DS_EMPTY;
    }
    QNode *node = queue->head;
    int saved = node->value;
    queue->head = node->next;
    queue->count--;
    if (queue->head == NULL) {
        queue->tail = NULL;
    }
    free(node);
    *out = saved;
    return DS_OK;
}
DsStatus lqueue_peek(const LinkedQueue *queue, int *out)
{
    if (out == NULL) {
        return DS_INVALID;
    }
    if (queue->count == 0) {
        return DS_EMPTY;
    }
    *out = queue->head->value;
    return DS_OK;
}
```

## 26.7 双端队列与并发边界

双端队列deque允许两端加入和取出，既不同于只在一端操作的栈，也不同于普通FIFO队列。可以用环形数组或双向链表实现，但仍需一套明确接口与不变量。本章介绍概念，不把当前queue.h说成已经提供deque全部操作。

这些代码是单线程容器，没有锁、原子操作或并发等待。循环队列的“循环”指下标绕回，不表示多线程可以同时安全操作。后续图的BFS会用队列保存待处理顶点，先掌握这里的顺序与边界即可。

## 26.8 组合实验：符号排队，数值入栈

普通写法`(2+3)*4`叫中缀；把运算符放到两个操作数之后，写成`2 3 + 4 *`，叫后缀表达式。这里先不实现从中缀自动转换，而是直接接受已经给好的后缀。

先把各token（这里一个数字或运算符算一个token）按输入顺序放进队列；逐个出队。数字压入值栈；运算符弹出右操作数，再弹出左操作数，计算后压回。

| 出队token | 操作 | 值栈从底到顶 |
| --- | --- | --- |
| 2 | 压入2 | [2] |
| 3 | 压入3 | [2,3] |
| + | 算2+3，压回5 | [5] |
| 4 | 压入4 | [5,4] |
| * | 算5*4，压回20 | [20] |

最后必须恰好一个值。过少说明操作数不足，过多说明表达式没有把所有值合成一个结果。减法、除法必须区分左右，不能按弹出次序直接算right-left。

完整工程见 [表达式实验台](示例代码/stage4-expression/README.md) 与 [第四阶段答案](第四阶段-参考答案.md)。它使用受限语法、长度和数值范围，不冒充通用计算器；坏token、容量、缺操作数、除零、结果范围分别报告。详细规格独立保留，避免在这一章混入尚未讲解的语法分析器。

## 26.9 常见错误

- 出队后移动全部元素，却在报告中声称常数时间。
- 没查capacity非零就取余。
- 满时写入覆盖队头，或把head==tail直接判空。
- 逻辑顺序按物理数组0到末尾打印，忽略head绕回。
- 链队列删最后一项只清head，留下失效tail。
- 先改尾链接再检查malloc失败。
- 后缀表达式把右、左操作数颠倒，或最后还剩多个值也返回成功。

## 26.10 练习与参考答案

练习一：容量3、head=2、count=2，下次写入下标是多少？

答案：(2+2)%3=1；只有当前未满才允许写。

练习二：容量1，入5后，再入6与出队分别怎样？

答案：再入6返回DS_FULL，原5保留；出队得到5，数量归0，下次可以再入。

练习三：后缀`8 3 -`先弹出谁？结果是什么？

答案：先弹3作为右操作数，再弹8作为左，结果5。

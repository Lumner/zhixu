## 教学契约

- 从没有写过程序的读者出发，每个新词先定义；第一阶段不假定指针、结构体、递归或命令行参数基础。
- 每章给出目标与先修、生活问题、精确定义、分步解释、手算或完整可运行实验、输出原因、常见错误、自测与答案、完成条件、下一步。预计时间含手打和改错。
- 主线 C17；不用 C++ 的引用、容器、`new`，不用 `void main`、`gets`、`fflush(stdin)` 或平台暂停命令。算法程序使用标准 C 库；平台相关内容独立说明。
- 主线环境为 Windows x64 上 MSYS2 UCRT64 的 Bash。终端命令一律说明终端与目录。已经有可用 GCC 的读者不必重装。安装要求以 99 资料页所列官方文档与核验日期为准。
- 完整程序标 `完整程序：文件名`，与 `示例代码/NN-英文名/` 的真实源码相同；需要上下文的片段必须写明放在哪里；伪代码必须注明不能交给 C 编译器。
- 第一阶段用 `getchar` 讲有界输入；04、05 章只读一位数字。复杂输入在阶段练习中用已学函数和循环组合，不暗中使用未解释的指针。
- 每个算法讲输入、输出、前提、状态/不变量、正确性、边界与失败、时间和额外空间，再讨论选择理由。复杂度从第17章正式推导；前八章只数实际操作，不提前要求背公式。
- 数组容量与实际数量不同；空序列、重复值、首尾位置、分配失败等各在相应章节出现。语言未定义行为只解释，不通过执行危险代码猜测结果。
- 阶段任务题目和答案独立成页；最终项目文档是任务书，在实现前明确写“待完成”。不能把有文件等同于实验已运行。

# 13 条件分支与循环

## 13.1 目标与先修

先会算术、比较和PC顺序执行。学完能把if与while式逻辑翻译成跳转，手动跟踪循环，避免差一错误和错误的有符号比较。下列片段放在main内观察；完整区间求和程序见[range-sum.s](示例代码/04-rars-programs/range-sum.s)。

## 13.2 条件怎样改变PC

`beq t0,t1,label`：相等时跳到label，否则执行下一条。`bne`是不相等，`blt/bge`是有符号小于/大于等于，`bltu/bgeu`按无符号解释。它们直接比较寄存器，不依赖先执行一条单独的“比较并设置标志”指令。

```asm
# 若t0<0，则a0=0；否则a0=t0
blt  t0, zero, negative
addi a0, t0, 0
j    done
negative:
addi a0, zero, 0
done:
```

`j done`是伪指令，可展开`jal zero,done`，无条件跳转且丢弃返回地址。若忘记这条，非负路径也会顺序落入negative，把刚写入的值清零。

## 13.3 循环的四个部分

求1到N的和，先约定N=5，结果15。循环需要初始化、条件、循环体、更新：

```asm
li t0, 1           # i
li t1, 5           # N
li t2, 0           # sum
loop:
    blt t1, t0, done
    add t2, t2, t0
    addi t0, t0, 1
    j loop
done:
```

这是说明性片段，done后可接第09章的整数打印。这里选择“i>N就结束”，因此i=N那次仍会相加。

| 进入条件时i | sum原值 | 是否执行循环体 | 执行后sum |
| --- | --- | --- | --- |
| 1 | 0 | 是 | 1 |
| 2 | 1 | 是 | 3 |
| 3 | 3 | 是 | 6 |
| 4 | 6 | 是 | 10 |
| 5 | 10 | 是 | 15 |
| 6 | 15 | 否 | 15 |

不要用“执行了五次”代替状态表：循环分支实际被检查六次。

## 13.4 循环不变式帮你解释正确性

每次进入loop时，t2等于1到i−1的和。初始i=1，空和为0；循环体把i加进去，再令i加1，不变式继续成立；结束时i=N+1，所以和是1到N。这比“试一个输入对了”更有说服力。

若N=0或负数，初始i=1，第一条判断直接退出，和0；若N非常大，sum或i可能32位溢出，例子不保证任意输入。规定小范围非负N，或者增加边界与溢出检查。

## 13.5 分支距离与比较选择

真实条件分支的相对偏移有范围限制，按字节计，目标相对当前分支指令PC。普通小程序用标签由汇编器计算；过远跳转需要工具生成其他序列或修改代码布局，不要把标签当无限距离硬件功能。

若t0=`0xFFFFFFFF`，`blt t0,zero,...`会跳，因为有符号−1<0；`bltu t0,zero,...`不会。循环边界若用错比较方式，可能让负数意外变成巨大无符号值。

## 13.6 实验与练习

实验：将完整range-sum.s中的N依次改为0、1、5，预期0、1、15。先单步前两轮，记录i和sum，再连续运行。出现死循环时暂停，检查更新是否执行以及跳回的位置。

练习1：把结束条件错误改成`bge t0,t1,done`，N=5时结果？参考：i=5之前就退出，得到1+2+3+4=10。

练习2：计算0—4的和，应怎样初始化与判断？参考：i=0，i>=5退出，体内加i再i++，得到10。

练习3：`beq`比较是否受有符号/无符号影响？参考：比较相同比特模式的相等性，不受数值解释影响。

# 11 整数运算、立即数与伪指令

## 11.1 目标与先修

先会寄存器三操作数语法。学完能选择算术、逻辑、移位、比较指令，解释立即数范围，并把常见伪指令还原为真实指令。下面都是说明性片段，可放入第09章main的打印前部分。

## 11.2 算术与逻辑

| 指令例子 | 意义 |
| --- | --- |
| `add t2,t0,t1` | t2=t0+t1，保留低32位 |
| `sub t2,t0,t1` | t2=t0−t1，保留低32位 |
| `addi t0,t0,-1` | t0减1 |
| `and t2,t0,t1` | 对应位AND |
| `ori t2,t0,1` | 把t0最低位置1后写t2 |
| `xori t2,t0,-1` | 低32位逐位取反 |

大部分I型算术逻辑立即数字段是12位补码，范围−2048至2047，并符号扩展到32位。`andi t0,t0,255`可取低8位；把65535直接写进同样字段超出范围，需要先构造寄存器常数。

注意立即数不是所有指令都相同格式：移位立即数、`lui`、分支偏移各有规则，不要把12位范围套到全部指令。

## 11.3 三种移位与两种小于

`slli`逻辑左移、`srli`逻辑右移、`srai`算术右移。RV32立即数移位量0—31；寄存器移位指令只取移位量寄存器低5位。

```asm
li   t0, -8
srli t1, t0, 1
srai t2, t0, 1
```

t0=`FFFFFFF8`；t1=`7FFFFFFC`即2147483644；t2=`FFFFFFFC`即−4。两种右移的差别来自左侧补0还是复制符号位。

`slt t2,t0,t1`按有符号比较，小于则写1，否则写0；`sltu`按无符号比较。同一t0=−1的位串与t1=1比较，slt结果1，sltu结果0。

## 11.4 为什么li可能变两条

`li t0,7`可展开为`addi t0,zero,7`。`mv t0,t1`可展开`addi t0,t1,0`；`nop`为`addi zero,zero,0`。

`lui`把20位字段放入结果高20位，低12位清零。要构造`0x12345678`，可用：

```asm
lui  t0, 0x12345
addi t0, t0, 0x678
```

但低12位若最高位为1，addi会把它解释为负数。例`0x12345ABC`：低12位ABC按补码为−1348，因此高部分需加1：

```asm
lui  t0, 0x12346
addi t0, t0, -1348
```

`0x12346000−0x544=0x12345ABC`。这就是汇编器处理`li`比机械切高低位更周全的原因。用工具查看展开，不背成“li永远两条”。

`auipc`把高位立即数与当前PC相加，用于PC相对寻址。`la`装入符号地址，可能展开为相对PC或其他序列，具体依汇编器/链接方式；它不会自动读取该地址的内容。

## 11.5 实验与练习

实验：把`li t0,7`与`li t0,0x12345ABC`分别汇编，观察机器指令数量和t0最终值。记录真实展开，与上面手写序列比较。

练习1：t0=45，`andi t1,t0,15`得到？参考：45=`0x2D`，低4位D，结果13。

练习2：`addi t0,zero,2048`为何不合法？参考：12位有符号最大2047，使用`li t0,2048`让汇编器构造。

练习3：能用`slli t0,t0,2`替代任意整数乘4吗？参考：对保留低32位的运算结果可以；不能据此保证数学结果不溢出，也不能推广到浮点运算。

常见错误：把`li/la`当单一固定机器指令、认为逻辑立即数总做零扩展、在RV32I里直接使用mul。下一章：[12 加载与存储](12-加载存储与内存实验.md)。

# 计算机组成：从零理解RISC-V

修订日期：2026-11-10。适合没有编程、汇编和电路基础的学习者。**详细版正文已完成第01—24章：前五阶段24/28/32/36/40题，第六阶段44题、22次小课、四项实验。各阶段配逐题解析与学习清单。第25—32章仍保留首版。** 本批所列模型、机器码与五个完整RARS程序检查已完成；下一批进入存储层次与I/O。

## 开始学习

1. 先读[整体规划](00-整体规划与学习路线.md)，看清阶段、先修与最终成果。
2. 从[第01章详细版](01-计算机与程序从哪里开始.md)依次学习，第一阶段不要求安装工具；一章拆成多次小课，每个例题先预测再核对。
3. 按[学习记录与验收清单](第一阶段-学习记录与验收清单.md)做纸笔实验，再独立完成[第一阶段24题](第一阶段-练习与参考答案.md)。预留约12—18小时，慢一些也可以。
4. 完成后从[第05章详细版](05-逻辑门与布尔代数.md)学数字电路，使用[第二阶段学习记录](第二阶段-学习记录与验收清单.md)及[28题与解析](第二阶段-练习与参考答案.md)。另预留约16—22小时。
5. 进入[第09章详细版](09-RISC-V工具与第一个程序.md)，按[第三阶段学习记录](第三阶段-学习记录与验收清单.md)准备工具、单步与访存，完成[32题与解析](第三阶段-练习与参考答案.md)。另预留约18—26小时。
6. 从[第13章详细版](13-条件分支与循环.md)把顺序指令连接成循环、数组与函数，按[第四阶段学习记录](第四阶段-学习记录与验收清单.md)完成四项实验、统计器和[36题](第四阶段-练习与参考答案.md)。另预留24—34小时。
7. 从[第17章详细版](17-指令编码与机器码.md)学习字段编码，接着补C语法、数据通路与控制；配[第五阶段学习记录](第五阶段-学习记录与验收清单.md)和[40题](第五阶段-练习与参考答案.md)，另预留24—36小时。
8. 从[第21章详细版](21-性能指标与加速比.md)练性能与五级流水，按[第六阶段学习记录](第六阶段-学习记录与验收清单.md)画转发/停顿/冲刷表，完成[44题](第六阶段-练习与参考答案.md)，另预留28—40小时。
9. 下一批进入第25—28章存储层次、Cache、虚拟内存与I/O；第31章模型与第32章综合实践保留在整体路线中。

# 示例01：位、补码与浮点编码

对应第02—04、08章。Node.js20或以上，在本目录执行`node bits.cjs`；从网站根目录执行时补全相对路径。不需要第三方包。

第一阶段详细版主线只需要纸笔，本脚本是已经能使用Node的读者的可选核对工具。第一次学习先看前三行输出；最后一行1.5的浮点编码对应第08章，目前不需要掌握。不会打开终端不影响完成第一阶段。

预期输出：37的8位二进制00100101、十六进制25；−5低8位11111011；AD与0F相与结果13；1.5的binary32编码3fc00000。

`bits()`先取32位表示再截低width位，仅为这些范围内的演示，不是任意精度进制库。`binary32()`用DataView按标准浮点格式转换，不通过整数加法伪造编码。

练习：预测2.5的编码，再把调用改成2.5核对；手工画小端字节00 00 20 40。回到[第08章](../../08-整数乘除与浮点数.md)。

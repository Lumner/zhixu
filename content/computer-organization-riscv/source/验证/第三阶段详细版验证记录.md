## 实际运行环境与来源

平台为本机Windows、PowerShell，作者检查脚本通过Node标准库启动Java；学生直接运行RARS不依赖Node。官方RARS v1.6 JAR从[维护者发行页](https://github.com/TheThirdOne/rars/releases/tag/v1.6)取得，大小1860244字节，本批SHA-256为：

```text
780f730eb457b1ba609e968accc2c8b77d8f92c3d9dbf30cc7fdb3cfb14e8c24
```

该值是本批下载文件指纹，用于重跑时固定同一发行物，不是额外的第三方安全认证。

Java运行时来自[Eclipse Temurin官方发行](https://github.com/adoptium/temurin17-binaries/releases/tag/jdk-17.0.21%2B9)，使用Windows x64 JRE ZIP，版本17.0.21+9，核对官方API给出的ZIP SHA-256：

```text
fe4656bd78fb09812dc38c49da777f79cc33e7ee435a254be82f9e7f40d9d117
```

下载、解压目录为本课`.cache/stage3-tools/`，没有改全局PATH或安装到系统目录。该缓存不在source内，不纳入教程ZIP；其他学习者自行获取适合平台的Java与RARS，不依赖本机缓存的绝对路径。Java程序会使用其正常用户偏好存储，本机沙箱限制该操作，故本批RARS运行在宿主命令行完成。

RARS设置由命令参数确定：RV32（不传rv64）、Default内存、小端、sm从全局main开始、允许伪指令；单个文件独立汇编，不用p目录项目模式。普通运行带ae2/se3，使汇编错误与模拟错误分别返回退出码2/3；有限步数场景故意提前暂停。

## 实际结果

检查脚本[verify-stage3.cjs](verify-stage3.cjs)实际通过**40个命名场景**，包括27次官方RARS调用。场景数不是指令种类数，不表示穷举ISA。详细输出、退出码与七个源文件的SHA-256保存在[stage3-rars-checks.json](stage3-rars-checks.json)。

| 范围 | 实际核对 |
| --- | --- |
| hello.s与三个改造 | 7、5、−9及表达式结果−2，核对a0与输入 |
| register-trace.s | 从初态分别执行前1—5条，最终7/4/14/0；禁伪指令模式也通过 |
| arithmetic.s | 两种右移、比较、掩码、立即数边界、大常数、复制、回绕、移位量低5位；−7变体 |
| pseudo.s | 最终寄存器；11条机器字逐项与独立给定编码核对；地址间隔4；mv实际add展开 |
| memory.s | word复制、最低字节78、FE的有符号/无符号加载 |
| memory-update.s | 输出5、输入保留、result写回、窄存储、旧副本、byte/half扩展、四次lbu字节顺序 |
| stage3-practice.s | 原始13、改造−13、全0、32位加法回绕；均核对输入与out |
| 预期汇编失败 | addi的2048/−2049、slli 32、非法t7、关闭伪指令后的hello |
| 预期运行失败 | 对t1和zero进行未对齐lw，均实际报告word地址未对齐 |

[stage3-pseudo-text.txt](stage3-pseudo-text.txt)是RARS的SegmentWindow实际导出，不是手工伪造的界面截图。教材表为了可读性把某些负立即数改写为十进制，原始导出保留工具形式。原示例组03保留hello与memory两程序，本批新增五程序，合计七个；示例组04的五个后续程序本批没有运行。

## 怎样重跑

在**PowerShell、网站根目录**执行。下方参数是你已下载的工具路径示例，必须替换成自己的实际文件：

```powershell
node content/computer-organization-riscv/source/验证/verify-stage3.cjs --java 'C:\riscv-study\java\bin\java.exe' --jar 'C:\riscv-study\rars1_6.jar'
```

脚本固定RARS发行物指纹，以免拿不同版本的展开验证当前表；Java要求8或以上，实际版本写入报告。临时改造/错误输入保存在本课`.cache/stage3-run/`，不覆盖教材的七个基线文件。它会更新本记录旁的JSON与机器表；文件来源、命令和退出码可交叉复查。

学生的日常运行用各章直接Java命令即可，不必先学习或运行这个作者检查脚本。阅读结果与亲手完成单步、预测、改造练习是不同要求。

## 验证边界

本批完成的是官方RARS**命令行**汇编、执行、寄存器/内存检查与机器表导出，没有实际点击RARS图形界面的菜单、断点或复位。GUI步骤依据维护者说明编写，学习者仍需完成自己的界面操作记录。

未执行Ripes数据通路/流水线、交叉编译、HDL、FPGA、真机、特权内核、设备I/O或DMA。有限步数是功能模拟的指令推进次数，不是芯片实测周期。非对齐错误结论限于本RARS配置，不能推广为所有RISC-V执行环境。

网页构建、链接、搜索与浏览器阅读另由根目录reports记录；网页显示成功不能替代汇编实测，汇编通过也不能替代完整网页走查。本批安装/API和规范来源核验日期同为2026-11-05，详见[官方资料页](../99-官方资料与核验说明.md)。

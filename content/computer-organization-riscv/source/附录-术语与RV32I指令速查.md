## 基础指令与伪指令

| 类型 | 常见名字 | 看见时问什么 |
| --- | --- | --- |
| 算术 | add/sub/addi | 低32位结果是否超出所需数值范围？ |
| 位运算 | and/or/xor及andi/ori/xori | 掩码和符号扩展是否正确？ |
| 移位 | sll/srl/sra及立即数形式 | 补0还是补符号？位数是多少？ |
| 比较 | slt/sltu/slti/sltiu | 有符号还是无符号？结果0或1？ |
| 加载 | lb/lbu/lh/lhu/lw | 地址、宽度、对齐和扩展规则？ |
| 存储 | sb/sh/sw | 来源寄存器低几位写到哪里？ |
| 分支 | beq/bne/blt/bge/bltu/bgeu | 比较规则和目标基准PC？ |
| 跳转 | jal/jalr | 链接保存哪里，jalr是否清最低位？ |
| 上立即数 | lui/auipc | 高位构造还是加当前PC？ |
| 环境 | ecall/ebreak | 运行环境怎样处理？ |
| 内存顺序 | fence | 与具体内存访问顺序约束相关，模型未实现 |
| 伪指令 | li/la/mv/j/ret/nop | 展开成哪些真实指令？ |

纯RV32I没有mul/div/rem、ld/sd、浮点运算或压缩编码；这些属于后续架构/扩展。CSR访问不应含糊地都叫“基础I里的普通寄存器操作”。

## 常用自查顺序

结果错误先检查：输入的比特与解释 → 地址和访问宽度 → 指令读写方向 → 分支条件与更新 → 调用现场 → 工具模式与环境接口。性能问题另查动态指令数、周期模型、频率、Cache参数和计时范围。

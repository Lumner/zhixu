## 3. 实验二：同一个位串的多种解释

固定8位，选择一个最高位为1的位串，例如11110000。记录：无符号值、补码值、十六进制、符号扩展到32位、零扩展到32位。

| 观察项目 | 我的结果 | 我使用的规则 |
| --- | --- | --- |
| 无符号值 |  | 位权相加 |
| 8位补码值 |  | 高半区减256，或负权位权 |
| 十六进制 |  | 每4位一组 |
| 32位符号扩展 |  | 新高位复制旧符号位 |
| 32位零扩展 |  | 新高位补0 |

最后回答：这些解释中，哪一步真正改变了保存宽度？哪几步只改变了我们观察和解释同一串bit的方式？

## 4. 实验三：纸上20字节存储器

从0x1000到0x1013画20个格，编号按十六进制递增。把3、−2、7、0、4按32位补码、小端填进去。

不要从参考答案整行照抄。对每项依次完成：算32位表示 → 拆成四字节 → 选小端次序 → 放到正确地址 → 读回检查。

接着做三次观察：先读0x1004的一个无符号字节；再读从0x1004起的四字节补码整数；最后把五项累计相加。每次都写清访问宽度。

在另一个格P写0x1004，说明P保存的地址值和该地址处的数据分别是什么。最后把0x1004处FE改FF，再重新读第二项与总和。

## 6. 第一阶段完成条件

- [ ] 能解释CPU、寄存器、主存、SSD、输入输出各做什么。
- [ ] 能追踪读取旧值、运算、写回的顺序。
- [ ] 能在二、十、十六进制之间转换小整数，并做反向核对。
- [ ] 能区分模式总数与最大值，正确换算bit和byte。
- [ ] 能逐位说明AND/OR/XOR、掩码和逻辑移位。
- [ ] 能推导负数编码，区分无符号与补码读法。
- [ ] 能用反例说明最高进位与有符号溢出不同。
- [ ] 能区分符号扩展与零扩展。
- [ ] 能画出数组的字节地址和小端布局，不混淆长度与下标。
- [ ] 能解释数值、字符编码与UTF-8字节数不同。
- [ ] 能独立完成20字节实验并解释一次数据改动的影响。

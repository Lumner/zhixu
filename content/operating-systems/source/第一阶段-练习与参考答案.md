# 第一阶段：练习与参考答案

范围 01—02 章。先不看答案，在自己 Linux 主目录的新练习目录完成。

## 任务一：说明三个层次

描述“编辑器读取文本”的应用、内核和设备职责，解释 RAM 与 SSD 区别。答案要点：应用提出请求并解释字节；内核检查并组织资源操作；设备传输实际存储数据。RAM 主要用于运行中的状态，持久设备用于长期保存，缓存与同步另需考虑。

## 任务二：独立整理目录

创建 `~/os-lab/stage1/notes`，进入 stage1，往 notes/day1.txt 写一行自己的笔记，先打印当前位置，再读取该文件。只用本阶段已学命令，不使用图形界面代替定位。

参考命令逐行在 Bash 执行：

```bash
mkdir -p ~/os-lab/stage1/notes
cd ~/os-lab/stage1
pwd
printf 'learning operating systems\n' > notes/day1.txt
cat notes/day1.txt
```

## 任务三：诊断而非猜测

若 `cat day1.txt` 报不存在，先写三个可能原因。答案：当前目录不对、真实路径在子目录、名字/大小写不一致。用 pwd、ls、ls notes 查证，不靠 sudo 解决路径错误。

## 通过标准

能解释每条命令改变了什么，能够重新打开 Ubuntu 找回笔记，知道哪些命令属于 PowerShell、哪些属于 Bash，且 gcc 能返回版本。安装受阻可先读概念，但应记录受阻项，不标记实验已完成。

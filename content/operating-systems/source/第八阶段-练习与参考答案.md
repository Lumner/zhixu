# 第八阶段：练习与参考答案

范围 34—36 章，组合成可验收的系统工具。

## 任务一：Shell 功能矩阵

在新临时目录运行 mini-shell，验证外部命令、pwd、cd、单管道、输出重定向、空行、不存在命令、错误语法。参考：`printf abc | wc -c` 结果 3；`echo saved > result.txt` 后 cat 能读到 saved；找不到命令为127；语法错误为2；内置命令参加管道被拒绝。

## 任务二：排查管道假死

把一种错误实现描述为“父先等待左命令退出，再启动右命令”。解释大输出为何卡住。答案：左命令写满管道后等读者，父等左退出，右还没创建。正确顺序是创建两端、父关闭无用 fd，再回收。

## 任务三：性能记录

任选 mutex 或 copy，写环境、编译参数、输入、命令、原始输出、三次耗时和结论。不提供固定预期毫秒数，真实结果应由你机器产生。说明测量工具开销与短例程计时精度的限制。

## 任务四：一个受控改造

增加独立 help 命令，说明支持范围和不支持语法。参考：更新 is_builtin，与 main 中具体分支；错误地只在 main 增加分支，会漏掉“help 不允许管道/重定向”的统一检查。测试 help、help带参数、help管道三条路径。

## 通过标准

代码能运行，异常能解释，资源能回收，限制写准确。进一步 xv6 路线只说明下一步目标，不以下载仓库代替完成内核实验。

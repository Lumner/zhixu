## 五、参考答案：前十一题

题1：15→35→70，int用%d。题2：依次0h0、0h59、1h0、2h5、24h0，使用小时×60+余数反算；整数除法7/2先得3，再转换成double也只能是3.0，另一个表达式按浮点规则计算3.5。

题3：7是输入字符，其编码与算术整数7不同；换行是读到了一个字符，EOF或失败又是另一类结果。题4：“至少”接受30，“超过”不接受30，29和31的归属不因此改变。

题5：原累计序列0、0、30、70、120、180、250。排除30得220，漏掉第7天的70得180。题6：使用1、2、4、5，共12；更新被continue跳过可能让状态一直不变，循环不能推进。

题7：普通参数按值接收，修改副本不改原对象；调用者用 `value = change(value);` 明确接收更新。题8：通常是链接缺实现；声明只提供接口，构建还要包含实现代码。

题9：5项、150分钟、4个有效日，0也占一个记录位置。题10：容量16、正文6字节；A中为4字节正文，加终止符至少5字节。题11：还需要换行与终止符两格；空行能成功读到换行，没有输入可能直接返回NULL，缺末尾换行违反本次完整行协议。

## 六、综合项目：一周学习记录统计器

在Ubuntu建立 `~/os-lab/batch02-review`，把下面参考程序保存为week-review.c。先尝试自行实现，再对照代码。

要求：最多7项记录，每项0—1440分钟；0表示该日没有有效学习。报告记录天数、有效天数、总分钟、最大单日分钟，以及按全部记录日/有效日分别计算的平均值。无相应记录时显示n/a，不做除零。

固定第一组数据为 `{15,0,45,30,60,0,20}`。先手算结果，给每个函数写输入与返回值说明。这里通过修改数组模拟输入数据，不提前要求会指针和严格文本转数值。

## 七、完整参考程序

**完整程序：week-review.c**

```c
#include <stdio.h>

int valid_minutes(const int values[], size_t count) {
    for (size_t i = 0; i < count; i++) {
        if (values[i] < 0 || values[i] > 1440) {
            return 0;
        }
    }
    return 1;
}

int total_minutes(const int values[], size_t count) {
    int total = 0;
    for (size_t i = 0; i < count; i++) {
        total += values[i];
    }
    return total;
}

size_t active_days(const int values[], size_t count) {
    size_t active = 0;
    for (size_t i = 0; i < count; i++) {
        if (values[i] > 0) {
            active++;
        }
    }
    return active;
}

int maximum_minutes(const int values[], size_t count) {
    if (count == 0) {
        return 0;
    }
    int maximum = values[0];
    for (size_t i = 1; i < count; i++) {
        if (values[i] > maximum) {
            maximum = values[i];
        }
    }
    return maximum;
}

int main(void) {
    int days[] = {15, 0, 45, 30, 60, 0, 20};
    size_t count = sizeof days / sizeof days[0];
    if (count > 7) {
        fprintf(stderr, "Too many records\n");
        return 2;
    }
    if (!valid_minutes(days, count)) {
        fprintf(stderr, "Invalid minutes\n");
        return 1;
    }
    int total = total_minutes(days, count);
    size_t active = active_days(days, count);
    printf("days=%zu active=%zu total=%d max=%d\n",
           count, active, total, maximum_minutes(days, count));
    if (count > 0) {
        printf("calendar_average=%.2f\n", (double)total / count);
    } else {
        printf("calendar_average=n/a\n");
    }
    if (active > 0) {
        printf("active_average=%.2f\n", (double)total / active);
    } else {
        printf("active_average=n/a\n");
    }
    return 0;
}
```

在该文件所在目录执行：

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic -g week-review.c -o week-review
./week-review
```

预期：

```text
days=7 active=5 total=170 max=60
calendar_average=24.29
active_average=34.00
```

两个平均值分母不同。calendar_average按本例提供的全部记录日计算，active_average只按分钟大于0的记录日计算。变量名清楚不等于口径自动正确，必须像这样写明规则。

## 八、为什么这份参考能处理边界

先检查count再读取指定区间，避免把超出本工具7项上限的输入当作正常数据。然后逐项校验0—1440，最多7项总和不超过10080。计算函数依赖这些前提，不宣称可以接受任意数量、任意整数而不溢出。

maximum_minutes在count为0时返回0，是本项目“非负分钟、空数据以0表示无贡献”的接口约定，不是一般整数最大值的通用定义。两个平均值则明确用n/a表示无分母结果。

`(double)total` 是显式类型转换，让除法按浮点规则进行；先完成total/count的整数除法再转double，会丢掉已经截断的小数。函数参数的const不提供自动长度检查，count必须属于实际可访问数组区间。

## 九、改造与验收

把数据换成 `{0,0,0}`，应为3天、有效0、总0、最大0，日均0.00、有效日均n/a。换成 `{60}`，两个平均都60.00。放入-1或1441应被拒绝，8项应返回2，不把错误输入继续累加。

空序列测试不要声明标准C容量为0的数组。保留一个有效数组，将本次逻辑count设为0，函数不访问任何元素，报告天数0和两个平均n/a。这是接口层的空数据，不是让越界地址看起来合理。

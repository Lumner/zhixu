# 详写第六批：练习、参考答案与虚拟内存实验台

对应第21—24章。作品把“虚拟地址拆页 → 判断是否驻留 → 选择页框 → 重新合成物理地址”连成一个有限模拟器，同时保留真实映射实验的独立验收。

## 1. 分阶段学习与边界

四章建议32—44小时，本练习5—7小时，合计37—51小时。先手算题目，再输入代码，最后用不同参数核对。所有命令在Linux/WSL Ubuntu的Bash、`~/os-lab/memory`执行。

本项目是**概念模型的完整可运行程序**，不设置真实页表、不拦截真实缺页、不读取物理页框。输出physical是模型地址，不能转换为C指针解引用。第24章mmap才是实际操作系统接口，两种验证分开记录。

## 2. 题目：先算中间步骤

1. 页大小4096，地址12300，页3映射框8，物理地址多少？
2. 16字节页、8位地址170，页号按2位目录+2位叶索引拆分，各是多少？
3. TLB miss但页表映射有效且已驻留，是否必须读磁盘？
4. 三框、页序列1,2,3,1,4,2,5，FIFO和LRU的缺页数分别是多少？
5. 为什么FIFO在命中时不移动替换指针，LRU却要更新时间？
6. 文件关闭以后，mmap区域一定失效吗？munmap以后呢？
7. 访问同一个模型页内不同字节，需要每次重新装入页吗？
8. 为什么一次程序正常结束不能证明它修改了真实内核置换策略？

提示：每次写“地址、页、偏移、页框、事件”，不要跳过中间列。第6题分别画句柄与映射生命期。

## 3. 参考答案

第一题12300=3×4096+12，物理8×4096+12=32780。第二题页号10、目录2、叶索引2、偏移10；若框9，则物理154。

第三题不需要，可能仅寻找翻译。第四题FIFO5、LRU6，使用第23章表逐项核对。第五题两者依据分别是装入先后与最近访问，命中的历史含义不同。

第六题关闭句柄不自动撤销映射；munmap后停止使用旧映射地址。第七题若该页仍驻留则命中，同页不同偏移不占新页框。第八题模型只是自己的普通数组与循环，没有对应的内核修改接口。

## 4. 项目接口先固定

命令格式：

```text
./vm-lab fifo|lru FRAME_COUNT PAGE_SIZE ADDRESS [ADDRESS ...]
```

框数1—8；模型页大小是1—4096中的2次幂；虚拟字节地址0—65535；每次1—64个引用。数字只接受非空十进制数字串，不接受负号、加号或空格，先验证全部参数再输出追踪。

整个虚拟范围在本模型都合法可读，初始所有页不驻留。物理页框槽编号为0到FRAME_COUNT-1，相应模型物理容量为框数×页大小。未驻留计一次fault并装入；没有脏页、权限变化、TLB和实际I/O。FIFO/LRU负责选择槽位，翻译公式负责保留偏移，两者各有职责。

## 5. 状态和不变量

pages[slot]表示该槽当前装入的虚拟页，-1表示空；last[slot]记录最近引用步数；next是FIFO下一替换槽。范围不变量包括槽在0到框数-1、偏移小于页大小、当前同一个页最多存在于一个槽。

命中不改变FIFO的next；每次引用都更新LRU用的last。所有页号来自已检查地址整除页大小；步数最多64，因此时间戳不会在本范围溢出。模型物理地址必须小于框数×页大小。

## 6. 完整项目参考实现

**完整程序：vm-lab.c**

```c
#include <errno.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static int decimal(const char *text, unsigned limit, unsigned *result) {
    if (*text == '\0') { return 0; }
    for (const char *p = text; *p != '\0'; p++) {
        if (*p < '0' || *p > '9') { return 0; }
    }
    char *end;
    errno = 0;
    unsigned long value = strtoul(text, &end, 10);
    if (errno != 0 || *end != '\0' || value > limit) { return 0; }
    *result = (unsigned)value;
    return 1;
}
int main(int argc, char *argv[]) {
    if (argc < 5 || argc > 68 ||
        (strcmp(argv[1], "fifo") != 0 && strcmp(argv[1], "lru") != 0)) {
        fputs("usage: vm-lab fifo|lru FRAMES_1_TO_8 PAGE_SIZE ADDRESS... (max 64)\n", stderr);
        return 2;
    }
    unsigned frame_count, page_size;
    if (!decimal(argv[2], 8, &frame_count) || frame_count == 0 ||
        !decimal(argv[3], 4096, &page_size) || page_size == 0) {
        fputs("invalid frame count or page size\n", stderr);
        return 2;
    }
    unsigned scale = page_size;
    while (scale > 1 && scale % 2 == 0) { scale /= 2; }
    if (scale != 1) { fputs("page size must be a power of two\n", stderr); return 2; }
    unsigned addresses[64];
    int count = argc - 4;
    for (int i = 0; i < count; i++) {
        if (!decimal(argv[i + 4], 65535, &addresses[i])) {
            fputs("address must contain decimal digits and be from 0 to 65535\n", stderr);
            return 2;
        }
    }
    int pages[8];
    unsigned last[8] = {0};
    for (int i = 0; i < 8; i++) { pages[i] = -1; }
    unsigned next = 0;
    int hits = 0, faults = 0;
    int fifo = strcmp(argv[1], "fifo") == 0;
    for (int i = 0; i < count; i++) {
        unsigned page = addresses[i] / page_size;
        unsigned offset = addresses[i] % page_size;
        int slot = -1;
        for (unsigned j = 0; j < frame_count; j++) {
            if (pages[j] == (int)page) { slot = (int)j; }
        }
        int hit = slot >= 0;
        int evicted = -1;
        if (hit) { hits++; }
        else {
            faults++;
            if (fifo) {
                slot = (int)next;
                next = (next + 1) % frame_count;
            } else {
                for (unsigned j = 0; j < frame_count; j++) {
                    if (pages[j] < 0) { slot = (int)j; break; }
                }
                if (slot < 0) {
                    slot = 0;
                    for (unsigned j = 1; j < frame_count; j++) {
                        if (last[j] < last[slot]) { slot = (int)j; }
                    }
                }
            }
            evicted = pages[slot];
            pages[slot] = (int)page;
        }
        last[slot] = (unsigned)i + 1;
        unsigned physical = (unsigned)slot * page_size + offset;
        if (physical >= frame_count * page_size) {
            fputs("model physical range invariant broken\n", stderr);
            return 1;
        }
        printf("step=%d address=%u page=%u offset=%u %s slot=%d physical=%u evicted=",
               i + 1, addresses[i], page, offset, hit ? "hit" : "fault", slot, physical);
        if (evicted < 0) { printf("none"); } else { printf("%d", evicted); }
        printf(" frames=");
        for (unsigned j = 0; j < frame_count; j++) {
            if (j != 0) { printf(","); }
            if (pages[j] < 0) { printf("-"); } else { printf("%d", pages[j]); }
        }
        putchar('\n');
    }
    printf("hits=%d faults=%d\n", hits, faults);
    return 0;
}
```

程序不需要lab.h，所有输入都在运行模型以前检查。输出没有假装是真实内核追踪；0也可以是合法模型物理字节地址，不表示程序要解引用空指针。

## 7. 分四段理解代码

decimal先检查字符语法，再用strtoul检查数值与范围，成功才写输出参数。它不同于前章某些strtol练习接受前导空白的协议；本版主动固定更小语法，避免输入含义不清。

初始化保证所有槽是空，没有把未初始化数组当成已有页表。每次先查所有有效槽是否已有目标页；只有没有时才选候选。

FIFO按next直接替换；LRU先用空槽，没有空槽才比较last最小者。装入以后与命中一样更新当前槽最后访问步数。

最后根据当前槽和偏移计算模型物理地址，输出被淘汰页和全部槽内容，便于逐行对手算。它不输出“访问某个物理指针的实际内容”，因为本模型只跟踪驻留关系。

## 8. 编译与第一组完整对照

在本批Bash目录执行：

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic -Werror -g vm-lab.c -o vm-lab
./vm-lab fifo 3 4 4 8 12 4 16 8 20
./vm-lab lru 3 4 4 8 12 4 16 8 20
```

地址除以4得到1,2,3,1,4,2,5，所有偏移为0。FIFO最后hits=2 faults=5；LRU最后hits=1 faults=6。物理槽编号由本模型从0开始，所以不直接沿用第22章另一张页表的5/2/7/1编号。

| 步骤 | 页 | FIFO槽/物理地址 | LRU槽/物理地址 |
| --- | --- | --- | --- |
| 1 | 1 | 0 / 0 | 0 / 0 |
| 2 | 2 | 1 / 4 | 1 / 4 |
| 3 | 3 | 2 / 8 | 2 / 8 |
| 4 | 1 | 0 / 0 | 0 / 0 |
| 5 | 4 | 0 / 0 | 1 / 4 |
| 6 | 2 | 1 / 4 | 2 / 8 |
| 7 | 5 | 1 / 4 | 0 / 0 |

同一个物理槽可先后装不同页；一个虚拟页被淘汰后重装，也可能分到不同槽。不要把第一次翻译结果永久保存为这个页的固定物理地址。

## 9. 同页、边界与Belady异常

运行`./vm-lab fifo 2 4 0 1 3 4`，前三个地址都在页0，只第一次fault；地址4进入页1再fault，总计hits=2 faults=2。地址3与4只差1字节，却跨页。

再运行：

```bash
./vm-lab fifo 3 1 1 2 3 4 1 2 5 1 2 3 4 5
./vm-lab fifo 4 1 1 2 3 4 1 2 5 1 2 3 4 5
```

页大小1只是模型参数，地址就是页号；两次缺页分别9与10。把fifo换成lru，可进一步观察同一序列3框10次、4框8次。比较前提和序列一致，不把“增加模型框数”称为给本机真正扩容。

## 10. 错误输入怎么验收

0框、9框、0页大小、3页大小、4097页大小、地址65536、负数、空字符串、带字母、超长数字以及65个引用都应拒绝，退出2。地址65535合法；同样的字节地址换不同页大小，页号和偏移也会变化。

例如`./vm-lab fifo 3 4 4 bad`必须在输出任何追踪以前失败，因为所有地址先校验。不要看到前一个参数合法就先跑一半，最后才发现尾部格式错却留下让人误以为完整的表。

模型不读取文件、不分配随用户参数增长的巨量内存，数组上限固定。非法字符串不进入数组索引与页框算术。

## 11. 真实映射与模型分别验收

先运行第24章mapping、map-modes、map-lifetime，解释MAP_PRIVATE、MAP_SHARED、关闭与munmap。再运行本项目，核对除法余数、逐步驻留与置换。

配套脚本会把C输出与独立的Python“页→槽映射+策略队列”参考模型逐步对照，检查命中、淘汰、页框内容、偏移及物理范围；还验证经典序列、边界、拒绝部分输出，以及真实映射接口的受控失败清理。随机样例固定种子，便于复现，不把它们描述为穷尽所有输入。

# 第七阶段：练习与参考答案

范围30—33章，从独立机制回到系统全貌。详细训练、完整项目与逐题答案见 [详写第八批](详写第八批-练习与参考答案.md)，本页保留阶段速查。

## 任务一：启动图

画出固件、引导、内核初始化、初始用户进程、Shell 的关系。参考：先建立内存、异常、调度和设备等基础，用户程序才能使用前面课程接口。具体产品可改变路径，WSL 与物理机器不能机械套同一启动图。

## 任务二：最小权限

列出编译 hello、运行 copy、安装 GCC 三种任务的权限。参考：前两项通常只需个人目录与相应资源访问权限，最后一项涉及系统软件管理。运行错误不应一律用 sudo 消除。

## 任务三：网络分层

解释 socket-demo 的 AF_UNIX 与 TCP 服务差别。参考：本机成对端点不需要互联网地址/监听，也不验证外部连通性；TCP 服务需要地址、端口、监听/连接流程。二者的流式读写都必须处理实际字节数。

## 任务四：环境判断

“我在容器里看到 PID 1，所以我有一个独立内核。”判断并解释。答案：不成立，PID 命名空间能提供独立视图；容器通常共享底层 Linux 内核，资源限制还需要额外机制。

## 通过标准

能画自己的真实实验环境和权限边界，指出网络实验的具体范围，并用“视图、内核、资源”三个维度比较虚拟机与容器。

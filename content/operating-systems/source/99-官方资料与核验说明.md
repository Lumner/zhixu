## 怎样读系统手册

先看 NAME/SYNOPSIS 确认函数用途、头文件、参数；再看 RETURN VALUE 与 ERRORS 写失败路径；最后看 NOTES/STANDARDS 理解平台限制。命令末尾 `(2)` 通常表示系统调用手册节，`(3)` 通常表示库函数节，不是软件版本号。

可在 Linux 本机试 `man 2 write`、`man 2 fork`、`man 3 pthread_cond_wait`，按 q 退出。未安装相关手册时可使用上面的项目文档。

## 核验与验证的区别

文档核验确认接口和教学表述；真实编译运行检查本课具体源码。全课的实际运行结果、手算模型对照和环境限制在 [验证记录](验证/验证记录.md)，没有用资料链接代替运行，也没有把本机 Linux 结果称为所有平台通用证明。

条件变量页面含历史实现说明，课程只依赖通用接口语义，不把其中历史 LinuxThreads 实现细节当作当前全部实现。GNU 文档的部分完整域名抓取曾超时，使用相同官方站点 `/s/` 路径核验进程创建概念。

GNU Make 规则页面本次抓取超时，保留官方学习入口，未宣称逐页核对其正文；本课 Makefile 已用现有 Ubuntu 的 Make 实际编译全部 23 个例程。

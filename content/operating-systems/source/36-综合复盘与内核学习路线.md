## 36.1 重新回答最初的问题

在简易 Shell 输入 `printf abc | wc -c > count.txt`：Shell 解析为两组参数和输出目标，建立管道，fork 两个子进程；左边把 stdout 指向管道写端，右边把 stdin 指向读端并打开输出文件；两边 exec 装入对应程序，内核完成调度、地址映射、字节传输和文件处理；父关闭不用的端并回收状态。

这条链同时使用 C 对象与指针、进程生命期、描述符继承、管道 EOF、文件命名与权限、内存隔离和错误处理。成功看到 count.txt 也不能直接推出“文件已抵御掉电”，因为持久性是另一层要求。

## 36.2 闭卷复盘六题

1. 父子打印同一虚拟地址但值不同，如何解释？
2. counter++ 为什么要同步，volatile 可以替代吗？
3. 管道读端为何可能一直等不到 EOF？
4. TLB miss、合法缺页与非法访问怎样区分？
5. 硬链接、软链接与已打开 fd 的生命期有何不同？
6. 一次 write 成功是否代表掉电后一定保留？

答案要点：1 独立映射与写时复制语义；2 无同步冲突访问可构成未定义行为，volatile 不能代替锁；3 还有写端未关闭或数据流尚未结束；4 缓存翻译未命中、内核可处理的映射需求、不能满足的访问请求不同；5 名字、链接对象与打开引用是三种关系；6 需区分缓存、同步、目录与平台保证。

能写答案后，选择两个例程不看正文重写最小版本，并加入一个失败输入。比“能背所有术语”更能检验是否形成可用理解。

## 36.3 如果要进一步学内核

建议先阅读 MIT 的 [xv6 介绍](https://pdos.csail.mit.edu/6.1810/2025/xv6.html) 与 [xv6 RISC-V 教材](https://mit-pdos.github.io/xv6-riscv-book/)。它是用于教学的 Unix 风格小型内核，规模比生产内核更便于建立整体认识。它不是本课例程的运行环境，已有 Linux 用户程序也不能不经修改就当作 xv6 内核代码。

下一阶段可分五步：补必要 RISC-V 寄存器、调用约定与少量汇编 → 对照系统调用入口和 trap → 阅读进程与上下文切换 → 页表与缺页 → 文件系统与日志。每次只沿一个请求追踪，不从第一行到最后一行机械浏览全部仓库。

RISC-V 工具链、QEMU 与实验工具要求以选定的 MIT 课程年份及仓库文档为准，核对主机平台后再装。本课没有把“已经写好学习路线”表述成“已经完成自制内核与 xv6 实验”。

## 36.4 进一步分支

想做系统软件：补数据结构、深入 C、调试、ABI 和网络协议；想学安全：先掌握权限与内存机制，再在授权实验环境学习；想做性能：加强测量、统计、缓存与并发；想做嵌入式：补体系结构、交叉编译、中断和设备接口。

不必立即全选。选一个与你想做的作品直接相关的方向，并为它定义输入、可运行成果和验收条件，就能沿用本课框架。

## 36.5 毕业验收

完成 [系统实验台综合实践](最终综合实践-系统实验台.md)，保存一份自己的运行记录，注明环境、命令、输出、失败路径与仍不支持的能力。能从零建立环境、解释例程、定位错误并完成一个小改造，即达到本课程主线目标。

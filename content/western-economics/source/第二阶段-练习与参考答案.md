## 练习A：独立写预算函数

需求：一个函数接收收入与支出，返回余额；两个金额必须有限且非负。主程序对1200和900调用，并显示两位小数。再处理负输入和文字输入。写清哪些错误由转换阶段处理、哪些由函数处理。

完整参考程序，可保存为 `budget_answer.py`：

```python
import math

def balance(income, expense):
    if not math.isfinite(income) or not math.isfinite(expense):
        raise ValueError("Amounts must be finite")
    if income < 0 or expense < 0:
        raise ValueError("Amounts must be non-negative")
    return income - expense

if __name__ == "__main__":
    try:
        income = float(input("Income: "))
        expense = float(input("Expense: "))
        result = balance(income, expense)
        print(f"Balance: {result:.2f}")
    except ValueError as exc:
        print("Invalid input:", exc)
```

执行 `python budget_answer.py`，输入1200、900，预期 `Balance: 300.00`。输入abc由float转换失败；输入-1或inf则由函数范围检查失败。本函数约定接收已转换的数值，不接受任意Python对象。本批验证已提取这段完整程序并实际运行1200/900情景，其他改造仍请按要求自行验收。

| P | Q | P×Q |
| --- | --- | --- |
| 5 | 90 | 450 |

```python
for price in [5, 15, 25, 35]:
    quantity = max(0, 100 - 2 * price)
    print(price, quantity, price * quantity)
```

追问：能把这四行收益加起来叫某一天总收益吗？答：不能，它们是同一模型的互斥价格情景。

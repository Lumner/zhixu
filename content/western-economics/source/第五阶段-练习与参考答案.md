# 第五阶段练习与参考答案：市场结构与失灵

## 目标与提交物

对应27—32章，建议4—6小时，计入阶段投入。先独立写公式和方向，再用程序核对。提交一张市场结构表、一个收益矩阵、一份可行分配、一个外部性与公共品对照表、一段信息机制分析。

## 练习一：垄断与竞争

反需求P=50-Q，MC10，默认固定成本0。

1. 推导MR和垄断最优价格、数量、利润。
2. 竞争基准数量、消费者剩余、总剩余与垄断无谓损失？
3. 固定成本改为80且本期不可避免，哪些量改变？

参考：MR50-2Q，最优Q20、P30，利润400；垄断CS200、PS400、总剩余600。竞争Q40/P10，CS及总剩余800，DWL200。固定80不改变短期Q/P，利润降为320；共同固定成本应在两种福利口径中一致处理。

## 练习二：最佳反应与古诺

收益矩阵两个对角格为(3,3)、(2,2)，另外两格均(0,0)。先标每人的最佳反应，再用第一题的需求与成本分析三家相同企业。

参考：两个对角格都是纯策略纳什，收益高低不决定另一格是否稳定。三家古诺每家(50-10)/(1×4)=10，总Q30、P20，每家利润100；CS450、总剩余750。与垄断600、竞争800比较时，保持需求与技术相同。

## 练习三：交换与网格边界

A禀赋(6,2)，B(2,6)，偏好均sqrt(xy)，py归一为1。求竞争分配，再比较有效与公平。

参考：总量(8,8)，px1，每人财富8，消费各(4,4)，效用由sqrt12约3.464102增为4。A(7,7)、B(1,1)在合同曲线上，却不使B相对初始改善，不能因有效就称为帕累托改进。

网格反例：在总量(10,10)时，A(1,2)可能不被其他整数点改进，但连续改为A(1.5,1.5)、B(8.5,8.5)双方更好。参考：A效用由sqrt2增至1.5，B由sqrt72增至8.5。答案必须写出这是“扩大可行集合后”的改进，不能偷偷把小数点塞进原整数网格。

## 练习四：更强污染与减排配置

沿用30章MB60-0.5Q、MPC12+0.25Q，将MD改为0.5Q。

参考：私人Q仍64；社会最优Q38.4，税19.2，社会净收益 `W(Q)=48Q-0.625Q²`。W64=512，W38.4=921.6，无谓损失409.6。税收与损害的福利口径不能重复扣除。

独立减排题：两家MAC2zA/6zB、容量各10，总减排8时A6/B2、成本48；总减排18时A10/B8、成本292。许可价格的边际减排对象与前一题的单位产出税不同，不能将默认许可价格18直接当成默认矫正税12的替代值。

## 练习五：公共品与共有资源

MBA=max(0,20-g)、MBB=max(0,12-g)，MC改为20。

参考：社会最优g6，边际收益14+6=20；净收益(32-20)×6-6²=36。两人单独目标供给均0，自愿总供给0，社会净收益0。这里应纵向加总边际收益。

共有资源另设三位相同使用者，πi=ei(8-E)。参考：每人努力2、总6，非合作总收益12；社会最优仍总4、收益16。它是过度使用，不是公共品供给不足。

## 练习六：参与池与隐藏努力

1. 默认品质价值与保留价，高品质占0.75，结果？答：报价175，两类参加，按原潜在商品计算交易净收益35。
2. 高品质份额仍0.5，但高品质保留价140，结果？答：报价150，两类参加，平均交易净收益40。
3. 保障比例0.9、损失100、努力成本4、概率0.3降到0.1，努力吗？答：不努力成本3，努力5，故不努力；社会预期成本30。
4. 若努力成本降为2，同样保障0.9？答：两种私人成本都为3，按程序的弱偏好约定选择努力；这不是严格激励。
5. 信号工资增量9、高低成本2/8，能保持原分离激励吗？答：低类型也有净收益1，原条件失效；仍未求完整信号均衡。

## Python参考调用

以下为依赖stage5/models.py的交互片段。先在stage5目录的Windows PowerShell执行python，再输入：

```python
from models import monopoly,cournot,exchange_equilibrium,externality,abatement
from models import public_good,commons,lemons,hidden_action

print(monopoly(a=50,b=1,mc=10))
print(cournot(firms=3,a=50,b=1,mc=10))
print(exchange_equilibrium((6,2),(2,6)))
print(externality(damage_slope=.5))
print(abatement(required=18))
print(public_good(unit_cost=20))
print(commons(users=3))
print(lemons(high_share=.75))
print(hidden_action(coverage=.9,effort_cost=2))
```

每次调用改变的是不同模型。即使数字碰巧相同，也不能因此把价格、税或数量解释为同一个现实市场的共同观测。

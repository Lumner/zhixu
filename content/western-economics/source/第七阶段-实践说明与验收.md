# 第七阶段实践：短期总需求实验台v0.4a

## 交付目标与范围

交付两份JSON报告、一份手算核对表和约1000字中文说明。实验台覆盖第39—44章的需求模型、政策比较与独立银行账本。它接在v0.3宏观核算之后，仍没有总供给、通胀动态、真实政策估计或完整国家经济模型；第45—50章将继续扩展v0.4。

完整入口[demand_lab.py](示例代码/stage7/demand_lab.py)，依赖同目录[short_run.py](示例代码/stage7/short_run.py)。学习程序只用Python标准库，没有在线数据和第三方安装。先读[方程与符号约定](短期模型方程与符号约定.md)，特别核对G只消费、I含公共投资与利率小数单位。

## 第一步：手算并预测输出

普通基准应为A320、λ.4、Y700、i4%、C490、T180、私人I40、公共I20。产品残差与货币残差均应接近0。另一个固定零利率的产品模型基准为Y800，报告中的该结果不是联立模型前后不一致。

预测G+20时Y约733.333333、i约4.666667%；G+20与Ms+40时Y750、i4%。写出两个不同政策闭合条件，再运行验证，不用先看JSON抄答案。

## 第二步：从自己的副本运行

以下在Windows PowerShell进入stage7目录执行。输出目录是你运行时创建的个人学习结果，课程源包没有预装你的“已完成”文件。

```powershell
Set-Location 'C:\Users\17597\Desktop\tutorial\content\western-economics\source\示例代码\stage7'
New-Item -ItemType Directory -Path 'my-results' -Force
python demand_lab.py --g-change 20 | Set-Content -Encoding utf8 'my-results/fiscal.json'
python demand_lab.py --g-change 20 --money-change 40 | Set-Content -Encoding utf8 'my-results/accommodated.json'
python demand_lab.py --regime floor --money-change 300
```

`Set-Content`会覆盖指定同名结果，选择自己的文件名。Windows PowerShell保存的UTF-8可能含BOM，Python读取可用`utf-8-sig`。程序自身只打印报告，不改任何源文件；标准JSON用ASCII转义保证跨终端稳定，`allow_nan=False`拒绝NaN/Infinity输出。

## 第三步：逐项核对报告

| 字段 | 核对内容 |
| --- | --- |
| version、origin、scope | v0.4a、synthetic_teaching_parameters、固定价格且非经验预测 |
| base_parameters、scenario_parameters | 明确保留各参数，观察是否只改变预定政策项 |
| base、scenario | 各自的均衡Y/i、支出、储蓄和两个残差 |
| changes | scenario减base；利率差以小数表示，转百分点要乘100 |
| fixed_zero_interest_goods_example | 固定i0的独立产品均衡，不与普通联立答案混读 |
| multipliers | 固定利率、普通IS—LM的不同乘数；分段跨界不能全程套普通乘数 |
| independent_bank_ledger | 41章独立账本，不由财政货币参数自动驱动 |

还要核对投资细分：普通财政情景总I减少6.666667，公共投资仍20；产出相较维持利率的750少16.666667，两者不是同一种挤出量。

## 第四步：单独检查下限

`--regime floor --money-change 300`让名义Ms从默认400变700，P1，得到Y800、i0、`liquidity_holdings`60。`linear_money_gap`也为60；`total_money_demand`将额外持有包含进去，最终货币残差才为0。

另运行`--regime floor --money-change 400`，得到相同Y800与额外160。再运行`--regime floor --money-change 300 --g-change 50`，应退出下限到Y约908.333333、i约.666667%。至少留一个分支不成立的候选计算，说明为什么必须切回普通方程。

普通模式直接Ms增300会报错，含义是超出普通函数承诺的非负利率区间，不等于现实经济不可能出现这种货币量。分段模型只覆盖一种下限机制，不能据此声称所有现实政策工具失效。

## 第五步：改变结构参数并说明假设

试运行`--import-propensity .1`，默认普通均衡应为Y600、i2%；固定零利率产品均衡640。进口漏出变化会改变两种模型，不要只改固定利率报告里的乘数。

`--mpc`、`--tax-rate`允许改变消费和比例税参数，但合法参数范围不保证每组普通解都落在有效经济区间。出现负私人投资、负消费或隐含负利率时，程序会拒绝；先解释原因，不用“把负数改成0”让输出看起来可用。

- 两个市场残差均接近0；下限分支明确区分线性缺口与额外持币。
- 比较固定货币、固定利率与下限，说明参数与单位，能解释G/I分类和实际ΔT。
- 银行账本逐步平衡，且不把它当成IS—LM的内生货币供给机制。

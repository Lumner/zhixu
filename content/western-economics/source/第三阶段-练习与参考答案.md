## 题目

基础市场改为 `Qd=100-2P`、`Qs=2P`。

1. 无税均衡价、数量、消费者剩余、生产者剩余与总剩余各是多少？
2. 每杯税10元，买卖方价格、数量、双方每杯税负、税收与无谓损失各是多少？
3. 从无税价25提高到30，沿需求线数量如何变化？用中点法计算带符号弧弹性，并比较总收益。
4. 最高限价20下的需求、供给、短缺和交易上界？最高限价30呢？
5. 最低限价30下的过剩和交易上界？能否保证生产者卖出计划供给量？
6. 要判断最高限价后的消费者剩余，除了供求曲线还缺什么？

## 参考手算

1. `100-2P=2P`，P=25、Q=50。反需求截距50、反供给截距0。CS=625、PS=625、TS=1250元/日。
2. `100-2(Ps+10)=2Ps`，Ps=20、Pc=30、Q=40。买方多付5、卖方少收5，双方各承担50%的单位价格负担。税收400、税后CS=400、PS=400，含税总量1200，无谓损失50。检查1250=400+400+400+50。
3. Q从50到40。平均Q=45、平均P=27.5；弹性 `(-10/45)/(5/27.5)=-11/9≈-1.222222`。总收益从1250降到1200，与本区间富有弹性一致。
4. 上限20约束时Qd=60、Qs=40、短缺20、交易上界40。上限30非约束，仍在25交易、数量50，不能把30强制代入。
5. 下限30时Qd=40、Qs=60、过剩20、交易上界40；没有额外收购和匹配假设，不能保证卖出60。
6. 缺实际交易量、哪些买者获得商品、匹配规则及搜寻成本等。只说价格更低不足以确定总消费者剩余。

## Python参考调用

这是**依赖本课econ和elasticity模块的交互片段**，不是独立文件。先在示例目录的PowerShell运行 `python`，再输入：

```python
from econ import equilibrium, taxed_market, price_control, welfare
from elasticity import midpoint_elasticity

base = equilibrium(a=100, b=2, c=0, d=2)
print(base)
print(welfare(base["price"], base["price"], base["quantity"], a=100, b=2, c=0, d=2))
print(taxed_market(10, a=100, b=2, c=0, d=2))
print(price_control("ceiling", 20, a=100, b=2, c=0, d=2))
print(midpoint_elasticity(25, 50, 30, 40))
```

所有参数都要一致：不能只改equilibrium的参数，却让taxed_market继续使用默认市场。CLI v0.1只暴露税和控制价，改基础模型时使用以上模块调用，或在自己的练习副本新增参数功能。

## 进阶改造与参考思路

将需求截距改为120，其余保持本题值，先预测再复算。答：无税P=30、Q=60；税10后Pc=35、Ps=25、Q=50；税收500、DWL50。需求右移改变均衡水平，线性斜率相同使此例数量减少仍为10。

试把税改为50，在本题参数下刚好无交易。配套内点程序应拒绝此情景，不能把报错当作数学上“不存在任何状态”；它表示当前实现没有覆盖无交易分段。扩展前先写分段定义和应有输出。

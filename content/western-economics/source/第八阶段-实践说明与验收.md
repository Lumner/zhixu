# 第八阶段实践：宏观政策实验台v0.4

## 交付目标

完成一份综合JSON、两组自选条件比较和一份约1000—1500字中文说明。它覆盖39—50章范围中的基础需求与政策主题，但本入口仅汇总stage8独立实验；旧stage7需求实验台保留原入口，不声称已合成完整国家动态预测软件。

源文件为[policy_lab.py](示例代码/stage8/policy_lab.py)与[policy_models.py](示例代码/stage8/policy_models.py)，全部标准库。先读[方程与口径](波动政策与债务模型约定.md)，特别区分价格水平/通胀率、政策利率/债务计息率、名义/实际增长。

## 先写预测，再运行

默认AD—AS应为Y700/P1；适应预期通胀路径2.5%、3%、3.5%、4%；财政正常PB25、总余额−3，衰退PB−6.5、总余额−34.5；规则基准x0/π2%/i4%；债务第一年N728/B580.72/比率79.769231%。这些结果来自不同账本，不能按名称相同就彼此代入。

在Windows PowerShell的个人副本目录执行：

```powershell
Set-Location 'C:\Users\17597\Desktop\tutorial\content\western-economics\source\示例代码\stage8'
New-Item -ItemType Directory -Path 'my-results' -Force
python policy_lab.py | Set-Content -Encoding utf8 'my-results/base.json'
python policy_lab.py --ad-shift 20 --demand-gap 0.02 --years 5 | Set-Content -Encoding utf8 'my-results/demand.json'
python policy_lab.py --cost-shock 0.1 --inflation-shock 0.01 --interest 0.08 --nominal-growth 0.01 --primary-surplus -0.02 --years 5
```

`Set-Content`会覆盖同名学习输出，选择自己的路径。Windows PowerShell可能写UTF-8 BOM，Python读取可用`utf-8-sig`。程序自己不改源数据，不联网；NaN/Infinity不允许进入规范JSON。

## 参数归属

| 参数 | 影响哪一块 | 不表示什么 |
| --- | --- | --- |
| --ad-shift | AD自主支出A相对320的增量 | 不自动改变财政账本或债务 |
| --cost-shock | 45章AS价格截距z | 不自动等于当期通胀冲击 |
| --demand-gap | 49章需求冲击d，小数缺口 | 与A的金额增量不同单位 |
| --inflation-shock | 49章通胀冲击s，小数率 | 不修改46章外部失业路径 |
| --interest | 50章债务名义有效利率 | 不改变49章政策利率规则 |
| --nominal-growth | 50章名义GDP增长 | 不按其数值自动生成真实增长或通胀 |
| --primary-surplus | 50章初级盈余/本期GDP | 正为盈余，负为赤字；不是金额 |
| --years | 债务递推期数，1—100 | 不生成真实年份预测 |

第三条命令同时改变若干**独立**实验。报告时逐块解释，不能把全部输出合在一起声称“某项政策导致这条十年国家路径”。真正联立还需统一时间、行为、价格与预算反馈。

## 必须核对的四件事

1. AD—AS的产品、货币与供给残差；长期候选若使用，写出Pe调整条件。
2. 预期路径先算本期π再更新；传播序列的历史变量不能覆盖错位。
3. 财政PB=(T−G)−J，总余额再扣利息；借债是净增量，另有滚续融资需求。
4. 规则模型的需求/通胀/规则残差与下限检查；债务每年金额与比率相互回代，流量分母为本期GDP。

## 报告怎么写

用“问题与假设、单位与来源、手算与程序、两组条件比较、边界与未识别因素”组织。至少选择一个价格水平例子与一个债务例子，不用外部真实数据也可完成。若另用真实材料，另存来源与获取日期，不覆盖合成样本或把它们拼接为官方序列。

至少留下一个被拒绝的输入，例如`--nominal-growth -1`、`--years 0`或`--ad-shift nan`，说明原因。测试报告是维护者实际验证，不自动证明你的个人练习已完成。

## 验收条件

能运行六个章内入口和综合入口；能复算三项残差与一项金额/比率检查；清楚区分独立块，不把模型参数当真实制度。能解释自动稳定与主动支出、初级与总余额、名义与实际增长、下限分支及政策规则的不确定性。

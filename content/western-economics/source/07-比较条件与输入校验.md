## 从一个判断开始

预算够不够取决于收入是否大于或等于支出。比较符号`>=`回答这一问题，结果只有`True`或`False`，这种类型称为布尔`bool`。其他符号为`>`、`<`、`<=`、`==`（相等）、`!=`（不相等）。注意单等号负责赋值。

以下是**需要已有income与expense数值的片段**：

```python
if income >= expense:
    print("Enough budget")
else:
    print("Not enough")
```

`if`后接条件和英文冒号。缩进的一组语句属于这个分支；使用四个空格，别把Tab与空格混在一起。`else`在条件不成立时执行。同一轮只执行符合规则的分支。

## elif与逻辑组合

`elif`表示前面的条件不成立时再判断一个条件。`and`要求两边都成立，`or`只要一边成立，`not`取反。`income < 0 or expense < 0`表示两项中有一项为负便应拒绝。

多个分支的顺序很重要。先判断无效数据，再判断经济结果，避免负支出被误判成“预算充足”。相等边界也要明确：本课规定收入等于支出属于余额0、预算恰好足够。

## 非数字为什么会失败

`float("abc")`无法形成数字，解释器会抛出`ValueError`。**异常**是程序发现无法按正常流程完成操作时发出的信号。`try`包住可能失败的转换，`except ValueError`规定这种失败如何处理。

完整文件见[decision.py](示例代码/decision.py)。它还包含：

```python
import math
```

**模块**是装有可复用工具的代码单元，`import`让本文件使用它。`math`是Python自带数学模块，`math.isfinite(x)`判断x是不是有限数。文字`nan`、`inf`有时能被`float`接受，却不适合作为本题金额，因此也要检查。这里的点号表示“math里面名为isfinite的函数”。不用自己写这些数学判定规则。

## 运行完整程序并记录四次输入

在示例目录的PowerShell执行：

```powershell
python decision.py
```

程序先问收入，后问支出。每次输入一项后按回车；要换情景就重新执行命令。

| 收入输入 | 支出输入 | 预期最后一行 | 原因 |
| --- | --- | --- | --- |
| 1000 | 800 | `Balance: 200.00 yuan` | 收入大于支出 |
| 800 | 1000 | `Shortfall: 200.00 yuan` | 差额需补足 |
| -1 | 100 | `Income and expense must be non-negative.` | 违反金额范围 |

再测试收入1000、支出1000，应显示余额0.00。输入nan或inf应被有限数检查拒绝。本题的异常处理只负责数值转换；键盘中断属于使用者主动结束，不把所有失败都吞成“请输入数字”。

## 结果与原因

条件把允许输入划分成不同情况。负金额判断不属于所有经济问题的普遍规则，例如企业利润可为负；本例因为输入定义为收入和支出金额而拒绝负数。规则必须跟随变量含义，不能把同一校验盲目用于所有列。

## 常见错误

- 漏冒号或缩进不一致，产生语法或缩进错误。
- 用两个独立`if`代替互斥分支，导致同一轮打印多种结果。
- 写 `if income = expense`。赋值不能在这里代替相等比较。
- 只判断输入“能转成float”，忽略负数、非有限值和经济含义。

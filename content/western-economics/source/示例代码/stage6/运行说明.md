# 第六阶段例程：标准库宏观测量实验

适用于已完成第05—12章Python入门的读者。只需Python标准库；六个章内入口、一个综合入口和一个共享模块，共8个Python文件。9个数据/说明文件与程序一起保留，不要只复制入口。

## 在哪里运行

Windows PowerShell，进入原项目或下载包解压后的对应`source/示例代码/stage6`。原项目路径为：

```powershell
Set-Location 'C:\Users\17597\Desktop\tutorial\content\western-economics\source\示例代码\stage6'
python --version
python gdp_accounting.py
python price_volume.py
python inflation.py
python labour.py
python sector_balances.py
python data_reading.py
python macro_lab.py
```

以上每行单独回车。完整程序都读取自身目录下data，不需要联网。`macro.py`被其他入口导入，不是第八个交互教程入口。不要把CSV当Python运行。

## 参数和错误

```powershell
python macro_lab.py --help
python macro_lab.py --scenario job_growth --vintage initial
python macro_lab.py --nominal-rate 0.03 --inflation 0.05
python macro_lab.py --inflation -1
python macro_lab.py --inflation nan
```

最后两条预期报错、退出码2，不能当成功结果。利率输入用0.03代表3%。未知情景、未知版本也由argparse拒绝。多组参数只改变各自独立实验，不模拟相互影响。

## 常见故障

`No module named macro`通常是只复制入口；把同目录macro.py一起复制。`FileNotFoundError`先确认data是否随程序解压。字段错误看CSV第一行是否改名、是否有空列。不要为通过验证把NaN或无定义比率强制填0。

若改变数据，请在自己的副本实验。由于若干输出有情景假设，人数和金额变动后要先检查经济含义。自动验证对原交付数据负责，不保证任意外部数据可用。分母为零时基础函数和相应入口保留未定义值。

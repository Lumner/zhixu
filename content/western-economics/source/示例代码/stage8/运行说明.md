# 第八阶段例程：波动、政策与债务

第45—50章新增6个完整章内入口、1个综合入口和1个模块。只需Python标准库；没有真实数据文件或在线接口。图解由维护者制作，学习者不必安装Matplotlib。

## 平台和目录

Windows PowerShell逐行执行，下载包解压后换成自己的绝对目录：


## 综合入口示例

```powershell
python policy_lab.py --help
python policy_lab.py --ad-shift 20
python policy_lab.py --demand-gap 0.02 --inflation-shock 0.01
python policy_lab.py --interest 0.08 --nominal-growth 0.01 --primary-surplus -0.02 --years 5
```

这些参数各自控制不同模块，不自动联动。尤其债务有效利率不会改写政策利率规则，AS价格截距不会改写适应预期路径。输出只是并列报告，不能冒称完整经济预测。

以下预期报错、退出码2：

```powershell
python policy_lab.py --ad-shift nan
python policy_lab.py --nominal-growth -1
python policy_lab.py --years 0
python policy_lab.py --years 2.5
python policy_lab.py --primary-surplus 2
```

最后一条使总债务转负，超出本模型范围，不能硬填0。某些AD输入即使数值有限，也会造成继承的普通区间负利率或负私人投资，同样拒绝。脚本只打印，不修改默认参数或写个人结果目录。

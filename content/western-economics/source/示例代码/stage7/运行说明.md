## 综合入口参数

```powershell
python demand_lab.py --help
python demand_lab.py --g-change 20
python demand_lab.py --g-change 20 --money-change 40
python demand_lab.py --import-propensity 0.1
python demand_lab.py --regime floor --money-change 300
python demand_lab.py --regime floor --money-change 300 --g-change 50
```

`--g-change`改变政府消费，未改变公共投资；`--money-change`是相对默认名义Ms400的增量，P1。`--mpc`、`--tax-rate`、`--import-propensity`分别控制结构参数，基准与政策情景都使用新结构。`--regime`为ordinary或floor，`--floor`只在后者生效、使用小数利率。

报告中的普通乘数只适用于普通区间，不可拿来跨越分段点推断全部变化。财政与货币变化不驱动`independent_bank_ledger`，它是独立记账练习。

## 预期拒绝的输入

```powershell
python demand_lab.py --mpc 1
python demand_lab.py --money-change nan
python demand_lab.py --regime ordinary --money-change 300
python demand_lab.py --regime ordinary --floor 0.01
```

这四条预期错误并退出码2，不是成功算例。普通高货币例子隐含负利率；选floor才是明确增加了分段假设，而非单纯隐藏报错。h与P在基础函数中要求正数，未知参数键也被拒绝。

## 复现与故障处理

`No module named short_run`通常表示只复制入口，补齐同目录模块。浮点残差在很小容差内即可，不要按显示四舍五入后再计算。若改数据或参数，在自己的副本中先写预期、再运行，保留模型有效区间；不可通过改默认全局字典让比较基准悄悄变化。

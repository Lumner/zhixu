# 第九阶段例程：开放经济与增长

第51—56章新增6个完整章内入口、1个综合入口、1个共享模块。全部Python标准库，没有联网API、真实汇率或国家增长数据。维护者静态制图的Matplotlib不属于本阶段学习依赖。

## 平台与目录


## 参数与预期错误

```powershell
python global_growth_lab.py --help
python global_growth_lab.py --regime fixed --fiscal-change 20
python global_growth_lab.py --regime floating --money 480
python global_growth_lab.py --saving 0.3 --technology-growth 0.03 --years 30
python global_growth_lab.py --saving 1.1
python global_growth_lab.py --money nan
python global_growth_lab.py --years 0
```

最后三条预期报错、退出码2，不算成功样例。综合期数1—200；模块可用0期看初始状态。单独复利函数可处理人口负增长，但综合入口共用人口参数进入基础索洛，后者限定非负n，因此不承诺负n的综合实验。

固定制度的money是尝试量，结果明确列满足汇率条件所需量；浮动制度money为外生水平。`--saving`不修改独立AK，`--output-growth`不修改索洛生产技术，避免把不相关参数悄悄联动。

## 复现与故障

`No module named open_growth`通常表示只复制入口。NaN、负价格、q非正、私人投资为负、无有限稳态或超出浮点范围时应查假设，不用截成0掩盖。没有输入文件可被程序覆盖；自己的输出与参数改造留在副本中。

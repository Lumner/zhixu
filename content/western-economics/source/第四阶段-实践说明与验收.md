# 第四阶段实践：微观实验台v0.2a

## 当前范围

本项目组合19—26章的消费者、风险、跨期、成本与劳动实验，是完整v0.2的前半批。27—32章的垄断、博弈和市场失灵尚未实现，宏观部分也没有交付。本版本把多个独立模型放到同一运行入口，没有声称求解一个联立的完整经济体。

## 运行与预期

取得整包后，进入source/示例代码/stage4。在Windows PowerShell执行：

```powershell
python micro_lab.py
python micro_lab.py --income 180 --new-px 12 --price 20 --wage 20
python micro_lab.py --help
```

基准输出应包含消费者(10,20)、斯勒茨基补偿(15,15)、企业q13/利润69、劳动L6/Q84；风险和跨期结果对照22章。第二次结果对照26章末表述。

参数归属要逐项说明：income与new-px属于消费者；price属于二次成本的竞争企业；wage属于单独劳动模型。劳动模型内部产品价仍为2，不随--price改变。风险与两期模型当前使用固定默认参数，可以在模块交互调用中另改，CLI未暴露全部选项。

## 报告模板

在自己的练习目录新建report.md，按下列结构写600—1000字，附表和运行命令不计字数：

1. 问题：分别分析哪一个模型，单位、输入、输出是什么。
2. 基准：列关键公式和手算值，至少一项不依赖程序复核。
3. 反事实：只改变一个指定参数，先预测方向，再解释数值。
4. 最优检查：内点条件、凹性和边界分别做了什么。
5. 异常输入：实际执行一项坏输入并记录提示；例如负收入或0价格。
6. 限制：明确效用表示、补偿定义、连续近似、借贷约束与市场结构范围。

推荐最小对照为“消费涨价”与“企业亏损是否停产”两项；再选风险或劳动之一。不得把不同模型同名的price直接合并成一个价格，也不得将教学参数描述为真实估计。

## 验收表

| 项目 | 通过条件 | 可观察证据 |
| --- | --- | --- |
| 可行消费 | 支出不超过收入，说明连续与网格区别 | 预算图、支出残差 |
| 效应分解 | 写明斯勒茨基规则，分项加总正确 | 三状态表和计算 |
| 风险/跨期 | 区分平均财富与平均效用，或核对现值预算 | 一项完整手算 |
| 企业选择 | 亏损时与停产利润比较 | P20与P3两行 |
| 劳动选择 | MRPL的价格条件和边界清楚 | L6内点与高工资零用工 |
| 程序与错误 | 命令、实际环境、参数归属、异常提示齐全 | 本次输出记录 |
| 结论 | 不超出模型，不把剩余叫全口径利润 | 限制段落 |

不要把作者的验证日志直接改名为自己的独立完成记录。作者日志证明配套程序执行过，你的验收还要求不看答案改参数并解释结果。

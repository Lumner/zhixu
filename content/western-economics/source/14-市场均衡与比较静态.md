# 14 市场均衡与比较静态

## 学习目标与先修

先完成13章并会联立一次方程。约3—5小时，求均衡、计算短缺过剩、分析单一冲击和双重冲击，理解比较静态的能力范围。

## 均衡是什么

在竞争性市场的入门模型中，**均衡价格**使需求量等于供给量，双方交易计划相容；共同数量是均衡数量。它是模型的相容状态，不自动表示公平、所有需求都满足，也不保证现实立刻到达。

本课无税基线：

```text
Qd = 120 - 2P
Qs = 3P
均衡要求 Qd = Qs
120 - 2P = 3P
P* = 24，Q* = 72
```

星号表示均衡值，不是乘号。价格单位元/杯，数量杯/日。回代两式都得72，图中交点(72,24)。

## 价格偏离时发生什么

P=20时，Qd=80、Qs=60，**短缺**20杯。它是该价格下意愿数量差，不能说已成交80杯；在没有其他来源与强制交易时，可成交量至多60。P=30时，Qd=60、Qs=90，**过剩**30杯，可成交量至多60。

常见直觉是短缺给价格上调压力，过剩给价格下调压力。这还依赖价格可调整、竞争、信息和交易机制。两条静态方程没有写具体调价速度，不能据此声称“三天内一定收敛”。工资、住房、长期合同等还可能有额外摩擦。

## 比较静态：一次只改一个条件

**比较静态**比较改变外生条件前后的均衡，不描述中间每一时刻的路径。

情景一：需求截距由120提高到150，供给仍为3P。

```text
150 - 2P = 3P
P = 30，Q = 90
```

价格提高6元，数量增加18杯。与在固定价格24比较需求增加30杯不同，均衡调整过程中价格也提高，压回部分需求并诱使供给增加。

情景二：需求不变，供给因成本变为 `Qs=3P-12`，正数量区域求解：

```text
120 - 2P = 3P - 12
P = 26.4，Q = 67.2
```

价格上升、数量下降。数量出现小数是连续模型的近似，可以理解为较大规模市场的平均日交易流量；不能真的卖0.2杯时，应说明离散交易需要调整模型。

## 通用公式与Python核对

将两条关系写成 `Qd=a-bP`、`Qs=c+dP`，要求b、d为正，求得 `P=(a-c)/(b+d)`，再回代 `Q=a-bP`。c可能为0或负数，本课程序对供给采用非负截断，并只接受正交易的内点均衡。

本课完整模型模块见[econ.py](示例代码/econ.py)。在示例目录的PowerShell输入 `python`进入交互模式，再输入以下Python片段；不复制提示符：

```python
from econ import equilibrium
print(equilibrium())
print(equilibrium(a=150))
print(equilibrium(c=-12))
```

主要结果分别为价格24/数量72，30/90，26.4/67.2。某些浮点数字可能显示更多尾数，近似比较即可。结束输入 `exit()`。

## 双重移动不能靠一个箭头决定

需求增加同时供给减少，价格在标准条件下都受到上升作用，但数量方向取决于幅度。例如a=150、c=-12时P=32.4、Q=85.2，比基线数量高；a=126、c=-60时P=37.2、Q=51.6，比基线低。

只给“需求增加、供给减少”却不给幅度，不能唯一判断数量。应报告可确定的方向和仍需参数才能判断的部分。

## 常见错误

- 只求交点、不回代两式，也不检查价格和数量是否在适用域。
- 将计划供给量直接当实际销售量，忽略市场另一侧。
- 把比较静态的前后两点当成完整时间轨迹。
- 多个条件同时变化，却用单一冲击结论解释全部差异。

## 练习与参考答案

1. P=10时短缺多少？答：Qd=100、Qs=30，短缺70，可交易上界30。
2. 需求改为 `Qd=100-2P`，均衡？答：P=20、Q=60。
3. 供给改为 `Qs=4P`，需求仍为120-2P？答：P=20、Q=80；供给扩张使价格降、数量增。
4. 均衡意味着所有人都买得到吗？答：只是按该价格愿意且能够购买的数量与供给相等，无法支付者的愿望不在相同定义中。

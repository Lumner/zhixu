# 第六阶段：宏观指标口径与数据字典

## 数据来源与边界

核验日期2026-11-13。`示例代码/stage6/data/`包含6个CSV和3个JSON。6个CSV与`accounts.json`全部由本课人为设置，独立服务不同例子，**不能拼成一个真实国家的完整账本**。`metadata.json`描述这些教学数据；`official_reading.json`单独保存少量官方历史公告摘录，不参与教学模型运算。没有在线抓取脚本或自动更新接口。

代码的`DATA=Path(__file__).resolve().parent/"data"`相对程序位置找数据，运行所在目录可以变化。CSV为UTF-8，首行是固定字段名。允许UTF-8 BOM；字段顺序、空字段、多余字段、非有限数值等会被检查。JSON是对象，数值不带百分号。十进制0.05表示5%。

## 文件与字段

| 文件 | 字段与含义 | 单位、时期、口径 |
| --- | --- | --- |
| [value_added.csv](示例代码/stage6/data/value_added.csv) | stage生产环节；output总产出；intermediate当期中间投入 | 同一虚构期、相同教学金额、没有税价调整；不是三个时期 |
| [goods.csv](示例代码/stage6/data/goods.csv) | good商品ID；base_price/base_quantity基期价格/数量；current_price/current_quantity现期价格/数量 | 同一虚构经济两期；各商品数量单位内部一致，价格为教学金额/该商品单位；先假定无进口，用于固定基期实际GDP，也借同两商品构造消费篮子 |
| [producer_prices.csv](示例代码/stage6/data/producer_prices.csv) | good；base_price；base_quantity；current_price | 与goods独立的生产者篮子；保持基期数量固定，不声称对应实际官方PPI样本 |
| [labour.csv](示例代码/stage6/data/labour.csv) | scenario情景；population调查范围人口P；employed就业E；unemployed失业U；outside非劳动力N | 人；同一调查范围三种替代情景，非连续年份；base/discouraged/job_growth；不代表全国或某年龄组 |
| [quarterly.csv](示例代码/stage6/data/quarterly.csv) | year年份；quarter季度1—4；value当季量 | 虚构2023—2025年，固定教学价格的GDP量、未季调、教学计量单位；不是累计值；全年可加总 |
| [vintages.csv](示例代码/stage6/data/vintages.csv) | vintage版本；year；quarter；value | 独立于quarterly.csv的两组修订例子；相同单位口径，初版100/108，修订101/109；两发布日期为虚构 |
| [accounts.json](示例代码/stage6/data/accounts.json) | y,c,g,i,x,m,t及两项境外净收入，见下表 | 同一虚构期、同一现价教学金额；非实际财政预算或国际收支表 |
| [metadata.json](示例代码/stage6/data/metadata.json) | kind、date、datasets、knownSeasonalPattern等 | kind为synthetic_teaching_data；记录构造、范围和限制，没有可推断的真实地区 |
| [official_reading.json](示例代码/stage6/data/official_reading.json) | publisher/title/url/publishedDate/accessedDate/referencePeriod等 | 官方2024全年GDP历史发布的少量手工摘录；kind为official_publication_excerpt；非全量快照、非读取日最新新闻 |

### accounts.json的十个键

| 键 | 符号与含义 | 基准值 |
| --- | --- | ---: |
| y | Y，GDP | 1000 |
| c | C，居民最终消费 | 600 |
| g | G，政府最终消费，仅消费 | 180 |
| i | I，总资本形成，含公共、私人投资和存货 | 200 |
| x | X，出口 | 90 |
| m | M，进口 | 70 |
| t | T，简化净税收，税收减向私人转移 | 220 |
| net_primary_income | NPI，来自境外的初次收入净额 | 0 |
| net_current_transfers | NCT，来自境外的经常转移净额 | 0 |

两项境外净收入在本模型归入合并私人部门；政府用T−G表示简化总储蓄。若改成政府全部购买口径，必须同步重分公共投资，不能重复计入。NPI、NCT、T、存货投资可有负值；消费、进出口等本例输入限定非负。没有将私人部门储蓄减总投资冒称严格的私人净借贷。

## 时间序列与版本规则

`quarterly.csv`要求年份与季度是整数、相邻期连续、无重复；`quarterly_rates`第一期环比、前四期同比为`None`，不填成0。`annual_totals`需要每年四个季度齐全。`cumulative_to_quarters`是教学累计非负GDP转换函数，每年必须从Q1开始；它不适合直接套任意可正可负的流量指标。

已知季节模式为(1,1.1,1.05,1.25)，先除以其均值1.1，再以原数除对应因子。因子是设计者已知的构造，不是从数据估计。只在此特殊序列中调整前后年度和一致；一般情形不保证这一性质。

修订例子的虚构初版发布日期2024-04-30、修订版2024-07-31。每版均含2023Q1和2024Q1，计算同比不得混版。官方GDP摘录的真实发布日期2025-12-26，与这两个教学版本无关。

## 字典输出与未定义值

`production_chain.gdp=250`、`price_volume.current_nominal=1500`、`accounts.gdp_expenditure=1000`来自不同小经济。综合报告将它们并列呈现，不要求彼此相等。所有利率和增长率用小数；`deflator_base_100`与`index_base_100`是指数水平，125与135不能再乘100当百分数。

没有劳动力时失业率未定义，JSON写`null`。没有现期产量时GDP平减指数也未定义。`allow_nan=False`避免NaN混入标准JSON。函数校验只能发现部分算术或格式问题，不能证明外部数据无误或统计制度可比。

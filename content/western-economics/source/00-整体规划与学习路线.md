# 00 整体规划与学习路线

## 你将学会什么

“西方经济学”在本课指以微观经济学和宏观经济学为主体的入门分析课程。微观研究家庭、企业及具体市场怎样选择；宏观研究总产出、就业、物价、经济波动和长期增长。学习时既要会解释机制，也要会检查模型的假设与数据口径。

你不需要先学 Python、微积分或其他编程课。先修只要求能进行四则运算、使用电脑保存文件。必要的代数、百分比、函数、导数和统计会在使用前解释。课程不是投资建议，也不把单个模型当作现实世界的完整描述。

最终作品是“经济学实验台”：用 Python 读取有来源说明的数据，计算市场均衡、政策情景和宏观指标，生成图表，再写一份能区分假设、恒等式、模型结果与经验证据的报告。

## 当前交付与学习投入

全课 **60个主线章节、10个阶段均已交付正文、练习答案与Python实验**。01—18讲起步和供求，19—32补齐微观分析，33—50进入核算、短期需求、波动与政策，51—56加入国际收支、汇率、增长及模型比较，57—60完成科学计算、统计和可复现小型报告项目。完整学习主线已交付，不代表读者个人毕业验收或全部经济学专题完成。

建议全课投入225—320小时，包含手算、重跑、改错和写报告；前三阶段约55—80小时，第四阶段30—42小时，第五阶段23—33小时，第六阶段22—30小时，第七阶段25—36小时，第八阶段25—35小时，第九阶段25—36小时，第十阶段20—28小时。各区间为计划近似值，章内时间已包含练习。网页阅读分钟只估算文字阅读；每周6—8小时可按阶段安排，节奏以实际验收为准。

## 学习方式与贯穿案例

01—04先用纸笔，不把编程门槛压到第一天。05—12逐项学习 Python，每次只引入少量语法。13—18使用同一虚构校园饮品市场：需求 `Qd = 120 - 2P`，供给 `Qs = 3P`，价格单位元/杯、数量单位杯/日。这些数是教学设定，不是对真实市场的估计。

每章按“目标和先修 → 情境 → 定义 → 分步解释 → 演算或操作 → 结果和原因 → 常见错误 → 练习与参考答案 → 完成条件”组织。先预测输出，再运行，最后更换一个数；只复制成功不算通过。程序标注完整文件或依赖上下文的片段，不让初学者猜缺少什么。

对一个结论，你能说清：讨论哪个对象和时期，单位是什么，保持什么不变，改变了什么，以及结果怎样复算。对一段程序，你能指出输入、处理、输出和失败条件。对一个现实论断，你能区分数据描述、模型预测和因果证据。

不要为了赶进度跳过错题。连续两次能在不同参数下独立完成本阶段练习，再进入下一阶段。实际记录分批保存：[前三阶段](验证/验证记录.md)、[第四阶段](验证/第四阶段验证记录.md)、[第五阶段](验证/第五阶段验证记录.md)、[第六阶段](验证/第六阶段验证记录.md)、[第七阶段](验证/第七阶段验证记录.md)、[第八阶段](验证/第八阶段验证记录.md)、[第九阶段](验证/第九阶段验证记录.md)、[第十阶段](验证/第十阶段验证记录.md)，来源核验日期见[资料说明](99-官方资料与核验说明.md)。

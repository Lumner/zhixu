# 18 价格限制与市场实验台

## 学习目标与先修

先完成13—17章。约4—6小时，区分最高限价与最低限价、约束性与非约束性，解释配给和交易量上界，并运行市场实验台v0.1。它是前三阶段作品，完整课程最终项目另见独立说明。

## 最高限价与最低限价

**最高限价**规定合法交易价不得高于某值。若上限20低于无政策均衡24，称为约束性；在上限价，Qd=80、Qs=60，短缺20杯。低价没有自动增加供给，可成交量至多60。

若最高限价30高于均衡24，竞争市场仍可在24交易，称为非约束性；不能强行用30代入供求，再宣称上限造成过剩。最高限价允许价格更低，不规定每笔必须等于上限。

**最低限价**规定价格不得低于某值。下限30高于均衡24时约束供给，Qd=60、Qs=90，过剩30杯。没有政府收购或强制购买时，不能保证卖出90杯。下限20低于均衡时为非约束性。

## 短缺、配给与福利

**配给**指数量不足时由谁获得商品：排队、抽签、关系、配额或其他规则。简单供求给出计划数量差，不能仅凭这两条曲线知道具体分配和真实成交量。

本课程序因此输出 `transaction_upper_bound=min(Qd,Qs)`，称交易量上界。如果买卖双方成功匹配且按规定价格成交，可以达到上界；搜寻失败、库存损失等可能使成交更低。价格控制下剩余取决于谁得到或供给商品，不能未经假设就沿用竞争均衡的三角形。

例如最高限价20，假设60杯全部给支付意愿最高的消费者，CS可按需求曲线下、20元以上的面积算为1500，PS为600，合计2100；若抽签把杯子分给支付意愿较低者，CS可能更低。排队耗时也可能消耗资源。本课CLI不报告限价情景的唯一福利值，以免掩盖配给条件。

## 三类政策情景分别回答什么

| 情景 | 关键约束 | 价格 | 数量解释 |
| --- | --- | --- | --- |
| 无税无管制 | Qd=Qs | 单一均衡价24 | 均衡72 |
| 单位税10 | Pc-Ps=10且Qd=Qs | 买方30、卖方20 | 重新均衡60 |
| 最高限价20 | 价格≤20 | 简化比较取20 | 需求80、供给60，上界60 |
| 最低限价30 | 价格≥30 | 简化比较取30 | 需求60、供给90，上界60 |

程序的税、最高限价和最低限价是**相对同一基线的三个独立反事实**，没有实现同时征税和限价。现实中的租金、最低工资等有合同、市场势力、质量和调整期差异；学习这里的方法后仍需具体建模，不能直接照搬数值结论。

## 运行完整作品

完整入口[market_lab.py](示例代码/market_lab.py)依赖同目录[econ.py](示例代码/econ.py)。从[运行说明](示例代码/运行说明.md)取得完整示例目录，保留两个文件的相对位置。

在示例目录PowerShell执行：

```powershell
python market_lab.py
python market_lab.py --tax 5 --ceiling 30 --floor 20
```

`--tax`等叫**命令行参数**，给本次运行指定数值；未提供时使用默认值。标准库argparse负责读取和说明参数，`python market_lab.py --help`可查看。标准库json把字典格式化为JSON文字，便于同时显示多个结果；`true/false`是JSON写法，Python中是True/False。

第一次运行得到第17章的税收情景，最高限价短缺20、最低限价过剩30。第二次运行税收5对应Q=66；另外两个价格控制均非约束，价格应恢复24、需求供给均72。

尝试 `python market_lab.py --tax -1` 或 `--tax 60`，程序应以清楚的错误信息和非零状态结束。负税属于补贴问题，本版本没有实现；极高税下无交易属于另一分段，也明确留给后续扩展。

## 从代码读经济含义

econ.py将工作拆成参数检查、无税均衡、福利、税后均衡与价格控制五部分。market_lab.py只接收参数、组合调用、输出。**接口**是模块向调用者承诺的输入输出约定，本课以字典键保留结果含义。

你不必现在背完argparse与JSON的全部API，但必须能跟踪`args.tax → taxed_market → report → print`，解释每个价格和数量属于哪种情景。后续版本将在此基础上逐步增加模型，而不是反复覆盖旧例程。

## 常见错误

- 把上限30理解成强制价格30；非约束上限下仍用均衡24。
- 把供给90解释成实际卖出90，遗漏买方意愿限制。
- 把程序输出的交易上界当作已发生的观测。
- 将不同政策情景的数字混合，或把旧市场参数当真实统计估计。

## 练习与参考答案

1. 上限10时短缺和交易上界？答：Qd=100、Qs=30、短缺70、上界30。
2. 下限40时过剩和上界？答：Qd=40、Qs=120、过剩80、上界40。
3. 上限恰好24是否改变本课均衡？答：不改变，程序binding为false，数量72；边界归类需保持定义一致。
4. 要计算限价福利还缺什么？答：至少需实际成交数量、买卖双方配给与匹配规则、搜寻成本等假设。

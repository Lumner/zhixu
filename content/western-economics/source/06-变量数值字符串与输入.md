# 06 变量、数值、字符串与输入

## 学习目标与先修

先完成05章并能运行文件。约3—4小时，学会用名字保存数据、进行计算、显示结果，理解输入文字与数字转换的关系。术语“类型”指数据属于哪一类，会影响能做什么运算。

## 赋值与数值类型

完整示例[budget.py](示例代码/budget.py)使用每月1000元预算。`income = 1000`把整数1000绑定到名字income。等号`=`表示赋值；它会改变程序中的绑定，不表示数学中永恒的等式。

```python
income = 1000
food = 400
books = 120
balance = income - food - books
share = food / income
```

这是完整文件的核心片段；下方输出代码在文件中已提供。Python名字区分大小写，`income`和`Income`不同。用有含义的英文名、单词间用下划线，不用数字开头，也不把`print`、`input`用作变量名。

`1000`是整数`int`，`3.6`是浮点数`float`。浮点数适合一般近似计算，不能保证每个十进制小数精确存储。`0.1+0.2`可能显示为`0.30000000000000004`，这来自数值表示，不是经济机制。

## 运算符与执行顺序

| 写法 | 含义 | 结果示例 |
| --- | --- | --- |
| `+ - * /` | 加、减、乘、除 | `5 / 2`为2.5 |
| `//` | 向下取整的除法 | `5 // 2`为2 |
| `%` | 余数 | `5 % 2`为1 |
| `**` | 幂 | `2 ** 3`为8 |
| `()` | 明确先计算的部分 | `(5 + 3) / 2`为4 |

乘除先于加减，容易误读就加括号。数学中可省略的乘号在Python里必须写，如 `2 * price`。`10%`不是Python中的百分数常量，增长10%写比例`0.10`，新值写 `old_value * (1 + 0.10)`。

## 字符串与格式化

**字符串**`str`是引号中的文字，例如`"400"`。它看起来像数字，但 `"4" + "5"` 得到`"45"`，属于文字拼接。需要计算时用 `float("400")` 或 `int("400")`转换。

`f"Balance: {balance:.2f} yuan"`称为格式化字符串：前面的f允许花括号内放表达式，`:.2f`表示显示两位小数。`{share:.1%}`把比例显示成一位小数的百分比。显示格式不会改变内部数据的精度。

在示例目录的PowerShell执行 `python budget.py`，结果为：

```text
Balance: 480.00 yuan
Food share: 40.0%
```

复算 `1000-400-120=480`、`400/1000=0.4`。如果先把share乘100，再用百分比格式，会重复扩大100倍。

## 认识输入：先接受文字，再转换

下面是**可单独保存为 input_budget.py 的完整练习程序**，不覆盖原预算文件：

```python
text = input("Income in yuan: ")
income = float(text)
print(f"Income: {income:.2f} yuan")
```

`input`显示提示并等待你输入，按回车后返回字符串。输入1000时，先得到文字`"1000"`，`float`再把它转换成数值。输入“一千”会触发`ValueError`，下一章会处理。输入空格或空字符串也不能自动变成有效金额。

## 变量更新与单位

执行 `balance = balance - 20`时，先算右边，再将新结果绑定到balance。若旧值为480，新值为460。这句在程序中合理，不能按代数等式消去balance得到0=-20。

用 `monthly_income_yuan`这样的名字能保留时期和单位。不要把月收入直接与年度支出相减，也不要靠显示两位小数让错误的单位变得合理。

## 常见错误

- 写成 `income == 1000`想赋值。双等号用于比较，下一章解释。
- 引用未定义的名字，或大小写拼错，触发`NameError`。
- 把`"1000"`与100相加，触发`TypeError`。
- 使用逗号作千位分隔，如直接写`1,000`。Python不会将其解释为整数1000。

## 练习与参考答案

1. 预算改为1200，餐费450，书本150，结果？答：余额600，餐费占比37.5%。
2. 为何 `"10" * 2`得到`"1010"`？答：字符串乘整数是重复；`float("10") * 2`才得到20.0。
3. 基期80、新值100，如何计算增长率？答：`growth = (100 - 80) / 80`，用百分比显示得到25.0%。

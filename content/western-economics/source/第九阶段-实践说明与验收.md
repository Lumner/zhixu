# 第九阶段实践：开放与增长实验台v0.5a

## 要交付什么

提交两份JSON、一张手算对照表与约1000—1500字说明。覆盖账户方向、汇率制度、复利、索洛技术与模型比较；它不是实时汇率工具、国家增长预测或完整学派求解器。第57—58章的科学计算与数据部分尚未进入本入口，所以版本是v0.5a。

完整入口[global_growth_lab.py](示例代码/stage9/global_growth_lab.py)，依赖[open_growth.py](示例代码/stage9/open_growth.py)，只需标准库。先读[模型约定](开放经济与增长模型约定.md)，不将独立块强行拼接。

## 先预测，再运行

默认账户CA18/FA20/残差0；报价升10%而篮子调整后q1；小型开放模型Y700/q1；无技术索洛稳态k4；含技术θ.1204、有效资本稳态约2.759351442。报告的20期索洛状态通常仍在过渡，不必等于解析稳态。

在Windows PowerShell、自己的副本目录执行：

```powershell
Set-Location 'C:\Users\17597\Desktop\tutorial\content\western-economics\source\示例代码\stage9'
New-Item -ItemType Directory -Path 'my-results' -Force
python global_growth_lab.py | Set-Content -Encoding utf8 'my-results/base.json'
python global_growth_lab.py --regime fixed --fiscal-change 20 --saving 0.3 --years 30 | Set-Content -Encoding utf8 'my-results/alternative.json'
python global_growth_lab.py --regime floating --money 480
```

`Set-Content`覆盖指定同名结果，选择自己的文件名。Windows PowerShell可能写入BOM，Python读取可用`utf-8-sig`。程序自己只打印，不联网，不覆盖课程源文件。

## 参数影响范围

| 参数 | 归属与含义 |
| --- | --- |
| --regime | floating或fixed，短期开放制度 |
| --fiscal-change | G消费相对150的增量，公共投资20不重复 |
| --money | 货币水平，默认400；固定时为尝试值 |
| --saving | 两种索洛块的储蓄率，不改独立AK参照 |
| --technology-growth | 仅含技术索洛块的gA |
| --output-growth | 仅复利示例总量增长 |
| --population-growth | 复利人口和索洛劳动共同使用的增长率，综合入口要求非负 |
| --years | 路径共同期数1—200，均从0期初始状态另记一行 |

替代输出短期块应Y740/q1/Ms432，而非独立固定Ms400；无技术索洛稳态应k9/y3/c2.1。它们由不同参数组控制，不能说储蓄率提高导致本题汇率固定下财政产出740。

## 对照报告

`external_accounts`保留残差与所需EO，不为账平偷偷改输入；`small_open_economy`检查产品和货币两个残差。`solow_without_technology`与`solow_with_technology`保存资本、技术、劳动、总量与每有效劳动量，核对K=k~AL、Y=y~AL。

从解析有效劳动稳态另跑一步，才适合核对人均2%、总量4.04%的平衡增长；默认从k~1出发时还含资本深化效应，不能把过渡增长强行填成2%。

`growth_accounting_reference`是已知参数的严格对数分解；`price_adjustment_reference`只改变价格调整假设；AK是独立线性技术。这些reference块不受不相关CLI参数控制，名称提醒你不把它们当全模型联动结果。

## 报告与验收

至少比较浮动财政与固定财政，再比较两种储蓄稳态；另说明一个价格水平/人均/有效劳动混淆的反例。保留实际命令、Python版本与日期，逐项写来源和单位。

必须能解释：FA正号的方向、q升降的含义、固定制度的货币内生性、索洛离散分母、黄金规则的范围、TFP与劳动增进A、模型比较与因果识别的区别。留一项拒绝输入，如`--saving 1.1`或`--years 0`，说明不是有效输出。

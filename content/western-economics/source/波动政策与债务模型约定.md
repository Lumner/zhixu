# 第八阶段：波动、政策与债务模型约定

适用45—50章，核验日期2026-11-13。新增模块是`示例代码/stage8/policy_models.py`，不改stage7接口。各块均使用合成参数，可以分别复算；综合JSON将它们并列展示，**没有把它们求成一套完整国家动态模型**。

## 单位和符号先隔离

| 模型块 | 核心变量与单位 | 不能混用 |
| --- | --- | --- |
| AD—AS | Y为固定价格产出流量，P为价格水平，Pe为参照价格水平；Ms名义货币存量 | P、Pe不是通胀率；改变P的比较不是自动生成实际年度通胀路径 |
| 失业—通胀 | u、un、π、πe均用小数率；期长在比较中固定 | 外部u路径不是内生就业均衡；ω不是当期通胀 |
| 波动传播 | x=(Y−Yp)/Yp，冲击和滞后系数为构造输入 | 负缺口、负增长和统计衰退不是同义词 |
| 财政账本 | 一年内的现价金额，期初债务为名义存量 | Tax总税、TR转移、T净税、G消费、J公共投资分开 |
| 利率规则 | x比例缺口，π/πe/i小数率，r_lin=i−πe近似 | 不与第35章精确Fisher混算，不同时强加固定Ms |
| 债务递推 | B名义总债务，N名义GDP，i名义有效计息率，gN名义增长 | 不用政策利率自动替代有效利率；pb与sf以本期GDP为分母 |

本批不使用真实GDP摘录作为模型输入，也不声称当前2%目标、5%自然失业率、5%计息率或80%债务率属于任何现实经济。有效利率与增长是条件输入，非估计或建议。

## AD—AS接口

`ad_at_price(price,a,money)`沿用stage7默认参数的约化形式Y=(a+money/(4P))/.6，回代产品与货币残差。a默认320；仅在其他支出不变时，a增20可以表示G消费增20。原先私人投资80−1000i、普通非负i的有效范围仍要满足。

`ad_as`再加P=expected_price+supply_slope*(Y−potential)/potential+cost，默认Pe1、s1、potential700、cost0。解析正根之后检查经济区间和AS残差；没有一般的负投资角点求解器。`long_run_price`只给固定Yp、可调整Pe且无持续供给截距问题时的需求价格候选，不能直接替代动态预期调整。

## 预期和传播接口

`phillips`为π=πe−α(u−un)+shock。`inflation_path`使用已给定u与冲击，先计算当期π，再更新πe_next=πe+weight*(π−πe)；默认weight1，0为人为固定预期。`disinflation_unemployment`只反解单期所需u，不保证政策能实现。

`propagation_path`为x_t=rho*x_(t−1)+lag2*x_(t−2)+shock。默认rho.6、lag2为0；另用1.2、−.5演示阻尼回摆。稳定检查针对常系数数学递推，不代表经验机制识别。初始历史缺口默认0；缺口必须大于−1，Yp严格正。输入序列须等长、非空、最多2000项，不接受NaN或bool。

## 财政账本

`fiscal_budget`默认Tax40+.25Y、TR20+.2max(700−Y,0)、G150、J20、Bprev560、有效i.05。净税T=Tax−TR，政府总储蓄T−G，PB=T−G−J，总余额PB−iBprev。其他收入、资本转移、金融资产、核算差异暂时省略；无其他调整时净新增借债为总余额相反数，不是含滚续本金的总融资需求。

本接口的Y外生；改变G只改变给定Y下的账目，不自行求财政乘数。`private_disposable_income`仅为简化Y−T指标，没有分配政府债务利息的部门归属，不能当完整私人可支配收入。若要联动产出和价格，需另构行为、供给与融资模型，不将并列输出强行连接。

## 三方程规则

```text
x=d-σ(i-πe-r*)
π=πe+κx+s
shadow_i=r*+π+φπ(π-π*)+φx*x+εi
i=max(floor,shadow_i)
```

默认σ1、κ.5、φπ.5、φx.5、r*与πe/π*均.02、floor0。`rule_equilibrium`先算普通解，必要时固定i为floor再解x和π，回代影子规则检查。报告三项残差与影子i；没有把负候选直接截断后保留错误产出。规则中x是比例缺口，参考文献也可能用对数缺口，具体单位不能照抄。

## 债务与增长

`debt_step`使用b_new=(1+i)/(1+growth)*b_old−primary_surplus+stock_flow。余额正为初级盈余；两个流量比率分母都是**本期名义GDP**。gross debt不能为负，超出后报错，不把净资产问题混入总债务定义。利率、增长均大于−1。

`debt_path`默认初始名义GDP700、债务率.8，逐年先算GDP，再把盈余比率转金额，分别验证比率与名义金额递推，年份1—100。`nominal_growth`用(1+real)*(1+deflator)−1，deflator必须与GDP范围匹配，不默认CPI可替代。

所有接口仅标准库。运行和参数归属见[阶段运行说明](示例代码/stage8/运行说明.md)，真实执行范围见[第八阶段验证](验证/第八阶段验证记录.md)。

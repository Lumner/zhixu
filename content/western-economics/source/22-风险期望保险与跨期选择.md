# 22 风险、期望、保险与跨期选择

## 学习目标与先修

先完成19—21章。本章约4—6小时，先定义概率和期望，再比较期望财富与期望效用，计算公平保费、确定性等价与风险溢价；最后用两期预算理解储蓄、借款和消费平滑。本章数值全部为虚构练习，不对应现实产品。

## 概率与期望不表示每次都会如此

**状态**是一种可能结果，**概率**表示该结果在模型中出现的可能性，数值介于0与1，全部互斥且穷尽状态的概率和为1。概率0.25是25%，不保证每四次恰好发生一次。

设当前财富100元，概率0.25损失36元，概率0.75无损失。损失后财富为64或100。**期望财富**是按概率加权的平均数：`E[W]=0.25×64+0.75×100=91`元。方括号表示对随机结果取期望。

91不是这一次一定会得到的结果，甚至不是本题任一状态的实际财富。期望损失是0.25×36=9元。

## 从期望财富到期望效用

若只按期望财富排序，称这类财富风险比较下风险中性。若在相同期望财富下更偏好确定结果，可用具有递减边际效用的凹函数表达风险厌恶。

本章设 `U(W)=ln(W)`，W必须为正。ln是自然对数，可理解为一种随W增加而增加、但越来越平缓的函数；例如ln(1)=0、ln(10)约2.302585。其导数1/W随财富增加而下降。

**期望效用**先算各状态效用，再按概率平均：

```text
E[U(W)] = 0.25*ln(64) + 0.75*ln(100)
```

它不同于 `U(E[W])=ln(91)`。凹性使本例前者更低，所以拥有确定91元优于面临64或100的风险。

19章说确定性选择的效用可以作任意严格递增变换保留排序；这里再取概率平均时，不能任意作非线性变换后仍声称风险偏好相同。例如把ln(W)变回W，会改成按期望财富排序，保险判断可能改变。期望效用的表示需要更强的偏好假设，不是随便找一个排序数字就能平均。

## 确定性等价和愿付保费

**确定性等价CE**是与风险方案效用相同的一笔确定财富，满足 `ln(CE)=E[ln(W)]`。exp是ln的逆运算，故：

```text
CE = exp(0.25*ln(64)+0.75*ln(100))
   ≈ 89.442719 元
风险溢价 = E[W]-CE ≈ 1.557281 元
最高全保险保费 = 初始财富-CE ≈ 10.557281 元
```

全保险指缴纳固定保费后，损失完全得到赔付，各状态最终财富相同。**精算公平保费**只等于期望赔付，本题为9元，暂忽略管理费用等。缴9元后确定财富91，大于CE，因此本模型偏好全保险。

若保费为12元，确定财富88低于CE，本模型选择不买。最高愿付保费不是风险溢价本身，而是期望损失9加风险溢价约1.557281。现实保险还有免赔额、保障范围、信息和风险态度差异，这个二状态模型未覆盖。

## Python的对数与指数

标准库math.log默认自然对数，math.exp计算相应指数，math.sqrt计算非负平方根。均需先import math，不需要安装科学计算包。无损失财富、损失后财富和保险后财富在本例都必须为正，不能把0直接交给log。

完整入口[risk_time.py](示例代码/stage4/risk_time.py)依赖micro.py。在stage4目录Windows PowerShell执行 `python risk_time.py`，前几项应为：

```text
expected_wealth: 91.000000
certainty_equivalent: 89.442719
risk_premium: 1.557281
max_full_insurance_premium: 10.557281
```

程序以insurance_weakly_preferred表示“保险至少一样好”，相等时也算不劣；用很小的数值容差处理浮点比较。它没有模拟真实事故，也不是从样本估计概率。

## 跨期预算：今天与明天的资源怎样换算

把现在称为第0期、未来称为第1期。y0、y1是两期收入，c0、c1是两期消费。利率r表示本期1元在下一期变为1+r元，故未来金额的现值为未来金额/(1+r)。这里所有量按同一价格水平表达，暂不讨论通胀。

假定可按同一利率自由借贷，没有额度约束或额外费用，两期预算为：

```text
c0 + c1/(1+r) = y0 + y1/(1+r)
```

设y0=80、y1=132、r=0.1，总现值资源为80+132/1.1=200，所以c1=220-1.1c0。效用设为ln(c0)+ln(c1)。利用对数相加等于乘积的对数，最大化它等价于最大化c0*c1，即 `220c0-1.1c0²`。

求导220-2.2c0=0，得到c0=100、c1=110。现在收入只有80，却消费100，**储蓄**s=y0-c0=-20，负储蓄表示借款20。下一期还22元，132-22=110，正好满足预算。

## 平滑消费的条件与局限

程序two_period_choice还允许给未来效用权重beta>0，目标为ln(c0)+beta*ln(c1)；beta表示偏好权重，不是市场利率。当前手算使用beta=1。其通用公式在代码中保留为延伸，不能把beta和1/(1+r)随意混用。

消费平滑是借贷与偏好的共同结果，不要求两期消费金额严格相等。若禁止借款，则本题c0不能超过80，原来的100不可行；在这个约束下最优为c0=80、c1=132。现有函数只实现自由借贷版本，未偷偷替你处理借款上限。

## 常见错误

- 把期望值理解成最可能值或保证结果。
- 先求平均财富再取效用，误当成期望效用。
- 将风险溢价与最高愿付总保费混为一谈。
- 把未来金额直接与当前金额相加，或忘记借款要连本带息归还。
- 把负储蓄误读成负消费，或不检查现实借贷约束。

## 练习与参考答案

1. 若按风险中性U(W)=W、保费9元比较呢？答：有风险的期望财富91与保险后确定91相同，本模型无差异。
2. 保费12元时，log效用模型为何拒绝？答：保险后财富88低于确定性等价约89.442719。
3. y0=100、y1=110，r0.1、beta1时消费？答：现值仍200，最优仍100和110，但储蓄为0，和原题不同的收入时点对应同一现值。
4. 原题禁止借款时能否仍消费100？答：不能；需重新在c0≤80下检查，本例最优80和132。

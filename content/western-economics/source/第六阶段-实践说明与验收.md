# 第六阶段实践：宏观核算实验台v0.3

## 要交付的结果

用第33—38章的独立教学样本生成一份JSON报告和一份自己的中文解读。报告回答如何核算、如何比较和是否口径一致，不承担政策预测。旧的市场实验台v0.1、微观v0.2a和v0.2保持各自入口；本阶段不修改旧模型。

项目文件是[macro_lab.py](示例代码/stage6/macro_lab.py)、共享[macro.py](示例代码/stage6/macro.py)与完整[data目录字典](宏观指标口径与数据字典.md)。学习程序只用标准库。维护者制作静态图的Matplotlib不是本实验安装要求。

## 第一步：先列出预期

基准生产链GDP250；两商品名义GDP1500、固定基期实际1200、平减125；消费篮子135、生产者篮子108；劳动基准失业率60/660；部门账目S220=I200+NX20。这些来自不同小样本，不能因为都是“GDP”就强制令250、1500、1000相等。

单独列出真实历史公告摘录的身份：2024年度、2025-12-26发布、现价1348066亿元、不变价增速5.0%、当次最终核实。它只用于阅读来源，不进入上述计算。`data_origin`和`official_reading.kind`分别标记两类材料。

## 第二步：运行并保存自己的输出

在Windows PowerShell执行，当前目录为你自己的实验目录；下面以项目内新增学习输出目录为例。该目录由你运行时创建，本课交付不预装任何“已完成”学习结果。

```powershell
Set-Location 'C:\Users\17597\Desktop\tutorial\content\western-economics\source\示例代码\stage6'
New-Item -ItemType Directory -Path 'my-results' -Force
python macro_lab.py | Set-Content -Encoding utf8 'my-results/base.json'
python macro_lab.py --scenario discouraged --vintage initial --nominal-rate 0.03 --inflation 0.05 | Set-Content -Encoding utf8 'my-results/alternative.json'
```

程序输出采用ASCII转义的标准JSON，PowerShell保存为UTF-8。若由Python读取Windows PowerShell生成的含BOM文件，使用`utf-8-sig`编码。命令中`|`将文本交给下一条命令；`Set-Content`写入指定文件，会覆盖同名学习输出，因此选好自己的文件名。程序本身只向终端输出，不写数据文件。

## 第三步：解释参数影响范围

| 参数 | 控制内容 | 不应从它推导的变化 |
| --- | --- | --- |
| --scenario | 三行劳动状态之一 | 不推导GDP、工资或价格反应 |
| --nominal-rate | 实际利率例子的名义利率 | 不估计银行、投资需求或储蓄反应 |
| --inflation | 同一利率例子的通胀率 | 不改写消费篮子、平减指数或季度量 |
| --vintage | 独立两期修订例子选哪一版 | 不把完整季度表也自动修订 |

替代输出应显示E600、U40、参与率64%、失业率6.25%；实际利率1.03/1.05−1≈−1.904762%；初版同比8%。GDP生产链、两商品表与部门账本保持原值，因为它们是并列测量实验，不是联动的经济行为模型。

## 第四步：核对时间序列和恒等式

完整季度表2024Q1：原始环比−13.6%、同比8%；年合计2023为440、2024为475.2、2025为494.208。报告前四季同比为`null`，不应填0。已知季节因子调整在章内完整程序演示，综合报告保留原序列，不伪装成官方季调数据库。

部门账目两项残差均应为0。另在自己的Python副本中仅把政府消费加10，观察−10残差，并解释“输入不再满足恒等式”。不要把程序改成悄悄填平差额，更不要据此宣称得到乘数或经济预测。

## 第五步：提交中文报告

建议800—1200字，包含：目的与来源；一项手算与程序对照；一个口径陷阱；一个参数改变；一项未定义或无效输入；一份官方公告元数据；核算与因果的区别。写清你真正运行的Python版本和日期。维护者通过测试不等于你的学习练习已自动通过。

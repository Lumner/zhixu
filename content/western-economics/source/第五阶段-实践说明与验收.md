# 第五阶段实践：微观实验台v0.2

## 作品范围

结合第四阶段消费者与企业例程，本批27—32完成市场结构与市场失灵的教学实验。v0.2表示规划中19—32这部分已提供基础模型与练习；不表示覆盖所有中级微观专题，更不是已经完成宏观、真实政策评价或联立一般均衡的软件。

## 操作与参数归属

进入source/示例代码/stage5，Windows PowerShell执行：

```powershell
python policy_lab.py
python policy_lab.py --firms 3 --damage-slope 0 --coverage 1
python policy_lab.py --help
```

--firms只改变古诺企业数；--damage-slope只改变外部性模型损害斜率；--coverage只改变隐藏行动的保障比例。垄断、交换、公共品和其他字段保持各自默认参数。CLI没有暴露全部函数参数，更多练习按模块交互调用完成。

第一组应有垄断Q48/P36、古诺总Q64/P28、交换各(5,5)、社会最优产量48/单位税12、公共品最优8/自愿4、低品质交易池报价100。第二组的古诺总Q72/P24、矫正税0、全保障下不努力，对照32章解释。

## 报告要求

在自己的练习副本中写800—1200字，附公式、表、图和运行记录：

1. 选三个机制，其中至少一个属于市场结构，一个属于外部性/公共品，一个属于信息问题。
2. 对每个机制写参与者、约束、信息、可选行动、单位和保持不变的条件。
3. 提供基准与一个反事实，先作方向预测，再用手算与程序核对。
4. 明确比较的是利润、消费者剩余、净社会收益，还是个人效用前后变化；不同指标不要混算。
5. 至少讨论一个边界：零交易、多个纯策略均衡、没有纯策略均衡、容量约束、公共品零供给或参与池变化。
6. 写出现有模型不能支持的现实结论，并说明需要什么数据或制度信息。

## 可复现验收

| 维度 | 通过条件 | 证据 |
| --- | --- | --- |
| 最优与均衡 | MR/MC、最佳反应或资源出清可逐步解释 | 方程、手算与回代 |
| 效率与分配 | 转移、真实资源损失、个人变差分别处理 | 福利表或帕累托比较 |
| 边界 | 不强迫内点条件覆盖所有情况 | 至少一个不同边界运行 |
| 信息 | 说明谁知道什么、何时知道 | 参与池或努力选择表 |
| 程序 | 完整目录、命令、解释器版本、退出结果 | 实际日志 |
| 局限 | 教学参数、有限网格、制度条件、因果边界齐全 | 独立限制段落 |

一个有用的反例是第29章整数网格：在有限集合里未被支配，不等于在连续集合里有效。请亲自写出一个小数分配使双方改善，证明你没有只背程序的“frontier”标签。

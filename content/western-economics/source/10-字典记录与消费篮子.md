# 10 字典、记录与消费篮子

## 学习目标与先修

先完成09章。约3—4小时，学会用字典表示一条有字段的记录，用列表表示多条记录，计算固定消费篮子的两期成本。这里的价格指数仅为教学篮子，不冒充官方CPI。

## 为什么只有列表还不够

`["rice", 5, 4, 5]`虽然能保存名称、数量和两期价格，但第三个5到底表示什么容易忘。**字典**`dict`将键与值配对，例如：

```python
item = {"name": "rice", "quantity": 5, "base_price": 4, "current_price": 5}
print(item["quantity"])
```

这是可独立运行的小例子。花括号创建字典，冒号分隔键和值，逗号分隔字段。键`"quantity"`是字符串，读取结果5。一个字典可作为一条**记录**，字段要有稳定含义，例如数量单位千克、单价元/千克。

读取不存在的键`item["weight"]`会触发`KeyError`。`item.get("weight")`可返回None，但不能靠默认值掩盖必需字段缺失。课程数据的必需列会在读入时检查。

## 列表装多条记录

完整文件[basket.py](示例代码/basket.py)有两项：米5千克，基期每千克4元、当期5元；奶10盒，基期每盒3元、当期3.6元。不同商品的数量单位不同，但各自的“单价×数量”都得到元，因此成本能相加。

```python
items = [
    {"name": "rice", "quantity": 5, "base_price": 4, "current_price": 5},
    {"name": "milk", "quantity": 10, "base_price": 3, "current_price": 3.6},
]
```

这段是完整文件的数据部分。每个列表元素都是一条字典；`items[0]["base_price"]`先取第一条记录，再取基期价，得到4。

## 固定篮子成本如何计算

**固定消费篮子**指比较两期价格时保持购买数量不变。先固定米5千克、奶10盒，再分别使用两期价格计算：

1. 基期成本 `5×4 + 10×3 = 50` 元。
2. 当期成本 `5×5 + 10×3.6 = 61` 元。
3. 基期设100，篮子价格指数 `61/50×100=122`。
4. 同一篮子成本增长22%，需要多花11元。

程序用两个累计变量分别计算成本。在示例目录的PowerShell执行 `python basket.py`，输出：

```text
Base basket: 50.00 yuan
Current basket: 61.00 yuan
Basket index: 122.00 (base=100)
```

米价格涨25%，奶涨20%，篮子涨幅不是简单平均22.5%。基期支出权重为米20/50=40%、奶30/50=60%，加权涨幅 `25%×40%+20%×60%=22%`。

## 修改、排序与复制的起点

`item["current_price"] = 6`更新一个字段。`items.append({...})`新增一条完整记录。`sorted(items, key=lambda row: row["current_price"])`可以按当期价排序：sorted返回新列表，key给出排序依据，lambda在这里是一个没有单独名字的小函数。初学可以先不使用lambda，等读懂普通函数后再替换。

`other = items`不会复制一套独立记录，而是让两个名字引用同一列表。修改其中的字典，另一个名字也能看见。`items.copy()`只复制外层列表，里面的字典仍共享。需要独立修改本练习，最简单是新建一份数据，后续再学习深复制。

## 常见错误

- 同一字典中重复写相同键，以为能保留两期价。后面的值会覆盖前面的；应使用不同字段名。
- 直接平均价格涨幅，忽略支出权重。
- 同时改变篮子数量和价格，却仍把成本比解释为纯价格变动。
- 将样例的122叫“中国CPI”。样例范围、权重、采样与官方统计都不同。

## 练习与参考答案

1. 奶当期价改为3.3元，指数多少？答：当期成本25+33=58，指数116，涨幅16%。
2. 米数量改为10、奶保持10，两期成本和指数？答：基期70，当期86，指数约122.86；权重改变使涨幅变化。
3. `item["quantity"]`为什么不用索引0？答：字典按键取字段，列表才按位置索引；二者解决不同组织问题。

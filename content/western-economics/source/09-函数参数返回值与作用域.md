# 09 函数、参数、返回值与作用域

## 学习目标与先修

先完成08章。约3—5小时，学会定义自己的函数，区分参数、返回值与打印，并理解局部变量。把需求规则变成可反复调用的工具。

## 从重复公式到函数

**函数**将一段有明确职责的步骤命名，调用时提供输入，执行后可以返回结果。Python中的函数与数学函数相似，但程序函数也可能读文件、打印或改变外部数据；本章先写仅根据输入返回数值的计算函数，容易检查。

完整文件[functions.py](示例代码/functions.py)中的定义是：

```python
def demand(price, intercept=120, slope=2):
    quantity = max(0, intercept - slope * price)
    return quantity
```

`def`开始定义，demand是名字，括号内是**形参**，冒号后的缩进是函数体。price是价格，intercept是截距，slope这里表示需求下降速度的正数，负号写在公式中。`=120`和`=2`是默认值，调用时可以省略。

定义不会立刻执行函数体。`demand(24)`才发起一次调用，24是这次提供的**实参**。执行 `max(0,120-2*24)`得到72，`return`把72交回调用处。

## 手工追踪一次调用

```python
q = demand(24)
revenue = 24 * q
print(revenue)
```

这是依赖前面demand定义的片段。过程为：计算调用、获得72、赋给q、计算24×72、输出1728。q是数量杯/日，revenue是总收益元/日。总收益等于价格乘销售量，还没有扣成本，因此不是利润。

在示例目录的PowerShell执行 `python functions.py`，完整文件输出：

```text
Quantity: 72
Revenue: 1728
```

## 返回与打印有何区别

`print`给人看，`return`给后续计算使用。若函数最后只写 `print(quantity)`，屏幕上会有72，但 `q = demand(24)` 得到的是默认返回值 `None`，表示没有相应数值结果；随后乘法会失败。

`return`也会结束本次调用，后面的同层语句不再执行。初学时建议把一个函数写成“输入有定义、输出有单位、职责单一”，不要一边询问用户一边随意修改全局数据。

## 参数传法和默认值

`demand(20, 150, 2)`按位置传值，结果为110。`demand(price=20, intercept=150)`按名称传值，slope使用默认2。较长调用优先用名称，减少把参数位置放错的风险。

本章只用数值默认参数。列表等可变对象作为默认值有共享状态的细节，等需要时再学，当前不要把默认值写成一个会不断append的列表。

## 作用域与入口保护

**作用域**决定一个名字在哪里能使用。函数内部的quantity是局部变量；调用后在外面直接访问quantity通常会触发NameError。函数把需要的结果通过return交出，调用者用自己的名字接住。

完整文件还写了：

```python
if __name__ == "__main__":
    q = demand(24)
    print(f"Quantity: {q}")
    print(f"Revenue: {24 * q}")
```

这是该文件实际入口的一段完整代码。直接运行文件时，Python将特殊名字`__name__`设为`"__main__"`，因此演示会执行。别的文件导入它时，函数仍可使用，演示部分不会自动打印。第12章会验证这一点。

## 常见错误

- 忘记调用括号，`q=demand`保存的是函数本身，未计算数量。
- 参数名与调用名拼写不一致，触发TypeError。
- 以为函数内quantity在所有文件里都可见。应使用返回值。
- 在多个函数里硬写120与2，后续改模型时漏改。把可变假设放到参数更清楚。

## 练习与参考答案

1. `demand(30)`是多少？答：60。
2. `demand(price=30, intercept=150, slope=3)`是多少？答：60，但来自另一套模型参数，不能因为结果相同就认为模型相同。
3. 写预算余额函数。参考：`def balance(income, expense): return income - expense`。实际文件分行并按四空格缩进；输入校验可由调用前负责或在函数中明确规定。
